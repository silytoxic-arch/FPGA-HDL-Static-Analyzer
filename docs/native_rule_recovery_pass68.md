# 第六十八轮：A-3-3 未寄存模块输出

本轮只深化规则判断逻辑，不调整界面和表格。软件对外编号继续采用官方三段式 `A-3-3`。

## 新恢复事实

- 最终虚表 `0x180eef7a8` / `0x180eef7f0` 的运行槽和选择槽分别为 `FUN_1807023a0`、`FUN_180704420`。
- `FUN_1804e66e0` 只接纳没有直接边沿子节点的组合过程。
- RHS 必须至少引用一个 `+0xa2` 寄存标志为零的对象；纯寄存来源不报告。
- 候选按文件、输出名称和物理行聚合，常量位选/范围展开后合并相邻位。
- 完整宽度正文为 `未寄存的模块输出端口<name>`，部分覆盖追加 `[bit]` 或 `[high:low]`。
- 严重级别为 `警告`，原生记录只有物理行、没有列。

## 产品变更

- 增加非寄存 RHS 门控，消除直接寄存信号送输出的误报。
- 恢复无边沿组合过程边界、同一行逐位聚合、完整宽度和部分位段正文。
- 原生无列位置统一用第 1 列占位。
- 为逐模块运行保留相同文件/行/正文的诊断重数。
- 增加直接寄存来源、混合表达式、部分范围、同一行完整位覆盖及同一行多模块测试。

复杂前端 lowering 与工程层次未知边界继续保持人工复核。
