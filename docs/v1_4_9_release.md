# FPGA HDL Static Analyzer V1.4.9

本版继续只处理规则集，不调整界面。

## GJB10157.5.2.17 条件编译参数重名

原生 `GJB10157.5.2.17` 对解析后的 `AST_PARAMETER(9)` 建立一次规则运行范围内的
全局名称表，并在后续同名 parameter 处报告。产品此前直接扫描原始 token，同时跳过所有
条件编译块，导致工程宏启用的实际分支可能漏检。

本版改为在判定前应用工程 `defines`：

- 活动条件分支中的 parameter 正常参与跨文件、跨模块重名检查；
- 非活动分支不会产生误报；
- 重复位置仍定位到后一个 parameter 的原始文件、行和列；
- 预处理失败时不猜测活动声明，结果保持人工复核；
- localparam 和大小写不同名称仍按原生已恢复边界排除。

新增正例、反例和源位置边界测试。厂商完整宏展开、include 内容注入、生成 AST 和遍历顺序
仍属于未知项，不宣称完整前端等价。
