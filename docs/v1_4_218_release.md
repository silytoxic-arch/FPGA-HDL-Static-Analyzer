# FPGA HDL Static Analyzer V1.4.218

## R-6-2 单边沿赋值状态

原生 FUN_180561f70 对 identifier-free RHS 或含任一 parameter/localparam 名称的
RHS 将目标状态置为 1；动态 RHS 仅在键不存在时插入 0，因此不能撤销已有覆盖状态。
本版将该行为接入显式单边沿 always 的简单赋值目标，覆盖常量、参数、混合 RHS、
两种赋值顺序、过程隔离、模块隔离和 <= 条件比较边界。

规则继续使用官方三段式 R-6-2，保持部分接入等级。拼接左值、局部名称遮蔽、
完整多边沿候选、综合关系生产和原生定位字段仍需恢复。无诊断继续人工复核，
完整专有前端等价为 0/209。

Windows 包仅由 GitHub Actions 构建和保存。本地仅执行源码验证，不生成或下载 Windows 包。
