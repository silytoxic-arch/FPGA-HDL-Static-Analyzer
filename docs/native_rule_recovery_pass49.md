# 第四十九轮：A-1-5 端口方向与时钟复位关系排序

本轮按官方索引使用三段式编号 `A-1-5`，内部条款键仅用于实现与证据关联；未进行表格或界面格式调整。

## 新恢复事实

- 构造函数、虚表、活动入口和 `AST_MODULE` 准入槽已闭合。
- `AST_WIRE` 的 `+0xa0/+0xa1` 组合区分 input、output、inout，实际记录保存名称和物理行。
- 关系类别 2/3 为时钟组，类别 0/1 为复位组；原生先收集时钟，再收集复位。
- 期望顺序为时钟输入、复位输入、其余输入、输出、双向端口，并按名称去重。
- 重复实际端口名导致期望/实际数量不等，整模块跳过；数量相等时仅报告首个错位。
- 原生输出为 Error、首个错位物理行、第 1 列，固定正文为“端口列表应按照“时钟、复位、输入、输出、双向端口”的顺序描述”。

## 产品变更

- 将重复端口名路径改为原生的数量不一致跳过。
- 将诊断正文、严重度及列位置改为原生值。
- 增加固定诊断、重复名称和同行端口定位测试。
- 台账将该规则提升为“证据支持的核心判据；集成源码适配器”。
