# V1.2.41 VHDL FILE_OPEN 路径规则

新增 GJB9765.4.14.d.4 的有界自动检查：对 `FILE_OPEN(...)` 的直接字符串参数，若包含 `:/` 或 `:\`，报告 Warning。附件中的 `G:/test.dat` 违反例与 `../test.dat` 遵循例均匹配；注释、无关字符串、嵌套参数和单独 Unix 根路径不触发这条已恢复的原生判据。原生证据与未知边界见 [恢复记录](evidence/native_vhdl_file_open_path_4_14_d_4_findings.md)。

公开样例审计保持 446 例，工程上下文类匹配数由 11 增至 12，失配由 11 降至 10。台账现为 209 条中 47 条核心谓词部分接入、162 条仍待解释、0 条完整等价验证；无告警仍不代表已证明合规。
