# FPGA HDL Static Analyzer V1.3.90

本版本只推进规则集准确性，不修改表格或其他界面格式。

## GJB10157.10.1

完成 `T-Linter.dll` 原生入口 `FUN_1804fe030` 及其 FSM 关系处理路径的只读恢复。原生实现先构建状态关系图，再进入规则专用诊断辅助函数，不是对状态名或 `case` 文本做简单匹配。

产品现接入可严格证明的死锁子判据：

- 支持既有严格识别的一进程 FSM 和直接二进程 `state/next_state` FSM；
- 只有转换图完整、且某状态所有显式出口均只回到自身时才报告；
- 两状态循环、存在显式离开边、转换目标复杂或图不完整时不误报；
- 不可达状态因仍需完整恢复原生起始状态选择，继续要求人工复核。

详细证据见 [原生恢复记录](evidence/native_verilog_fsm_deadlock_10_1_findings.md)。
