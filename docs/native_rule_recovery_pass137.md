## 观察与实现

V1.4.254 同一向量逻辑模块的字面形式会报告 A-9-1，完整模块宏形式却漏报；
宏生成父模块的参数覆盖也未进入该检查的工程集合，导致使用子模块默认参数报警。
保留的 before/after 是产品版本对照，不是厂商运行结果。

本轮迁移 A-9-1、R-10-2、R-11-1、A-11-1、R-11-3 共五项检查：
判据消费同一预处理会话的不可变展开文本，模块、表达式 token 与宽度模型共用虚拟坐标。
检查完成后仅映射新增诊断到文件/行。字面整行可证明一致时保留精确列，宏生成、include
及逻辑 line 没有精确列证明时使用第 1 列。不会用报告偏移索引展开文本。

A-9-1 及 R-11-3 的默认参数准入从所有展开根收集命名/位置覆盖，覆盖来自其他文件或宏
生成父模块时同样保守推迟默认参数解释。任一 Verilog 根未获得有效展开输入时，不能证明
不存在覆盖。该集合只覆盖现有有界解析器识别的实例；不是完整 elaboration。

保留 R-11-3 原生不对称：标签宽度未知跳过，选择器宽度未知却可能与已知标签比较报警。
因此不能把“停用默认参数”等同于“此条规则没有任何告警”。
