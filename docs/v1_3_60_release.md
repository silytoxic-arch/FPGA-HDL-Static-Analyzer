# FPGA HDL Static Analyzer V1.3.60

本版只调整规则集，没有修改问题列表、代码规模明细或任何表格界面。

## 规则准确性

- 恢复 GJB9765.4.9.h 的直接计数分支：同一 VHDL 设计单元内存在两个或更多不同的时钟关系名称时，每个设计单元报告一次。
- 时钟名按 VHDL 不区分大小写去重；同一时钟的上升沿和下降沿不被重复计算为两个时钟域。
- 无告警仍保留 `ProjectContextRequired`，不把尚未完整恢复的层次连接、PLL/时钟原语和跨实例传播伪判为合规。
- 新增附件双时钟正例、单时钟反例、大小写和边沿边界测试。

原生证据与局限见 [GJB9765.4.9.h 恢复记录](evidence/native_vhdl_clock_domains_4_9_h_findings.md)。
