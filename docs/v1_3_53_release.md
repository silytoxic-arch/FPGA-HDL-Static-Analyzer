# FPGA HDL Static Analyzer V1.3.53

本版本只推进规则集，不包含表格或界面格式调整。

## GJB9765.4.10.j

- 从用户附件 `T-Linter.dll` 的构造函数 `0x180024f10` 和 vtable slot 0 `0x1806530a0` 恢复复位/置位唯一有效电平核心判据。
- 按 VHDL 大小写不敏感信号名汇总跨进程有效电平；同名信号同时出现高、低有效用法时报告。
- 补齐附件明确覆盖的 `SET` 异步置位控制，不再只识别 reset/rst 名称。
- 显式条件电平优先于名称后缀推断，避免单个 `SET='0'` 或 `RST='0'` 进程被虚构为极性冲突。
- 保留每个设计单元、每个冲突信号的独立诊断；原生逐后续冲突记录的诊断重数差异写入限制台账。
