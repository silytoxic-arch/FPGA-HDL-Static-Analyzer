## GJB10157.9.2.3 case 选择项位宽

对附件 `T-Linter.dll` 的指令级静态复核确认，普通 case 规则对选择器和每个
非块选择项都以 flag-zero 调用位宽辅助器。同一分支的多个标签逐个判断；
default 组和语句块子项跳过，casez/casex 不进入该分支。

未知门控具有原生不对称性：选择项宽度为 `-1` 时跳过；选择器为 `-1`、
选择项宽度已知时仍按不相等告警。产品已撤销从通用字面量和取值范围诊断到
本条款的间接映射，改用专用适配器复现该行为。

接入范围覆盖固定信号与选择、显式位宽字面量、连接、静态重复连接、位运算
和有界算术树，并支持多标签、嵌套普通 case 及配置后的条件预处理。函数返回
宽度、强制转换、动态选择以及完整参数覆写/宏/生成展开仍保持未知。无覆写
歧义时会解析固定数值参数默认值，避免把附件中的定宽默认参数误当成未知。
