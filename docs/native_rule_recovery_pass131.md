## 产品接入

process 敏感表仍在声明前的可见范围解析，随后复制声明环境，完整读取 BEGIN。
支持已有有界语法中的局部 variable/constant、标识符枚举和标量 subtype 链。
声明名先隐藏外层同名对象，初始化不会改变已恢复的顶层 IF 分类。
局部子程序、导入、文件及非法局部 signal 保留未知，函数体 BEGIN 不当作 process BEGIN。

局部 IEEE 标量变量、常量可以成为可读 EQ 操作数，并有自己的声明归属。
时钟候选单独要求原可见信号绑定仍然存在；局部值不能靠同名继承外层信号身份。
类型/值绑定都限制在本进程中，不泄漏到后续进程。
跨声明归属的同名额外配对继续未知，不根据名字相同就制造诊断。

顺序部分查找唯一顶层 IF，允许它前后出现有界简单信号赋值、NULL 和相应可选标签。
不把任意顺序语句简单删除：WAIT、循环、复杂表达式赋值及其它未核验语法保留未知；
两个顶层 IF 不会被偷偷归为单 IF 类别。
