# FPGA HDL Static Analyzer V1.3.93

本版本推进 GJB10157.7.2.2 门级锁存器检测和 GJB10157.6.2.5 初始化逻辑恢复。

## 7.2.2 门级反馈检查

根据 DLL 原生反馈分量构造、四类单元计数和最终告警分支，接入模块内连续布尔表达式和基本门实例的强连通分量检测。可以定位常见交叉耦合 NAND/NOR 锁存结构；统计环内 AND/OR/逻辑与/逻辑或单元，并保留“超过两个则跳过”的原生条件。每个独立反馈环报告一条问题，环外输入逻辑不参与该计数。

时序寄存器、纯连线别名、无环逻辑链、不同模块同名信号和宏非活动分支均有回归覆盖。复杂驱动、向量、常量折叠、参数、generate 和层次结构仍需复核；无告警不会自动判合规。详见 [恢复证据](evidence/native_verilog_gate_latch_7_2_2_findings.md)。

## 6.2.5 恢复进展

已定位初始化属性过滤、initial 配置分支、时序过程源码匹配及缺少初始化目标的报告路径；器件适用性和配置语义仍在恢复，本版保留人工复核。详见 [当前证据与下一步](evidence/native_verilog_power_initialization_6_2_5_findings.md)。
