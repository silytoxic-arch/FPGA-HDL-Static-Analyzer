# FPGA HDL Static Analyzer V1.4.3

## GJB9765.4.13.a 文件头注释规则修正

原生规则入口读取外部配置的文件头关键字表。附件没有给出该表的厂商默认栏目，因此不能把示例中的文件名、作者、版本、日期、修订历史等栏目全部臆测为固定要求。

规则文本本身明确要求“文件开头应添加英文注释”。本版加入一个有界的标准文本默认子判据：

- 在首个 `library`、`use` 或 `entity` 之前查找 VHDL 注释引导符 `--`；
- 文件开头完全没有注释时，可确定报告违规；
- 注释写在第一个上下文子句之后，不算文件头；
- 有注释只能证明最小要求，不证明规定栏目齐全，干净结果仍为人工复核；
- 工程显式关键字配置优先，显式空表仍可关闭该配置型检查。

详细恢复证据和边界见 [GJB9765.4.13.a VHDL 文件头关键字规则恢复记录](evidence/native_vhdl_header_policy_4_13_a_findings.md)。

## GJB10157.7.3.3 保留工程上下文

附件违规样例只包含父模块，没有提供 `my_module1` 的定义。缺少子模块形式端口方向时，无法证明 `IN1`/`OUT1` 是单向端口；本版明确保留 ProjectContext，不为追求样例命中而伪造库单元模型。
