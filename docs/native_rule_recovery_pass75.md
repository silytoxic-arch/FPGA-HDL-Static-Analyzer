# 第七十五轮：R-5-1 异步复位非复位端口

本轮只深化规则判断逻辑，不调整界面和表格。软件对外编号继续采用官方三段式 `R-5-1`。

## 新恢复事实

- 恢复构造函数、旧键与标准键、最终虚表和模块选择器。
- 确认赋值数据端及单元实际端口中的每个异步控制标识符 AST 独立进入候选并独立报告。
- 恢复精确正文 `异步复位/置位信号<名称>连接到非复位/置位端口`、原生内部标签
  `警告`、标识符物理行及无列语义。
- 确认单元分支依赖专有端口元数据排除复位/置位端口。

## 产品变更

- 连续赋值、过程赋值和命名端口表达式不再只检查第一个异步控制标识符。
- 同一行多个命中保持每个标识符 AST 一条诊断，不再因正文和位置相同而折叠。
- 自定义场景正文统一改为原生固定正文，位置改为标识符物理行、列 `1`。
- 增加精确正文、无列位置、同一行多命中和同一表达式多复位测试。

位置端口、专有库端口语义和完整复位关系生产器仍保持人工复核边界。
