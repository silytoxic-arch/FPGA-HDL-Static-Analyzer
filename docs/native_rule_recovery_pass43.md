# 第四十三轮：A-14-1 状态关系键计数与数值规范化

本轮按官方三段式编号深化 `A-14-1`，不修改表格或界面布局。

## 新恢复事实

- 原生报告器遍历状态机关系键，精确排除 `init` 和 `default`，再把其余键插入去重树。
- 去重树大小只有严格满足 `0x28 < size` 时才报告，即 40 不报告、41 报告。
- `AST_CONSTANT` 标签先经前端数值转换再成为关系键；等值的不同进制/位宽写法不应重复计数。
- 原生严重级别为 Warning，完整消息为 `状态机状态数不应超过40个,当前<数量>个`。
- 新建并保存了可复用的完整 Ghidra 工程 `T_Linter_A14_1`，原目标 DLL 未执行、未修改。

## 产品变更

- 状态标签数值键新增二、八、十、十六进制、位宽和 signed 的有界规范化；
- 保留 Verilog 标识符大小写敏感；
- 继续排除 default，合成 init 不进入源状态集合；
- 恢复 Warning 和完整原生消息；
- `A-14-1` 台账提升为“原生核心谓词 + 集成源码适配器”，集成适配器由 26 条增至 27 条；完整厂商算法等价仍为 `0/209`。

## 验证边界

7 组定向断言覆盖 40/41 严格边界、一进程、二进程、`always_ff`、重复标识符、等值数值编码及非状态译码器，并校验原生 Warning 与完整消息。CTest `135/135` 全部通过；附件 446 个示例审计保持无未解释差异。
