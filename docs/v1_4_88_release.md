# FPGA HDL Static Analyzer V1.4.88

本版本只推进规则逆向、判断逻辑和验证，不调整界面或表格布局。

## 本轮规则

- 官方公开编号：`A-2-3`
- 内部标准映射：`GJB10157.5.2.13`
- 主题：Verilog 时钟信号命名。

## 准确性修正

- 从 DLL 恢复关系类别 `2/3`、转义标识符规范化、每设计名称去重、AST 定位和精确消息路径。
- 同一非法时钟在上升沿和下降沿重复出现时只报告一次。
- 转义标识符先规范化，再执行原生大小写敏感的完整正则匹配。
- 固定 Error，使用候选物理行和第 1 列。
- 保持关系类别正式含义、别名、派生时钟和层次传播未知时的人工复核状态。

## 验证结果

- 自动化测试：`135/135` 通过。
- 规则审计：附件中的 `446` 个示例结果保持稳定（`435` 个自动匹配、`6` 个工程上下文匹配、`4` 个仍需上下文、`1` 个原生实现与附件正文冲突）。
- 已集成源适配器：`18` 条；`A-2-3` 因关系生产模型未完整恢复，仍严格标记为部分集成。
- 209 条公开规则编号格式：全部符合官方三段式 `R-X-X / A-X-X`。
- 厂商完整算法等价：`0/209`。
