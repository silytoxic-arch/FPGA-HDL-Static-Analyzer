# FPGA HDL Static Analyzer V1.4.249

扩大 VHDL A-10-4 的进程来源检查，减少局部声明和普通顺序语句造成的漏检。

- 支持 process 中有界变量、常量、类型声明和初始化，遵守声明顺序及名称隐藏。
- 局部标量可读值可以参与 EQ 条件，时钟候选仍需保持信号身份；局部值不继承同名外层时钟。
- 唯一顶层 IF 前后可以有简单信号赋值、NULL 及相应标签，不误计为额外源 IF。
- 多个顶层 IF、复杂控制流、局部子程序和未确认的跨归属同名配对继续保留未知。

新增 32 组模型边界、4 组端到端回归，本地 CTest 134/134 通过。
446 个附件示例保持 433 项自动匹配、6 项工程上下文匹配、4 项需上下文和
3 项既有静态实现/文档差异，没有新增未解释变化。

7 份新增原始证据与 [第一百三十一轮记录](native_rule_recovery_pass131.md) 一并保留。
完整算法验证仍为 0/209，无诊断仍需人工复核。
