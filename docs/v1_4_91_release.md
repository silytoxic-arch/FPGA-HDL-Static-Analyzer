# FPGA HDL Static Analyzer V1.4.91

本版本只推进规则逆向、判断逻辑和验证，不调整界面或表格布局。

## 本轮规则

- 官方公开编号：`A-2-2`
- 内部标准映射：`GJB10157.5.2.12`
- 主题：名称长度规则配置入口闭合。

## 证据修正

- 新建并分析附件 `runCheck.exe` 的独立 Ghidra 工程，追踪规则字符串和配置分发函数。
- 确认 `A-2-2` 只调用通用 `setRule`，三个扩展配置字段均为空，不经过任何专用 setter。
- 检查附件全部 PE64 导入/导出表，没有名称长度 setter。
- 验证 `setMaxStatesNum` 只写规则对象 `+0x140`，与名称长度字段无关。
- 因此撤销“存在未接入配置入口”的旧推断：所提供版本固定采用 2..32，并将该规则提升为证据支持的源适配器。

## 验证结果

- 自动化测试：`135/135` 通过。
- 规则审计：附件 `209` 条标准规则、`446` 个文档样例均已重新扫描；`435` 个自动匹配、`6` 个工程上下文匹配、`4` 个仍需上下文、`1` 个原产品与文档冲突。
- 已集成源适配器：`20` 条。
- 209 条公开规则编号格式：全部符合官方三段式 `R-X-X / A-X-X`。
- 厂商完整算法等价：`0/209`。
