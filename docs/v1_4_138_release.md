# V1.4.138 官方三段式规则编号

本版本统一 FPGA HDL Static Analyzer 的所有用户可见 GJB 规则编号，严格采用附件官方索引中的三段形式 `R-X-X` / `A-X-X`，例如 `R-2-1`、`A-8-1`。

## 编号边界

- `R-X-X` 表示官方强制规则索引，`A-X-X` 表示官方建议规则索引；两者均保留，不能把 `A` 规则改写成 `R` 规则。
- `GJB9765.4.8.e`、`GJB10157.5.2.1` 等正文条款键仅在分析器内部用于算法定位和兼容，不再作为界面或报告中的规则编号。
- GJB9765 与 GJB10157 可各自包含同名编号（例如都包含 `R-2-1`），因此查询时由当前标准配置消除歧义。

## 对外输出

- 问题列表、问题详情、文本报告、HTML 报告、JSON 报告、SARIF 报告和 CLI 规则列表均使用官方三段编号。
- JSON 的 `standard.assessments[].ruleId` 与 `violations[].ruleId` 不再附带内部 `clauseId`。
- SARIF 的规则和结果只发布官方三段 `ruleId`，不再在 `properties` 中泄露内部条款键。
- 审计脚本改为使用与产品相同的官方编号映射关联诊断，避免依赖已移除的内部字段。
