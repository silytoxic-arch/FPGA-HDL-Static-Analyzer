# Figma 界面优化

设计文件：https://www.figma.com/design/QGY5w6p4GZ4ibG5Ek1oFFT

- 分析工作台：节点 `3:46`。
- 代码行数统计：节点 `3:47`。
- 专用指标卡片与导航组件：节点 `3:48`。
- 色彩与间距由基础变量和语义变量管理；页面内容、组件均可编辑，不是截图拼接。

Qt 实现采用暖白工程导航、白色工作区、无边框指标、浅色源码区与独立统计页面。
第二轮风格收敛为石墨灰文字与低饱和灰绿色状态提示；去掉大面积蓝色、卡片边框和
统计说明色块，缩短重复提示，保留明确的选中、悬停与键盘焦点状态。
保留六列问题信息、实际工程数据、数字排序、异步分析、源码定位以及 HTML/SARIF/CSV 导出。
源码与问题列表之间可拖动调整大小，统计的工程/语言/文件汇总合并在一个可排序表格中，
避免将设计中的固定示例行硬编码为产品数据。

Figma 字体使用 Noto Sans SC / JetBrains Mono，库按钮使用 Inter；Qt 使用系统中文字体
与系统等宽字体，保证 Windows/macOS 无额外字体安装也能显示。操作系统菜单、字体度量与
真实内容长度导致少量平台差异。Windows 发布包须在 Windows Qt 环境重新编译并验收。

桌面程序支持传入工程目录作为启动参数。`fpga_gui_smoke` 支持环境变量
`FPGA_GUI_TEST_PROJECT` 验证真实项目分析、统计页切换、双击文件和问题定位；
可选 `FPGA_GUI_SCREENSHOT_DIR` 保存实际窗口截图，用于设计对照检查。
