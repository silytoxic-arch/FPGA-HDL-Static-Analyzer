# FPGA HDL Static Analyzer V1.3.98

本版完成 GJB10157.5.1.7 单行端口声明规则的原生核心判据恢复与诊断乘法修正。

## 规则准确性

原生构造函数确认生效入口为 `FUN_18052ae80`。它对同一文件中的端口记录做两两比较，并在物理行号相同时报告后一个记录。因此同一行出现 `N` 个端口会产生 `N*(N-1)/2` 条诊断；端口方向是否重复书写不影响结果。

产品继续使用条件编译后的活动源码和解析器确认的模块端口，但现在保留原生两两比较乘法。详细证据见 [5.1.7 恢复记录](evidence/native_verilog_port_line_5_1_7_findings.md)。
