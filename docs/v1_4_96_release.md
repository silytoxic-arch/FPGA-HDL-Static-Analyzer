# V1.4.96 A-5-31 复位关系图恢复记录

## 新恢复的原生边界

- `FUN_1805f6790` 只检查 `AST_ARCHITECTURE(0x75)` 的直接 `AST_ASSIGN_LE(0x56)` 子节点。
- RHS 只接受直接 `AST_IDENTIFIER(0x13)` 或严格的一元 `AST_BIT_NOT(0x24)`；含点号的选择名被排除。
- 关系存储方向为“赋值目标 → RHS 来源”。
- `FUN_1805f6590` 从语义复位种子沿该方向递归，追溯上游来源；不会从一个复位 RHS 反向标记下游目标。
- 进程、子程序、block 和 generate 中的赋值不进入关系图。

## 产品修正

原实现把简单关系当作双向别名并扫描全文件，可能扩大复位集合。V1.4.96 改为 architecture 直接并发赋值的单向上游图，并保留单实体源码绑定边界。新增测试覆盖：

- 复位 RHS 不向下游目标传播；
- 一元 NOT 从复位目标向上游来源传播；
- 嵌套 block 赋值不参与该关系构造器的传播；源码适配器同时排除进程、子程序和 generate 区域。
