# FPGA HDL Static Analyzer V1.3.85

本版本只推进规则集准确性，不修改表格或其他界面格式。

## GJB9765.4.2.g

完成 `T-Linter.dll` 原生入口 `FUN_1805d2930` 的只读恢复。原生逻辑按同一源文件键收集实体记录，数量严格大于 1 时遍历完整集合，对该文件中的每个实体分别报告“一个文件宜对应一个设计实体”。

产品现已实现相同的有界语义：

- 同一 VHDL 文件存在两个或更多实体时，对每个实体定位报告。
- architecture 不计入实体数量。
- 注释中的 `entity` 不计数。
- 工程内多个文件各含一个实体时不报告。

详细证据见 [原生恢复记录](evidence/native_vhdl_one_entity_per_file_4_2_g_findings.md)。
