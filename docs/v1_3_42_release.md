# FPGA HDL Static Analyzer V1.3.42

本版只推进规则集，没有调整问题列表、代码规模明细或其他表格界面。

- 逆向并接入 `GJB9765.4.6.b.2` 的 VHDL case 选择表达式与 choice 位宽判据。
- 原生比较器只接受可解析的直接简单名 selector；完整包围括号允许，但切片、索引和复杂表达式不进入该规则分支。
- 补齐直接命名常量 choice 的宽度解析，附件违反样例由原先仅命中两个字符串提升为同时命中两个 boolean 常量和两个字符串。
- 未知宽度不猜测；只有 selector 与 choice 两侧宽度都已知且不等时逐 choice 报告。
- 补充命名常量、字符串、等宽、切片/索引排除和逐项定位测试；131 项测试通过，446 个附件样例审计维持 345 个自动匹配和 5 个自动不匹配。
- 核心判断逻辑累计接入 151/209，仍有 58 条需要继续解释；完整原生算法验证仍为 0。
- subtype、枚举、包常量、别名、生成域、重载与完整前端 AST 等价仍未恢复；未检出保持人工复核。
