# V1.2.43 VHDL 运算符空格规则

新增 GJB9765.4.14.c.3 的有界检测：`=`、`/=`、`+`、`-`、`*`、`/` 两侧缺少空白时报告 Warning；`<=`、`:=`、`=>` 和 `**` 不按本条报告。附件的违反与遵循例均匹配，并加入运算符、注释、字符串与幂运算边界测试。原生证据与安全差异见 [恢复记录](evidence/native_vhdl_operator_spacing_4_14_c_3_findings.md)。

公开样例审计为 446 例，Automated 类匹配数由 187 增至 189、失配维持 17。逐条台账现为 209 条中 49 条核心谓词部分接入、160 条待解释、0 条完整等价验证；无告警不代表已证明合规。
