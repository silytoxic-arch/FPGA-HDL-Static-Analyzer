# FPGA HDL Static Analyzer V1.4.230

R-6-3 的简单模块复位名称表扩展到固定打包宽度的数据总线。复位控制与事件仍须
为标量；直接赋值的数据目标可以为向量，运行时 RHS 的已知宽度须与目标一致。
支持 ANSI 端口、普通声明、升序/降序范围和不同宽度目标的组合。未知宽度、
宽度转换及其它未恢复的多边沿过程继续使整张名称表保持未知。

补充时钟过滤、跨过程复位诊断和未知/不匹配宽度边界验证。
原生依据与适配边界见第一百零八轮；第一百零七轮保存模块构造、两类处理入口、
标志初始化及重处理分派的静态证据，仍不擅自定义标志的完整业务含义。

完整综合关系和等式根准入仍未恢复，完整算法等价仍为 0/209。
无诊断继续人工复核。Windows 版本仅在 GitHub Actions 构建并保存，本地不下载。
