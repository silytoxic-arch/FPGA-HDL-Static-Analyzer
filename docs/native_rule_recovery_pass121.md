## 声明与类型链路

Local_parameter_declarationContext 虚表 0x180e0f940 经监听器
0x180e3dd90 的 +0x228/+0x230 进入 FUN_1800e1870/FUN_18010c1c0。
入口构造 AST_LOCALPARAM(10)，初始值占位为 32 位零；退出回调按各声明克隆模板，
再替换初始化表达式。普通 parameter 回调也单独保留，未把其默认值当成可求解值。

FUN_180082fe0 请求 token 0x98。词法字面量数组以 local_1e78 为起点、
std::string 步长为 0x20，`'signed'` 位于 local_b78，索引恰为 0x98。
此 token 存在时，退出回调把声明 +0xa4 设为 1。声明构造器默认该字段为零。
范围访问器返回非空时才另行追加范围节点，只有 signed 不会隐式生成范围。

原生宽度/符号推断对参数标识符读取声明 +0xa4；无范围时物理位宽取初值常量。
随后的标识符替换却克隆初值常量，保留初值节点本身的符号及缓存。
第一百二十轮已确认只有范围归一化路径才覆写该常量的符号。
因此，声明推断类型与替换后的物理常量类型可能不同，不能只存一个符号标志。

算术和移位通过已有推断上下文转换子常量；比较分派则在子节点折叠后重新读取
双方常量的 +0xa4 和实际位宽，再决定共同符号和扩展方式。
原始窗口保留了推断、子节点处理、比较分派和替换路径，避免仅按语言标准猜测。

## 产品接入与验证

内部 Node 保存推断阶段的声明符号，Value 保存物理常量的位向量、符号和诊断缓存。
叶节点克隆保持物理状态，父运算在消费它时才转换；比较分派使用子运算完成后的
物理类型。布尔常量结果保持一位，声明归一化随后执行需要的扩展。
这恢复了上一轮暂未推断的无范围 signed localparam，并修正了普通无类型声明
在算术上下文中的默认标志处理。

例如 `localparam signed P=4'hf;` 的直接常量缓存为 15，`+P` 的新常量缓存
为全 1，而 `P<4'sh0` 使用替换后无符号常量，得到 0。
`localparam P=4'shf;` 的 `P>>>1` 按声明推断上下文得到 7，
直接比较 `P<4'sh0` 却按常量类型得到 1。这些是恢复的原生阶段行为，
并不声称等同于完整 HDL 语言语义。

新增 20 项值/宽度/物理节点类型预期、6 项缓存断言，及两种边沿、比较两侧的规则验证。
