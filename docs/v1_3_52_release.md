# FPGA HDL Static Analyzer V1.3.52

本版本只推进规则集，不包含表格或界面格式调整。

## GJB9765.4.13.c

- 从用户附件 `T-Linter.dll` 的构造函数 `0x1800258a0` 和 vtable slot 0 `0x1805bc5a0` 恢复 VHDL 内部 signal/variable 注释核心判据。
- 对每个声明名称独立检查其所在精确物理行是否含有原始字节标记 `--`。
- 声明前后相邻行的注释不生效；同一行的分组名称共享该行注释。
- 保留原生的非词法字节搜索语义，包括字符串中的 `--` 也会使该行通过。
- 排除实体 port 接口中的显式 `signal` 类，避免与 4.13.b 重复。
