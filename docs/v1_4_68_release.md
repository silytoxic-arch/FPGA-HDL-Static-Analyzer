# V1.4.68 R-13-3 与规则公开编号修正说明

## R-13-3 原生恢复

- 对附件 `T-Linter.dll`（SHA-256 `60e6b52875f4d7c3fbdf494d869b3a4bcc3fdc8ee63d8620ea9614da5d6599b0`）恢复构造函数 `FUN_180024660`、根选择器 `FUN_18058d740` 和执行函数 `FUN_18058d060`。
- 根选择器只接纳类型 4 的 function；执行函数递归收集类型 `0x56` 的 `ASSIGN_LE` 后代，并对每个节点分别报告。
- 原生报告级别是 `Warning`，GB18030 诊断为 `禁止在function语句中使用非阻塞赋值.`；产品输出已与之对齐。
- 增加嵌套多命中、赋值右值关系比较、class method 与 package function 回归。

## 公开规则编号

- GJB10157 保留附件索引中的显式 `R-X-X` / `A-X-X` 映射。
- GJB9765 的 106 条规则改为显式三段数字映射，例如 `4.2.a -> R-2-1`、`4.8.e -> A-8-1`、`4.5.f.2 -> A-5-3`。
- 不再把条款字母和嵌套点号拼成 `R-8-e`、`R-5-f2`。
- 标准正文存在但附件规则入口未收录的条目保留编号空档，例如 `4.11.c -> R-11-3`、`4.14.b.1 -> A-14-3`。
- 两个标准可在各自配置文件中复用同一个公开编号；内部抑制、严重级别覆盖和追溯仍使用完整 GJB 条款号，防止跨标准歧义。
