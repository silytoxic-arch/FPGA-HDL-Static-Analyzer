# FPGA HDL Static Analyzer V1.4.92

本版本只推进规则逆向、判断逻辑和验证，不调整界面或表格布局。

## 本轮规则

- 官方公开编号：`A-2-8`
- 内部标准映射：`GJB10157.5.2.18`
- 主题：冗余端口/内部信号的 cell 方向传播与默认消息分支。

## 原生证据升级

- 构造函数在规则对象 `+0x158` 写入小端字 `0x0001`：默认开启内部信号分支，
  并保持 `+0x159=0`。
- 恢复默认选中的原生消息：`冗余的端口` 和 `冗余的内部信号`。
- 恢复 `FUN_180532db0` 的候选名称—子树标识符交集逻辑。
- 确认可解析 cell 的纯输出 formal 对 actual 建立驱动，输入/inout formal 对
  actual 建立使用；未解析 cell 保守按使用处理。

## 产品接入

- 对同源文件中唯一可解析的子模块支持命名和位置端口方向。
- 子模块输出驱动但父模块未读取的内部信号，现在正确识别为冗余信号。
- 重名或未知子模块不猜测端口方向，继续保守为已连接。
- 新增命名端口、位置端口、输出驱动和未解析上下文边界测试。

## 验证结果

- 自动化测试：`135/135` 通过。
- 规则审计：附件 `209` 条标准规则、`446` 个文档样例均已重新扫描；`435` 个自动匹配、`6` 个工程上下文匹配、`4` 个仍需上下文、`1` 个原产品与文档冲突。
- 已集成源适配器：`21` 条。
- 209 条公开规则编号格式：全部符合官方三段式 `R-X-X / A-X-X`。
- 厂商完整算法等价：`0/209`。
