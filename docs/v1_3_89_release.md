## GJB9765.4.10.i

产品现已接入附件证实的判断边界：

- VHDL 时序进程在时钟沿分支中直接使用实体输入作为同步复位时报告。
- 通过内部第二级信号实施同步复位时不报告。
- 异步复位和普通同步使能不映射到本规则。
- 复杂条件、别名、层次和组件/原语同步器继续要求人工复核。
