## GJB9765.4.1.a

- 从用户附件 `T-Linter.dll` 的构造函数 `0x180026530`、vtable slot 0 `0x180778a50` 和递归助手 `0x180779190` 恢复 VHDL 端口名称关联核心判据。
- 原生算法递归收集关联容器，直接子项类型 `0x8b` 表示允许的具名关联；首个其他类型触发诊断。
- 保留原生诊断重数：同一实例即使包含多个位置关联也只报告一次，多个违规实例分别报告。
- 混合位置/具名映射报告；全部具名映射以及具名 `open` 实参不报告。
