# FPGA HDL Static Analyzer V1.4.94

本版本只推进规则逆向、判断逻辑和验证，不调整界面或表格布局。

## 本轮规则

- 官方公开编号：`A-5-32`
- 内部标准映射：`GJB9765.4.5.g`
- 主题：跨层级信号同名规则的位置端口映射分支。

## 原生证据升级

- 完整重新导出 `FUN_1806bc5c0` 与连接构造器 `FUN_1804d0140`。
- 构造器对 `AST_INSTANCE_ENTITY(0x93)` 和 `AST_INSTANCE_COMPONENT(0x94)` 建立连接记录。
- 类型 `0x8b` 的具名关联从关联节点提取形式端口和实际端名称。
- 直接 `AST_IDENTIFIER(0x13)` 位置实参按关联序号与已解析形式端口配对，并生成相同记录。
- 规则入口对记录两侧非空名称执行不区分大小写的完整比较，每个不一致连接独立报警。

## 产品接入

- 保持官方公开编号 `A-5-32`；内部 clause 只用于证据追踪。
- 原有具名直接标识符映射保持不变。
- 新增已解析本地 component 和同源唯一 entity 的位置映射：按端口声明顺序比较直接标识符实参。
- 新增位置映射违反、大小写一致、表达式及 `open` 排除测试。
- 表达式、外部库、无法唯一绑定、配置和生成层级仍不猜测；无报警继续保持人工复核含义。

## 验证结果

- 完整自动化测试：`135/135` 通过。
- 附件规则审计：`209` 条标准规则、`446` 个文档样例；`435` 个自动匹配、`6` 个工程上下文匹配、`4` 个仍需上下文、`1` 个原产品与文档冲突。
- `A-5-32` 台账状态提升为 `evidence-supported-core-predicate; integrated-source-adapter`。
- 公开编号格式：209 条全部为官方三段式 `R-X-X / A-X-X`。
- 厂商完整算法等价：`0/209`，仍不宣称完成。
