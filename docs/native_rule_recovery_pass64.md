# 第六十四轮：R-3-1 端口实参表达式

本轮只深化规则判断逻辑，不调整界面和表格。软件对外编号继续采用官方三段式 `R-3-1`。

## 新恢复事实

- 虚表选择器只准入 `AST_CELL(0x4f)`，运行入口只检查 cell 的直接 `AST_ARGUMENT(13)`。
- 每个实参独立判断；同一行多个违规实参会输出多条字节相同的诊断，不合并。
- 允许类型精确为 `AST_CONSTANT(16)`、`AST_IDENTIFIER(19)`、`AST_PREFIX(20)`；其他首子节点类型报告 Warning。
- 诊断位置来自实参首子节点物理行，原生记录无列。
- 从 DLL 的 24 个 GB18030 字节恢复固定正文 `端口例化时禁止使用表达式`。

## 产品变更

- 正文改为原生固定文本，定位改为实参物理行第 1 列。
- 为该规则关闭通用相同诊断合并，恢复逐 argument 重数。
- 增加固定正文、Warning、行/列、同一行多实参、位置实参和层次标识符边界测试。

完整宏/include/generate 前端、常量折叠和异常语法恢复仍未知；无告警路径继续要求人工复核。
