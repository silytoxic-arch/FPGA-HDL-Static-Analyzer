# V1.2.46 表格列宽拖动与框体修正

## 修正内容

- “问题列表”和“代码规模明细”不再在鼠标移动期间反复改变列宽与水平滚动范围。
- 按住列标题右侧边界拖动时显示深色指示线；向左移动代表收窄，向右移动代表加宽，松开鼠标后一次性应用新宽度。
- 两张表的标题栏、表头、数据区和空白网格区统一放入连续闭合的 2 像素深色 `QFrame`，移除原先叠加的内外双边框。
- 表格空白区域继续绘制行列网格，未加载结果时也能明确看到表格范围与列边界。

## 验证

- GUI 自动化覆盖左右拖动、横向滚动后的拖动及最右侧滚动位置。
- 新增拖动过程断言：移动期间列宽不变、指示线与鼠标同向，释放后列宽才改变。
- 新增两张表外层 `QFrame::Box` 与 2 像素线宽检查。
- 使用真实 RTL 测试夹具生成“问题列表”和“代码规模明细”截图进行视觉检查。

本版本只修正界面交互与视觉框体，不改变 V1.2.45 已集成的规则判断逻辑及规则等价性声明。
