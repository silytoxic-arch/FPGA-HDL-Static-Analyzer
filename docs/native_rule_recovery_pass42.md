# 第四十二轮：R-14-3 状态机合成 init 关系

本轮按官方三段式编号继续处理 `R-14-3`，不修改表格或界面布局。

## 新恢复事实

- 原生报告器精确查找内部 ASCII 键 `init`；键缺失时以 Warning 输出 `状态机变量<名称>未设置初始状态`。
- `init` 是关系构造器生成的合成键，不是源状态名；状态标签 `INIT` 不能满足规则。
- 显式 `initial`、非状态控制 `if` 的非默认分支，以及非状态控制 `case` 的非 `default` 分支可生成该键。
- 普通 `else/default` 分支只有在另一个尚未完全恢复的依赖标志成立时才可能插入该键，不能单凭其中的复位赋值推定合规。
- 因而原生路径并非复位语义分类：普通 then 分支的 next-state 传递也可能生成 `init`，只有 else 分支复位则不一定生成。

## 产品变更

- 接入同一模块内的显式 initial、非状态 if then 和非状态 case 非 default 三类已证实生产者；
- 支持简单原子和简单三目右值，并跳过候选状态控制 case；
- `R-14-3` 级别修正为 Warning，诊断文本恢复为原生完整格式；
- `R-14-1` 的可达性起点继续使用更保守的状态值证明，避免把所有合成 init 关系误作可达性证明；
- 台账由“部分接入”提升为“原生核心谓词 + 集成源码适配器”，集成适配器由 25 条增至 26 条；完整厂商算法等价仍为 `0/209`。
