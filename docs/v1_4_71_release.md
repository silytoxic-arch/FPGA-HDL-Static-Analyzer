# V1.4.71 R-13-6 原生判断深化说明

## 原生恢复

- 静态恢复 `R-13-6` 的构造函数、`$para_assign` 候选筛选器、执行函数和共享递归位宽入口。
- 原生只接纳名称精确为 `$para_assign` 的阻塞赋值绑定，要求前两个子节点之一含 `$task$`；分别求两端宽度并以整数不等作为违规条件。
- 原生按 `$task$` 所在子节点追加 `，任务输入：<名称>` 或 `，任务输出：<名称>`，严重级为 `Warning`，位置来自绑定节点。
- 精确诊断为 `task语句，输入信号的位宽%d与输出信号的位宽%d不一致%s`，两个宽度保留赋值子节点顺序。

## 产品修正

- task 位宽适配器返回位置、左右宽度、方向与形参名，不再输出缺少上下文的泛化提示。
- 输入绑定输出“形参宽度→实参宽度”，输出绑定输出“实参宽度→形参宽度”，并追加原生方向后缀。
- 新增固定宽度裸 module 端口实参和数值位选择；原有数值片选与同 module 位置绑定继续支持。
- inout 原生 lowering 尚未闭合，因此不猜测其报告数量或方向。

## 验证与边界

- 测试覆盖附件中的两处 4 位到 3 位违规、三处 3 位匹配，以及输入/输出两种精确文案。
- 边界覆盖固定宽度裸实参、1 位选择、未知基名、跨 module 同名 task、inout 排除和参数化未知宽度。
- 完整厂商前端等价尚未声明；legacy task、复杂或命名实参、参数化范围、宏/include、完整类型传播与诊断顺序继续人工复核。
- 未修改表格或界面布局。
