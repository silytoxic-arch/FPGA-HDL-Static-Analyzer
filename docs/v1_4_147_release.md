# FPGA HDL Static Analyzer V1.4.147

本轮继续恢复 `GJB9765 / R-9-1`，软件和报告只显示官方三段式编号 `R-9-1`。

## 原生关系类别

- `FUN_18069ed00` 在调用共享关系生产器 `FUN_1804d56f0` 后，精确遍历有序树的 `[1,2)` 与 `[2,3)` 区间，因此只消费类别 1、2。
- 类别 1 是外层异步控制分支具有可证明静态动作、后续 ELSIF 或 ELSE 链接 IF 找到边沿的关系。
- 类别 2 是主 IF 条件自身或其先序后代包含首个可识别边沿的关系。
- 无边沿的类别 3 和前置动作未证明静态的类别 4 均不会进入 `R-9-1` 的原始时钟集合。
- 产品将 `R-9-2` 已恢复的同一分类器抽取为共享实现，`R-9-1` 再在类别 1/2 集合上执行 V1.4.146 的一跳派生和直接候选判断。

## 新增验证

新增类别 1 正例和类别 4 排除边界：静态复位动作后的 ELSIF 时钟可参与重汇聚；把静态动作替换为动态数据赋值后不报告。既有一跳、后置别名、两级派生、双时钟来源和根类型边界继续回归。层次组件绑定和专有前端异常降低仍保持人工复核，完整厂商算法等价仍未验证。
