# FPGA HDL Static Analyzer V1.3.75

本版继续只处理规则逆向、判断逻辑与验证，未修改表格或界面布局。

## GJB9765.4.10.a

已恢复并接入“寄存器输出经组合逻辑反馈到自身异步复位或置位端”的证据支持核心判断。产品从 VHDL 进程的前置异步条件与复位分支目标出发，沿同一架构内唯一驱动的连续赋值依赖图追溯；路径包含明确组合逻辑且回到同一寄存器时报告。

独立外部复位、来自其他寄存器的控制和无法证明的组件/多个驱动路径不伪判；不确定的清洁结果继续为 `ManualReviewRequired`。详见 [恢复记录](evidence/native_vhdl_async_reset_feedback_4_10_a_findings.md)。
