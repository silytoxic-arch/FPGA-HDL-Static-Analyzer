## 指令证据

FUN_1800d1e40 的反编译把多个字节值误显示为 bool true。本轮读取实际指令：

- `0x1800d20d3` 起用大小写掩码识别 X 与 Z，分别跳转 `0x1800d22c5` 和
  `0x1800d2201`，写入中间标记 0xf0 / 0xf1；`?` 路径写入 0xf2。
- `0x1800d2445` 起，当十进制输入只含一个标记且字节 >=0xf0 时，改为二进制
  位向量路径。混合十进制数字与标记会进入无效字面量报错分支。
- 位展开循环 `0x1800d25e6` 设置 EBX=1、ESI=2、R14D=4。
  `0x1800d25f4` 起，0xf0 转为 2 或 4，0xf1 转为 3 或 4，0xf2 转为 4；
  其它数字按位测试生成 0/1。配置参数可以改变未知状态类型，但这些状态都不等于 1。
- 第九十六轮已恢复的 FUN_1808e3930 仅对字节等于 1 的位设置 +0xbc；因此
  X/Z/? 对该规则读取的整数缓存没有置位贡献，同时保留常量中的确定 1 位。
- 第九十七轮的位宽调整与有符号扩展按位状态复制；复制未知状态同样不会设置
  整数缓存位。已知最高位为 1 时仍需符号扩展，如 `8'shFx` 缓存为 0xfffffff0。

## 接入与验证范围

扩展 R-6-3 字面量缓存解码：二/八/十六进制 X/Z/?、单一十进制未知标记，以及
单 token 的 'x/'z，均保留大小写形式。添加 24 种四态形态，与已有二态矩阵共
