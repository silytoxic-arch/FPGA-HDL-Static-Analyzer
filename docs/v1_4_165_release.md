# FPGA HDL Static Analyzer V1.4.165

## 本轮目标

继续恢复 GJB10157 官方规则 `R-11-6`（内部条款键 `GJB10157.9.2.6`）的分支候选类型、首子节点规则和诊断粒度。本版不调整界面和表格。

## 新恢复的原生行为

- 构造函数 `FUN_180023e60` 注册规则并安装虚表 `0x180ef51c8`。
- 选择器 `FUN_180716130` 接收非空、`+0x183 == 0` 的 `AST_CASE(0x57)`。
- 执行函数 `FUN_180583ca0` 逐个检查 `AST_COND/AST_CONDX/AST_CONDZ(0x58..0x5a)` 分支，但只读取每个分支的第一个子节点。
- 第一子节点为 CONSTANT、REALVALUE、BLOCK 或 DEFAULT 时跳过，其他类型按分支节点输出一条 Warning。
- 同一 item 中逗号后的第二、第三项不参与判断；不同违规 item 各自输出一条。
- 固定原生消息解码为“case语句的分支语句必须使用常量,禁止使用变量或者逻辑运算.”。

## 产品修正与测试

- 旧实现会扫描逗号后的所有选择值；`0, runtime_signal:` 会被过度报告。
- 新实现严格只分析第一项：`0, runtime_signal:` 不报告，`runtime_signal, 0:` 报告一条。
- 两个 item 的第一项均为已证明的运行时对象时输出两条。
- 新增常量在前、变量在前、多分支、拼接内部逗号、三元表达式、嵌套 case、条件预处理等正反例和边界回归。
- 原生常量折叠阶段未恢复，因此未知表达式及无告警结果继续保持 `ManualReviewRequired`。
