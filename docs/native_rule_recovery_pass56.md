本轮按官方索引使用三段式编号 `R-2-4`，内部条款键仅用于实现与证据关联；未调整表格或界面格式。

## 新恢复事实

- 闭合构造函数、虚表、活动入口和六类声明过滤集合。
- 恢复“模块名映射中必须恰好一个模块根”的准入边界。
- 恢复五个固定名称分别经过 C `tolower` 后做等长字节比较，不是前缀或子串判断。
- 恢复每声明节点独立报告、固定 Error、原生无列及 `禁止使用<名称>命名` 精确正文。

## 产品变更

- 重复同名模块组不再产生 `R-2-4` 误报。
- 诊断改用原生正文和第 1 列映射。
- 最终去重阶段为该规则保留原生每节点多重性。
- 增加固定正文、大小写保留、严重度、位置、同名节点、重复模块组、不同唯一模块组及函数后代测试。
- 台账将该规则提升为“证据支持的核心判据；集成源码适配器”。

非 ASCII 区域设置、跨文件重复模块、完整宏/include/generated 前端和专有位置字段生产仍保持 `ManualReviewRequired`。完整证据见 [R-2-4 原生恢复记录](evidence/native_verilog_power_names_5_2_4_findings.md)。
