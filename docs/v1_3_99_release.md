# FPGA HDL Static Analyzer V1.3.99

本版完成 GJB10157.6.2.10“同一 always 只使用一个复位信号”的原生消费者核心恢复，并将证据支持的有界判断接入 Verilog/SystemVerilog 分析。

## 规则准确性

原生入口 `FUN_180557340` 仅在过程分组数大于 1 时逐组检查字节键集合。某组包含值 `1` 时计数一次，第二个合格组出现后立即进入诊断路径，因此每个过程最多报告一次。Yosys 公开枚举中 `State::S1` 与 `SyncType::ST1` 均为 1；产品据此保守映射显式边沿事件和 `if` 复位条件，但不猜测尚未恢复的专有分组生产器。

源码适配器现同时支持 `always` 和 `always_ff`，并验证高有效、低有效、三个复位组只报一次、同一复位名重复边沿不误报，以及条件编译活动分支。详见 [6.2.10 恢复记录](evidence/native_verilog_multiple_reset_6_2_10_findings.md)。

## 当前状态

209 条规则均已有证据支持的原生核心谓词部分接入。完整厂商算法等价验证仍为 0 条；专有数据模型、工程上下文、宏展开、层次传播及配置相关的未知条件继续保留人工复核，不把无告警结果伪判为完整合规。

- 用户 RTL 目录实测：34 个文件、203 个设计单元、34,383 条诊断、0 个分析错误；结果与 V1.3.98 基线一致。
