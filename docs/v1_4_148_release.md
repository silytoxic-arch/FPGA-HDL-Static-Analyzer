# FPGA HDL Static Analyzer V1.4.148

## 本轮变更

- 规则列表、问题列表和 TXT/JSON/SARIF/HTML 报告继续只显示官方三段式公开编号，例如 `R-2-1`；完整 `GJB10157.5.2.1`、`GJB9765.4.8.e` 仅保留为内部兼容与逆向追溯键。
- 209 条公开编号仍采用显式映射，不能根据条款字母或嵌套点号临时拼接；标准正文中未被附件规则集收录的条目继续保留编号空档。
- 增加编译期完整性门禁：公开编号表必须与 209 条规则清单等长，每个编号必须严格匹配 `R-X-X` 或 `A-X-X`。编号缺失、额外分段或非数字分段会使构建失败。
- 运行期目录测试继续逐条验证规则清单覆盖和标准内唯一性，并验证两个标准复用 `R-2-1` 时必须使用标准配置限定消除歧义。

## 证据边界

- GJB10157 扫描版正文及附录 A 直接显示三段式索引；附件 T-Linter 示例文件名提供额外交叉证据。
- GJB9765 扫描版正文逐条标明强制/建议属性，产品按正式条目顺序建立三段式数字索引并保留未收录条目的空档。
- 此变更只加固公开编号契约，不把尚未完全恢复的原生算法声明为等价实现；完整 DLL 算法等价仍为 `0/209`。

## 验证结果

- 完整测试：`135/135` 通过。
- 新打包 CLI 逐条列举：GJB10157 `103` 条、GJB9765 `106` 条，`209/209` 均匹配 `^[RA]-[0-9]+-[0-9]+$`，条款号回退为 `0`。
- 附件回归：`446` 个正反例中 `435` 个自动检测匹配、`6` 个工程上下文匹配、`4` 个保持上下文必需、`1` 个保持原生实现与附件文档冲突标记。
- 新打包应用通过 `codesign --verify --deep --strict`，CLI 与应用版本均为 `1.4.148`。
