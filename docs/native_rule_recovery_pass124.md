## 从源拼写到 AST 的静态闭环

默认词法器 FUN_180138530 的实际 DFA 数据表经离线回放：
`$signed` 接受动作 0x77，返回 token 0x158；`$unsigned` 为 0x78 / 0x159。
翻译表及符号名表分别确认 TOK_TO_SIGNED / TOK_TO_UNSIGNED。
`$clog2` 进入普通名称候选；动作 0x7a/0x7b 在未绑定类型的普通名称路径拼接
反斜杠并返回 TOK_ID。prefix 字节已由第一百二十三轮目标字节窗口证实。
单引号对应 OP_CAST，signed/unsigned 对应类型关键字。

默认 LALR 表离线回放确认：局部参数初始化规则 0x152 为
`single_param_decl_ident '=' expr`，直接替换参数初值子节点。
普通函数 0x288/0x289 生成 AST_FCALL(0x1c)，复制已加前缀的名称及参数；
$signed/$unsigned 的 0x28a/0x28b 分别生成 AST_TO_SIGNED(0x1e) /
AST_TO_UNSIGNED(0x1f)。signed'(expr) / unsigned'(expr) 的 0x2b4/0x2b5
进入相同节点，且原生要求 SystemVerilog 模式；正常导入命令已带 -sv。

因此上一轮因可选 ANTLR 常量入口而保留的 $clog2 初始化限制，不适用于已证明的
默认导入路径。本轮解除该限制，恢复局部参数初始化、别名及复位数据常量证明。
可选 -antlr 入口的归一化仍未完整复现，不声称所有解析器已经等价。

回放脚本只读取目标 PE 数据、模拟 DFA/LALR 表，并使用明确给定的 token 类型；
不运行目标，不执行其语义动作，也不是原工具运行 oracle。
输入目标摘要不符会拒绝回放。源码拼写、接受动作、token 和语义动作窗口分别留档，
不把 token 表命中单独当作完整行为证明。

## 接入和位置

0x1e/0x1f 在无继承上下文下处理参数，再按节点上下文调用普通 resize，
通过 FUN_1808e3a30 创建新常量；物理符号由转换 opcode 固定。
产品接入两种系统函数和两种符号静态转换，清除旧诊断缓存，保留宽度/符号阶段差异。
运行时参数、四态、超宽、未解析调用及尚未恢复的定宽/用户类型转换继续未知。

函数中间动作 0x288 在左括号读入后构造；符号转换在右括号后构造。
产品据此修正拆行调用的位置，新增左括号/右括号行断言。
