# 1.2.3 界面与规则准确性修正版（2026-10-10）

## 界面

- 软件顶部、窗口标题、应用名称统一为 `FPGA HDL Static Analyzer`；其他界面保持中文。
- 代码行数统计六列均可拖动调整宽度，支持横向滚动，分析刷新后保留当前列宽。
- 新 Figma 图标：芯片表示 FPGA，代码括号/源码行表示 RTL，放大镜与检查标记表示分析定位和规则检查。
  PNG 与 macOS ICNS 均嵌入应用；旧图标保留备份。

## 规则修正及验证边界

修复注释/字符串误触发、跨行 X/Z 表达式、casez 漏报、default 分支 X 范围、非阻塞赋值被误当比较、
大小写命名检测顺序、内部信号命名、文件头和代码行宽处理。普通 `wait` 不再一概映射成不可综合违规。

附件 GJB9765.4.9.e 的说明/示例与既有条款目录出现语义差异，暂改为人工核对，防止把 CDC 诊断错误归类。
附件旧工具的非整数 generic 反例也未泛化成所有 FPGA 综合工具的硬错误。

99/99 CTest 和 89/89 CLI 回归通过。附件逐规则台账覆盖 544 条标识（537 个随包说明页，加 7 条无说明规则），
其中 209 条 GJB 的 446 个文档正反例已经运行。具有自动检测器的 172 个例子中 150 个吻合、22 个仍存在差异。
该结果不是完整规则符合性认证；未实现规则和未恢复的厂商内部算法仍明确待复核。

详见 [逐规则证据与测试台账](t_linter_rule_audit.md) 和 `evidence/t_linter_after_1_2_3.json`。

复核补充：GJB10157.5.1.1 的一个“正确”示例作者为空，另一“错误”示例同样以作者为空作为违反依据，
附件判据存在矛盾；未为追平示例通过率放宽空作者检查。
代码审查还提示 based literal 空白、拼接表达式中的 X/Z 传播、非 case 的 default 语境、
头部字段子串匹配等边界需要追加探针；当前未宣称这些边界已验证或厂商算法已恢复。

## 使用

关闭旧版，解压 ZIP 后双击 `fpga_analyzer.app`。当前软件包为 Apple Silicon macOS，ad-hoc 签名，未公证。
Windows 原生二进制仍需 Windows 编译，本包不是 Windows EXE。
