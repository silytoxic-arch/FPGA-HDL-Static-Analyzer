## GJB9765.4.14.c.3 原生逐字节判据修正

DLL 静态证据确认该规则按 `fgets(..., 0xff, ...)` 读取的原始文本扫描，而不是按
VHDL 词法 token 判断。V1.4.20 已接入证据支持的核心逻辑：

- 识别 `/=` 和单个 `+`、`-`、`*`、`/`、`=`；
- 排除 `<=`、`:=`、`=>`、`**` 和原生特殊分支排除的 `/=>`；
- `=` 前一字节排除位图精确还原为 `/`、`:`、`<`；
- 在首个字面 `--` 处停止当前行扫描，包括字符串内的 `--`；
- 字符串中的运算符也参与检查；
- 只有运算符紧邻两侧均为 ASCII 空格或 Tab 才视为满足本条。

新增复合运算符、字符串、字符串内双连字符、Tab、form-feed 和异常 `/=>` 边界测试。
原生 254 字节读取块、第二字节边界保护、重复源记录和完整诊断排序仍缺少运行态验证，
因此无告警继续保持 `ManualReviewRequired`，不宣称完整算法等价。证据见
[4.14.c.3 逆向记录](evidence/native_vhdl_operator_spacing_4_14_c_3_findings.md)。
