## GJB9765.4.9.e

依据附件 `T-Linter.dll` 的入口与辅助函数静态反编译，4.9.e 将组合表达式赋值目标与已识别时钟关系求交。产品在 VHDL 设计单元中追踪明确的时钟赋值依赖，识别逻辑、反相、移位、算术及条件选择形成的时钟；不将纯标识符别名或普通数据逻辑误认作违规。它与 4.9.c“门控时钟”分别输出；完整原生 AST 类型与跨层级语义尚未恢复。详见 [恢复记录](evidence/native_vhdl_combinational_clock_4_9_e_findings.md)。
