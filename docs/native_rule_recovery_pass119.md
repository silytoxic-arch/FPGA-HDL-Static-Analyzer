## 原生链路

第九十四轮的表达式监听器以 AST 0x48 构造条件节点，三个子节点依次为条件、
真分支、假分支，+0x210 写入表达式起始 token 的行号。
FUN_1808f46c0 对 0x48 分别递归两个结果分支，累积结果宽度和符号信息，
不把条件宽度用于结果宽度。

FUN_18090c960 扫描条件的整个位向量：有状态 1 时选择真分支；全部为确定零时
选择假分支；没有确定 1 且有未知状态时不返回唯一分支。这里检查的是整个位向量，
不能使用诊断专用的低 32 位缓存来代替条件真值。

简化器 0x48 分支使用上述选择结果。条件不能唯一确定而两个分支均为整数常量时，
先按公共宽度/符号转换，再逐位保留相同状态、把不同状态写成 2。
存在唯一选择且所选分支为整数常量时，按整个表达式的宽度/符号转换后构建常量。
共用替换尾部保留原条件节点的源位置；完整尾部见第一百一十三轮证据。

## 产品接入

两态 1 至 64 位模型新增右结合条件表达式，条件独立求值并检查全部位；
两个结果分支共同决定自然位宽/符号，外层上下文再传播到选中的分支。
未选中分支仍须可解析类型，但不以其数值计算错误污染已确定的选中结果。
例如 `1 ? 8'h1 : 4'h0/4'h0` 为确定值 1。

原生 R-6-3 只接受特定 AST 根节点。`RST == 1 ? 0 : 1`、`RST == 1 && 0`
等表达式的根不是相等比较；新增求值能力不能把其后半段当成独立常量来报告。
产品因此按优先级确认比较根，区分一元归约与二元位运算；同级相等运算按左结合
选取最后的比较根，使 `1 == 0 == RST` 的常量子比较可先被折叠。
这里结合已恢复的监听器节点映射和原生准入谓词实现；并未声称恢复整个解析器。

新增 20 项自然位宽/值交叉检查，以及双向比较、两种边沿、源行、根优先级和
复位名称表测试。独立 Icarus 检查累计 106 项，104 项一致，另 2 项仍为既有
大十进制位宽差异。有符号低 32 位缓存另由 C++ 固定预期验证。

四态条件/分支、运行时条件、未恢复或可覆盖参数、超宽及完整前端变换仍有未知。
本轮不实现四态逐位合并，不将未知路径判为合规。完整算法验证保持 0/209。
