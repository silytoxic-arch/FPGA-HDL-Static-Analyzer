# V1.4.70 官方规则编号与 R-13-5 原生判断深化说明

## 官方三段式编号

- GJB9765 与 GJB10157 的用户可见规则编号统一为官方三段式 `R-X-X` / `A-X-X`，例如 `GJB9765.4.2.a → R-2-1`。
- 强制准则使用 `R`，建议准则使用 `A`；末两段只使用数字，不再显示条款字母、嵌套点号或四段式编号。
- 209 条规则使用显式映射；附件规则入口未收录的正式条目保留序号空档。
- GUI 问题列表、CLI、TXT、JSON、SARIF 与 HTML 报告均显示公开编号；完整 GJB 条款号仅作为内部兼容键，并在结构化报告的 `clauseId` 中保留。
- 两个标准可能各自存在同名的 `R-2-1`，因此公开编号解析按标准配置限定；旧条款号配置仍可继续使用。

## R-13-5 原生恢复

- 静态恢复 `GJB10157.9.4.5` 的构造函数、候选筛选器、执行函数和递归位宽入口。
- 原生规则筛选 function 返回结果赋值，分别推断赋值左右子节点位宽，以整数不等为违规条件，严重级为 `Warning`。
- 原生诊断精确为 `在function语句中，返回值的位宽%d与输入信号的位宽%d不一致`。
- 产品现输出双方实际位宽，并覆盖返回值窄于或宽于已知输入表达式的两个方向。

## 验证与边界

- 官方编号测试验证全部 209 条规则均为三段纯数字形式，且在各自标准配置内唯一；旧条款号与标准限定查询均可解析。
- R-13-5 测试验证 `1 → 4` 与 `8 → 4` 两个方向的精确原生文案及 Warning 级别。
- 完整厂商前端等价尚未声明；参数化范围、复杂表达式、宏/include、内部名称生成与完整类型传播继续保持人工复核边界。
- 未修改表格或界面布局。
