# V1.4.127 A-9-1 组合时钟的 RHS 根节点边界

本版本只推进规则逆向、判断逻辑和验证，不调整界面或表格布局。对外规则编号继续严格采用官方三段式 `R-X-X` / `A-X-X`。

## 原生证据闭环

- `FUN_18060a000` 建立时钟关系，并通过 `FUN_18060ae10` 将赋值目标与时钟关系名称求交。
- `FUN_1804d3050` 对直接赋值检查的是 RHS 根节点类型，而不是表达式任意后代是否含某个运算符。
- 原生根集合包含二元 `AST_ADD/AST_SUB/AST_MUL/AST_DIV`（`0x3c..0x3f`），不包含一元 `AST_POS/AST_NEG`（`0x43/0x44`）。
- 因此根二元 `clk + en` 属于该分支，根一元 `-clk` 与函数调用根 `wrap(clk + en)` 不属于该分支。

证据：原生入口伪代码 `ev_2614f6621bf4803ebbf8c32cf6c0e058febc1c3f5c5b373ecb8376bd87e1075a`，恢复记录 `docs/evidence/native_vhdl_combinational_clock_4_9_e_findings.md`；附件 DLL SHA-256 为 `60e6b52875f4d7c3fbdf494d869b3a4bcc3fdc8ee63d8620ea9614da5d6599b0`。

## 产品修正

- 去除包围整个 RHS 的外层括号后，只在根层识别逻辑、反相、移位、二元算术和条件选择运算。
- 根位置的一元 `+/-` 不再被二元算术集合误收。
- 函数调用参数内部的运算符不再越过调用根触发本规则。
- 仍只沿解析器确认的 VHDL 时钟及同架构直接赋值依赖反向追踪。

## 新增验证

- 合法重载一元 `-` 的 `derived_clk <= -clk_in`：0 条 `A-9-1`。
- 合法重载二元 `+` 的 `derived_clk <= clk_in + en_in`：1 条 `A-9-1`。
- `derived_clk <= wrap(clk_in + en_in)`：0 条 `A-9-1`，证明嵌套运算不冒充 RHS 根。
