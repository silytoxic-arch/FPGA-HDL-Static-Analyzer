# FPGA HDL Static Analyzer V1.4.86

本版本只推进规则逆向、诊断还原与验证，不调整界面和表格布局。

## 本轮规则

- 官方公开编号：`A-2-5`
- 内部标准映射：`GJB10157.5.2.15`
- 主题：参数、localparam 与变量命名大小写。

## 准确性修正

- 将规则严重级别由旧目录中的 Warning 修正为原生五条输出路径固定使用的 Error。
- 参数/localparam 消息还原为 `<名称>:建议常量的命名中字母全部采用大写`。
- 默认 wire 类消息还原为 `<名称>:建议变量的命名中字母全部采用小写或者仅首字母大写`。
- 使用声明物理行和第 1 列，匹配原生未携带列号的定位记录。
- 同一物理行多个违规声明逐节点保留，不由全局诊断去重合并。
- 条件编译活动分支与固定配置位 `0/1/1` 的既有边界保持不变。

## 验证结果

- 自动化测试：`135/135` 通过。
- 规则审计：446 个示例；435 个自动化匹配、6 个工程上下文匹配、4 个需上下文、1 个原生文档冲突，相对 V1.4.85 基线稳定。
- 已集成源适配器：`17` 条。
- 209 条公开规则编号格式：全部通过 `R-X-X` / `A-X-X` 三段式校验。
- 厂商完整算法等价：`0/209`，未恢复的前端与工程上下文不判合规。
