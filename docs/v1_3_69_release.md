## GJB9765.4.9.j

原生 slot 0 先构建并传播时钟路径关系。直接赋值辅助函数只接受 RHS 根节点为两个特定单目类型之一、恰有一个子节点且该节点为标识符；附件错误例证明该分支覆盖 `clock_1 <= not clk`。产品从解析器确认的 VHDL 时钟反向追踪直接赋值，并仅对去除源码括号后严格为 `not <标识符>` 的可达驱动报告。普通别名、其他组合逻辑和未作为时钟使用的数据逻辑不报告。

原生 component 缓冲器路径涉及库、实例和层级解析，尚未可靠恢复，未判为合规。详见 [恢复记录](evidence/native_vhdl_clock_path_inverter_4_9_j_findings.md)。
