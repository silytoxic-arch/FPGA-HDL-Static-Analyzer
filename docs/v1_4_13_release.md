# FPGA HDL Static Analyzer V1.4.13

本版继续只处理规则集，不调整界面。

## GJB10157 名称形态规则条件编译修正

修正以下四条共享原生 AST 声明边界的规则：

- `GJB10157.5.2.1`：名称以数字或下划线开头；
- `GJB10157.5.2.2`：名称含连续下划线或以下划线结尾；
- `GJB10157.5.2.4`：名称精确命中电源保留名称；
- `GJB10157.5.2.12`：名称字节长度不在闭区间 2..32。

产品此前对原始 token 运行名称适配器，并跳过整个条件编译块，导致活动宏分支内的确定违规
漏检。本版改为使用工程 `defines` 成功预处理后的活动声明：活动分支正常报告，非活动分支
不误报，诊断行列保留原始物理位置；预处理失败时不猜测声明集合。

新增四条规则的活动分支正例、非活动分支反例和逐条源位置测试。完整厂商宏/include/generate
展开、转义标识符及错误恢复仍未恢复，无告警继续保持人工复核。
