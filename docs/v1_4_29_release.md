## GJB10157.8.1 比较操作数位宽

对附件 `T-Linter.dll` 的指令级静态复核确认，两侧调用
`FUN_1808f4650` 前均把 Windows x64 第五参数栈槽写为 0。因此本规则的嵌套
表达式必须使用通用 helper 的 flag-zero 路径：

- 嵌套 ADD/SUB/MUL/DIV/MOD 取子节点最大宽度；
- POW、单目正号和负号传播第一个子节点宽度；
- CONCAT 对子项宽度求和，REPLICATE 用静态次数乘内容宽度；
- 两侧最终推断宽度不相等时报告。

产品现支持上述有界静态表达式，并补齐原生证明的 `AST_ALWAYS` 和连续
`AST_ASSIGN` 根：比较节点位于 if/while/for、条件表达式，或直接作为连续/过程
赋值 RHS 时均可检查。声明初始化不会伪装成原生 `AST_ASSIGN` 根。

新增回归覆盖嵌套加法、乘法、幂、单目符号、拼接、连续赋值、过程赋值和声明
初始化边界。其他 AST 运算符、函数、动态选择、未解析参数、宏/生成展开、实例
覆盖和精确诊断顺序/重数仍保持人工复核。
