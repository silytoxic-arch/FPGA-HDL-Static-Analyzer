# 第七十三轮：A-4-3 门控时钟

本轮只深化规则判断逻辑，不调整界面和表格。软件对外编号继续采用官方三段式 `A-4-3`。

## 新恢复事实

- 恢复构造函数、最终虚表、模块选择器及连续/过程赋值三类 AST 候选。
- 确认两个固定运算符集合覆盖二元逻辑、条件选择和二元位运算，一元反相不属于本条。
- 原生对每个命中赋值独立报告，不按信号名或物理行合并。
- 恢复构造模式零对应的精确正文 `避免使用时钟门控.`、`Warning`、赋值物理行和
  无列语义。
- 附件第 31 行标记与“在门控赋值处报告”一致。

## 产品变更

- 输出改为原生固定正文，并使用第 1 列表示原生无列定位。
- 去重粒度改为赋值对象；不同赋值即使位于同一物理行，也保留各自告警。
- 通用结果去重为 `A-4-3` 和 `A-4-1` 保留原生对象/端点重数。
- 增加精确正文与位置、同一行两个门控赋值，以及同一行双边沿端点回归测试。

完整时钟关系集合生产、跨层次传播、库原语、宏和 generate 仍保持人工复核。
