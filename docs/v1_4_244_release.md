# FPGA HDL Static Analyzer V1.4.244

按实际 VHDL 语法节点校准 A-8-1 空语句规则：

- 恢复初始化、条件、聚合及局部子程序中的 NULL 字面值，包含 process 声明区。
- 修正跨行标签、postponed 和空进程的起点；完整结束符关闭进程检测范围。
- 移除空 CASE、LOOP、普通 ELSE 被错误当作空 BLOCK 的源码外观推断。
- 初始 IF 空真分支使用条件起点；空 ELSIF 真分支保留原生未知行 0。
- 未知行在界面显示“行号待确认”，SARIF 保留文件级诊断，避免制造第一行定位。
- 同一位置的多个真实命中仍分别报告，固定正文和 Warning 保持原生字段。
