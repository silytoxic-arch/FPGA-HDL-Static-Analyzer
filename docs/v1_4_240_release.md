# FPGA HDL Static Analyzer V1.4.240

R-6-3 常量模型新增未定宽二态填充值 `'0` / `'1`，区分原工具常量折叠
所用的普通宽度转换与后续 RTL 生成的填充扩展。过程生成先克隆 AST，
复位规则读取保留的简化 AST，因此原生诊断结果可能与标准仿真结果不同。
原始静态证据和边界见 [第一百二十二轮](native_rule_recovery_pass122.md)。

后者分别覆盖两种边沿及等号两侧。独立 Icarus 检查累计 172 项：
144 项位宽/值匹配，28 项精确差异单独记录（10 项字面量、6 项类型阶段、
12 项填充阶段）；差异不计作匹配，也不构成原工具运行等价验证。

本地源码 Release 构建及 134/134 项 CTest 通过。附件 446 个示例保持
434 项自动匹配、6 项工程上下文匹配、4 项需上下文、2 项既有原文冲突，
无新增未解释回退。

四态填充值运算、未恢复转换及完整工程语义继续保留未知；无诊断保持人工复核。

本地不生成或下载安装包。
