## GJB9765.4.9.a

原生入口和递归路径计数辅助函数已经恢复。厂商逻辑从时钟关系出发传播赋值依赖，候选必须是逻辑、移位/旋转、逻辑非或条件表达式根；当相关时钟路径标识符叶节点命中数严格大于 1 时报告再汇聚。

产品在同一 VHDL 架构内反向展开唯一直接驱动图，只在同一已确认时钟源经至少两条路径到达一个实际作为时钟使用的候选根时报告。普通输出端终止、单路径和无法解析的组件路径不伪判；后两类清洁结果继续为 `ManualReviewRequired`。详见 [恢复记录](evidence/native_vhdl_clock_reconvergence_4_9_a_findings.md)。
