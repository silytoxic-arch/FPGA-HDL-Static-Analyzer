# FPGA HDL Static Analyzer V1.4.146

本轮继续恢复 `GJB9765 / R-9-1`（附件内部名称 `GJB9765.4.9.a`）。软件和报告只显示官方三段式编号 `R-9-1`。

## 新恢复的原生容器语义

- `FUN_18069ed00` 的第一次 `FUN_18069fb50` 调用固定查询原始时钟关系名称集合。赋值目标不在原始集合、但 RHS 至少包含一个原始时钟名称时，只把该目标加入第二个“派生名称”集合。
- 赋值目标本身已经属于原始时钟关系时，该赋值直接进入最终候选向量，不再把目标加入第二个集合。
- 最终候选的第二次辅助函数调用只对第二个集合计数，匹配叶节点数大于 1 才报告。两个匹配名称不必追溯到同一个时钟源。
- 第二个集合不会回灌到原始集合，因此原生关系构造是一跳的，不是任意深度的依赖图递归。
- 汇聚表达式后再接裸别名时，裸别名才是直接时钟候选；其 RHS 根不满足最终掩码，所以不会把更早的汇聚表达式提升为告警候选。

## 产品修正与验证

产品移除了此前的唯一驱动递归和“同一源”分组，改为两个名称集合和直接候选判断。新增边界验证覆盖：标准一跳双路径正例、汇聚后别名排除、两级派生排除、两个不同已识别时钟关系的叶节点计数，以及移位根排除。层次、组件关系类别和专有前端错误恢复仍保持人工复核，完整原生等价仍未验证。
