# FPGA HDL Static Analyzer V1.4.89

本版本只推进规则逆向、判断逻辑和验证，不调整界面或表格布局。

## 本轮规则

- 官方公开编号：`A-2-1`
- 内部标准映射：`GJB10157.5.2.11`
- 主题：Verilog 模块名与源文件名一致性。

## 准确性修正

- 从 DLL 恢复每模块遍历、Windows/POSIX 路径统一、最后点提取和转义模块名规范化。
- 覆盖多点文件名、无扩展名和前导点文件边界。
- 还原大小写敏感的字节比较、完整原生消息、Warning 严重度和行定位。
- 将该规则提升为证据支持的源适配器。
- 宏生成、异常解析和同名重复根仍未知时继续人工复核。
