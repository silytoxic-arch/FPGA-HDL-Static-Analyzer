# FPGA HDL Static Analyzer V1.4.93

本版本只推进规则逆向、判断逻辑和验证，不调整界面或表格布局。

## 本轮规则

- 官方公开编号：`A-5-31`
- 内部标准映射：`GJB9765.4.5.f.30`
- 主题：VHDL 复位信号 `rst` 命名规则的配置链边界。

## 原生证据升级

- 基类构造函数把规则对象 `+0xc0` 等四个命名字符串初始化为空，本规则构造函数不写入 `+0xc0`。
- 恢复导出函数 `setRuleNameConvention` 及其四字符串写入辅助函数，确认规则入口从 `+0xc0` 读取比较词。
- 随附 `runCheck.exe` 虽把 `VLR-200055` 映射到本规则，但配置分发函数没有为它调用命名配置写入口。
- 随附 `.lprp` 仅保存本规则启用状态和严重级，没有命名词参数。
- 因此 `rst` 是附件规则文字和正反例确定的产品规则词，不宣称为已经恢复的 DLL 对象默认值。

## 产品接入

- 保持官方公开编号 `A-5-31`；内部 clause 只用于证据追踪。
- 复位相关名称继续要求以不区分大小写的 `rst` 开始，非复位候选不得包含 `rst`。
- 新增独立边界回归：`reset_main` 被识别为复位时仍报警，防止把 `reset` 擅自扩展为 `rst` 的同义前缀。
- 未发现原生绑定值时继续保留未知边界，不把无报警结果判定为完整原生合规。

## 验证结果

- 自动化测试：`135/135` 通过。
- 规则审计：附件 `209` 条标准规则、`446` 个文档样例重新扫描；`435` 个自动匹配、`6` 个工程上下文匹配、`4` 个仍需上下文、`1` 个原产品与文档冲突。
- 209 条公开规则编号格式：全部符合官方三段式 `R-X-X / A-X-X`。
- 厂商完整算法等价：`0/209`。
