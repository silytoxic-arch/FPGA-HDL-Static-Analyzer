# 第七十轮：R-4-2 时钟作为输入数据

本轮只深化规则判断逻辑，不调整界面和表格。软件对外编号继续采用官方三段式 `R-4-2`。

## 新恢复事实

- 恢复构造函数模式字节、边沿过程选择器、赋值收集和 RHS 根节点比较路径。
- 原生只比较直接 RHS 根名称，不递归检查条件或复合表达式。
- 恢复正文 `时钟<名称>驱动非时钟引脚.`、`Warning`、RHS 物理行和无列语义。
- 每个匹配赋值独立报告。
- 附件黑盒数据端口说明与 DLL 实现冲突：页面只标记直接赋值，主函数没有单元端口路径。

## 产品变更

- 将宽泛的“时序过程全部读取集合”收紧为直接 RHS 根节点判据。
- 恢复原生正文、RHS 行、第 1 列占位和逐赋值重数。
- 增加条件读取、复合 RHS、黑盒端口和同一过程多赋值边界测试。

完整时钟关系生成、别名、层次和生成结构仍保持人工复核。
