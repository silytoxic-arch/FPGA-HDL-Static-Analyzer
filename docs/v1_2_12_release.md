# V1.2.12 持续逆向检查点

GJB10157.5.2.5的最终虚表入口已由构造函数汇编和表原字节交叉确认。
该入口按一个完整字符串键分组模块对象，每个加入的声明各占一个条目；
同组条目超过一个时报警。相同名称的两个模块仍是两个条目。
软件原有的同文件模块计数与这一核心谓词方向一致，本轮增加相同名、不同名及单模块正反例。
原生对象排除位、分组字符串来源及宏/包含/生成处理仍未确认，因此仅记作部分接入。
证据详见 [第十轮记录](native_rule_recovery_pass10.md)。

先前可执行检测器未报警时，部分规则仍输出 `no-violation-found`，
尽管其原生算法尚未完整恢复。现将此类规则统一输出 `manual-review-required`；
已检出的违规仍输出 `violated`，需要明确工程配置的规则继续输出
`project-context-required`。这使评估状态与逐规则台账中“完整算法等价验证0条”一致。

209条规则中24条核心谓词部分接入、2条模型谓词观察到但未接入，
其余185条核心谓词仍需解释；完整算法等价验证0条。
这不是209条规则全部恢复的最终版。
