# 第五十九轮：R-2-8 禁止的数据类型

本轮按官方索引使用三段式编号 `R-2-8`，内部条款键仅用于实现与证据关联；未调整表格或界面格式。

## 新恢复事实

- 闭合构造函数与活动入口，确认遍历模块记录中的直接子对象。
- 恢复十三类 wire 标志、`localparam` 无条件报警与普通 `parameter` 明确跳过。
- 恢复逐对象重数、固定 Error、对象物理行及原生无列定位。
- 从 PE 字节逐地址恢复 wire 分支和 localparam 分支的精确 GB18030 正文。

## 产品变更

- `R-2-8` 改用精确原生正文，并将无列定位稳定映射为第 1 列。
- 增加两类正文、严重度、行列以及既有十三类/作用域边界回归。
- 台账将该规则提升为“证据支持的核心判据；集成源码适配器”。

完整专有前端降低仍未恢复，因此完整原生等价保持为零；未证明的无报警路径继续人工复核。完整证据见 [R-2-8 原生恢复记录](evidence/native_parameter_types_5_2_8_findings.md)。
