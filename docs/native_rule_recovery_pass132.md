## 移植及来源恢复

使用 ISC 许可的对应源码，保留原版权/许可，增加独立主机桥接，不依赖目标 DLL 或
Yosys 内核。支持对象/函数宏、默认值、嵌套实参、拼接、字符串展开、续行、条件编译及
递归 include。完整调用串行保护共享 token 队列，失败路径也清空队列；增加资源边界及
UTF-8 文件访问。移植补丁和 [上游说明](../src/parser/vendor/UPSTREAM.md) 一并保存。

按照对应词法器处理 file_push、file_pop 和 line 指令，恢复文件/行计数。
多行实参在展开体发出前已经推进计数，因此采用词法器实际计数，不猜成宏定义行或
第一个实参行。精确宏物理列/字节偏移尚未恢复，相关命名规则保留无列缺省值 1。
line 指令可能给出虚拟文件/行，它不保证磁盘上存在同名文件。

原有位置保持预处理器补齐工作目录优先 include 查找、注释内指令排除及宏文件名验证。
展开失败不被当成成功的 AST 输入；物理源码型规则继续读取原输入。

## 已接入规则及有意的定位差异

R-2-1、R-2-2、R-2-4、R-2-6、A-2-2、A-2-5 使用展开输入。
分别保留原选择器、唯一 module 门控、分支优先级、固定消息/严重性、默认阈值与逐节点次数。
关键字、时钟/复位关系、文件命名等还有工程结构依赖，继续核验后接入，未静默切换。

**定位是明确的平台改进，不计作厂商报告全等。** 已恢复的多个原生命名入口采用所属
module 的文件路径，再带候选行号。平台使用选中声明的词法来源：在 include 中声明的
对象定位到该文件；受 line 指令影响时使用该声明的逻辑位置。原生路径行为仍在各规则
台账中保留，不把新增测试称为目标运行 oracle。
