# 第七十一轮：R-4-3 组合逻辑输出作为时钟

本轮只深化规则判断逻辑，不调整界面和表格。软件对外编号继续采用官方三段式 `R-4-3`。

## 新恢复事实

- 恢复构造函数、准入过滤器和主判断函数。
- 连续赋值只在 RHS 根节点不是直接标识符时进入候选；无边沿组合过程中的阻塞、
  非阻塞赋值均可进入候选。
- 候选目标必须匹配展开后的时钟关系。
- 原生以归一化目标名称为键保存候选，因此同名多个驱动只保留首项并报告一次。
- 恢复精确正文 `禁止将组合逻辑的输出<名称>作为时钟信号`、`Warning`、首个驱动
  物理行和无列语义。

## 产品变更

- 将报告重数从“目标名称与行”收紧为“目标名称”，恢复同名驱动去重。
- 恢复原生正文、首个驱动行和第 1 列占位。
- 增加精确正文与位置、直接别名、反相、算术表达式、组合过程、时序过程和重复
  驱动边界测试。

完整展开时钟关系、跨层次别名、生成结构和特殊名称仍保持人工复核。
