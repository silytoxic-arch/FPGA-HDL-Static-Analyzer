# 第一百零六轮：AstModule 派生快照修正

同一目标映像，静态分析未执行目标。原始 RTTI 虚表和函数摘录位于
`reverse-tools/evidence/t_linter_pass106/`。

第一百轮曾恢复 RTLIL::Module 基类的 +0x58 克隆入口 FUN_1809b7fd0。这个入口
不能单独证明所有模块对象的动态调用都落到基类。

本轮确认 AST::AstModule 实际虚表 0x180f4ebc8 的 +0x58 覆盖为 FUN_1808db820。
该函数分配派生对象，调用相同的模块内容复制 FUN_1809b8500，再复制/克隆
+0x2d8、+0x2e0 的 AST 字段及 +0x2e8 至 +0x2f3 标志。准备代码读取 +0x2f3
时，需要保留这个派生对象边界，不能把它解释成普通 Module 的某个字段。
标志的完整业务含义仍未恢复，不能擅自称为“综合失败标志”。

同时跟进 genRTLIL 的共同二元节点生成函数 FUN_1808f2de0：它构建节点参数及
A/B/Y 连接。等式 ID 由 FUN_1808eef50 提供；尚不能由此跳过完整控制降低过程。
本轮修正证据解释，不声称不同动态模块类别已全部等价复现。
