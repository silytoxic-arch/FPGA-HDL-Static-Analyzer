## GJB9765.4.10.k

已恢复并接入“组合逻辑产生的复位信号应同步处理”的证据支持核心判断。产品从 VHDL 进程的前置异步条件出发，沿同一架构内唯一驱动的并发赋值图追溯；直接或经名称别名到达明确组合运算根时报告。

两级时序同步后的复位信号、独立外部复位和无法证明的组件/多个驱动路径不伪判；不确定的清洁结果继续为 `ManualReviewRequired`。详见 [恢复记录](evidence/native_vhdl_combinational_reset_sync_4_10_k_findings.md)。
