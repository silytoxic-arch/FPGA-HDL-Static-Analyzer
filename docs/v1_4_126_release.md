## 原生证据闭环

- `FUN_180796d70` 递归调用 `FUN_1807981c0`，检查架构直接子节点中的三态控制信号和组合赋值目标。
- 原生组合根集合包含 `0x3c..0x3f`；相邻原生分支已交叉确认它们是二元 `AST_ADD/AST_SUB/AST_MUL/AST_DIV`。
- 一元 `AST_POS/AST_NEG` 是 `0x43/0x44`，不在 `A-6-2` 的组合根掩码中。
- 因此 `logic_en <= a + b` 属于恢复出的组合使能来源，而 `logic_en <= -a` 不应因源文本中出现减号而被纳入。

证据：原生入口伪代码 `ev_4d22f40c42455c53fa232188a5a2c4d569699d4f481a7e79bbacdbe8c2e13f6e`，恢复记录 `docs/evidence/native_vhdl_combinational_tristate_enable_4_6_i_findings.md`；附件 DLL SHA-256 为 `60e6b52875f4d7c3fbdf494d869b3a4bcc3fdc8ee63d8620ea9614da5d6599b0`。

## 产品修正

- 组合根扫描在剥除外层括号后，区分位于表达式开头的一元 `+/-` 与两个操作数之间的二元 `+/-`。
- 根位置一元 `+/-` 不再触发本规则；二元 `+/-`、乘除、逻辑及条件根保持原判断。
- 该修正只收窄有原生类型证据支持的误报边界，不扩张未知层级或进程语义。

## 新增验证

- 两个样例均为合法 `numeric_std.signed` VHDL，避免用语法歧义替代规则边界。
