## 已复现缺陷

头文件定义 FROM_HEADER，根文件随后 ifdef 选择 active_owner，第 3 行含 bad__。
V1.4.252 展开命名检查正确命中 R-2-2，但物理结构仍错误选择第 5 行 inactive_owner。
显式指定 active_owner 时，旧顶层门控返回“指定的顶层设计不存在”，退出码 2，并跳过命名规则。
修正后结构选中第 3 行 active_owner，无顶层错误，R-2-2 仍定位第 3 行；退出码 1 仅表示存在 lint 问题。
输入和有界前后结果保存在 `reverse-tools/evidence/t_linter_pass135/repro/`。

## 接入逻辑和证据边界

保留的展开逻辑在 ifdef/ifndef/elsif/else/endif 五类出口记录输出游标及分支处理后的活动状态，
不向 HDL 流添加标记，也不重算其宏判据。原判断、缓存、词法消费及 emitted HDL 不变。

来源恢复维护与逻辑 line 指令分离的物理文件/行栈；file_push/file_pop 保存和恢复父文件，
line 只重定向逻辑报告位置。观察记录据其输出位置绑定回根文件的物理条件指令，投影使用
该活动状态，解决 include 定义或取消宏、嵌套条件、elsif 和非活动 include 的分支一致性问题。
不从“展开输出上有无普通 token”推断活动行，也不把逻辑行号当作物理行号。

宏生成条件指令、同一物理行的多个控制出口或无法唯一绑定的根条件保持未证明：物理投影清空
可解析内容并输出中文复核诊断。展开后的命名检查可独立使用已证明的展开输入；不猜测物理结构。
这不是厂商所有错误恢复或生成结构算法的复现。

九个标准工程预处理入口改为复用 Analyzer 的同一导入结果：向量逻辑、赋值位宽、case 缺省、
case 重叠、case 项位宽、端口连接位宽、参数复用、行长和注释率。
对应规则的候选选择、位宽判据及 raw-line 内容判断不变；只修正准入所使用的有效源码上下文。
显式 Verilog 顶层准入使用相同展开模块索引，保留名称归一及恰好一个模块的要求；
展开失败时报告无法可靠确认，不把缺失输入说成不存在的设计。
