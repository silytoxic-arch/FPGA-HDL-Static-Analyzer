# FPGA HDL Static Analyzer V1.4.211

## R-5-1 原生判据深化

- 软件规则编号严格采用官方三段式 `R-5-1`。
- 恢复逐标识符 AST 报告粒度、精确原生正文和标识符物理行无列定位。
- 连续赋值、过程赋值及命名实例端口表达式现在检查全部异步控制标识符。
- 同一物理行的多个独立命中不再被全局去重折叠。
- 专有库端口元数据、位置端口和跨层次复位关系尚未完整恢复，无告警继续为
  `ManualReviewRequired`。
- 产品按 GJB 强制条款继续显示 `Error`；二进制内部的 `警告` 标签作为逆向事实记录。

Windows 安装包只由 GitHub Actions 构建和保存；本地不下载、不保留 Windows 安装包。
