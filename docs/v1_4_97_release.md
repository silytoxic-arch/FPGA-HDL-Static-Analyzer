# V1.4.97 A-5-29 低有效信号候选恢复记录

## 新恢复的原生边界

- `FUN_1805f1190` 从共享生产器取得分类后的条件关系记录；它检查类别 1 的全部记录，以及类别 2 中显式标志为 1 的记录。
- 两类记录都只有在极性字段等于 0 时才进入 `_n` 后缀检查。
- 条件提取器 `FUN_1804c4430` 明确把 `falling_edge(identifier)` 写为极性 0，把 `rising_edge(identifier)` 写为极性 1。
- 类别 1/4 分类器使用 `FUN_1804d20e0` 区分赋值形态；其中字面量 RHS 是已经静态恢复的支持分支。

## 产品修正

原实现只检查时序模型确认的低有效复位/置位，遗漏了原生分类器中“下降沿 + 支持赋值形态”的极性 0 分支。V1.4.97 新增受限源码适配：同一 VHDL 进程存在直接字面量赋值时，检查 `falling_edge(identifier)` 的标识符是否以 `_n` 结束。

新增测试覆盖：

- 下降沿条件树含字面量赋值且名称缺少 `_n` 时报告；
- 普通下降沿数据传送不因边沿方向被猜测为低有效控制；
- 既有低有效复位/置位、普通数据与零比较的边界保持不变。
