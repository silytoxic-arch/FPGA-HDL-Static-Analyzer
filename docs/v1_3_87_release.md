# FPGA HDL Static Analyzer V1.3.87

本版本只推进规则集准确性，不修改表格或其他界面格式。

## GJB9765.4.10.c

完成 `T-Linter.dll` 原生入口 `FUN_1805a4390` 及最终关系判断辅助函数的只读恢复。原生逻辑会构造复位网络和寄存器传递关系，并在无法证明复位路径具备同步释放属性时报告；它不是简单地禁止异步复位。

产品现已接入附件证实的两级结构：

- 原始复位可以异步置位两个同步级。
- 第一级在时钟沿进入非复位值，第二级在时钟沿采样第一级。
- 业务寄存器使用第二级复位时通过。
- 原始复位直接控制业务寄存器、单级释放链以及存在但未被业务逻辑使用的同步器均不会被误判为合规。
- 同步复位和不在敏感列表中的普通控制不参与本规则。

详细证据见 [原生恢复记录](evidence/native_vhdl_async_reset_sync_release_4_10_c_findings.md)。
