## R-14-3 原生判据校正

- 公开规则编号严格使用官方三段式 `R-14-3`；规则矩阵中的 209 条标准规则也已统一为 `R-X-X` / `A-X-X`，不再把内部 GJB 条款当作用户规则编号。
- 恢复并接入原生内部 `init` 关系的生产逻辑，而不是按产品自行理解的复位语义判断。
- 支持显式 `initial`、非状态控制 if 的非默认分支及非状态控制 case 的非 default 分支中的简单原子/三目赋值。
- 明确保留原生非对称边界：else/default 单独赋值、无条件赋值和声明初始化不被推定为已生成 `init`。
- 严重级别修正为 Warning，诊断文本恢复为 `状态机变量<名称>未设置初始状态`。
- 未支持路径继续标记为 `ManualReviewRequired`，不伪判合规。
