# FPGA HDL Static Analyzer V1.3.97

本版完成 GJB10157.5.2.8 数据类型规则的原生核心判据恢复与独立接入。

## 规则准确性

原生 DLL 的模块直接子节点路径现已恢复。规则精确报告 `time`、`realtime`、`tri0`、`tri1`、`triand`、`trior`、`trireg`、`real`、`supply0`、`supply1`、`uwire`、`wand`、`wor` 和 `localparam`；普通 `parameter` 明确跳过。

产品按声明对象定位，覆盖条件编译后的模块直接声明、ANSI 参数和端口列表，并支持逗号列表的类型继承。函数、任务、过程局部声明、包、typedef、nettype 和类型参数不被扩大解释。详细证据见 [5.2.8 恢复记录](evidence/native_parameter_types_5_2_8_findings.md)。

## 当前状态

209 条规则中，207 条已有证据支持的原生核心谓词部分接入；剩余 GJB10157.5.1.7、6.2.10 两条继续恢复。完整算法等价验证仍为 0 条。
