# 第四十八轮：A-1-4 物理行长度与模块映射生产链

本轮按官方索引使用三段式编号 `A-1-4`，内部条款键仅用于实现与证据关联；未进行表格或界面格式调整。

## 新恢复事实

- 原生规则只扫描被模块名映射接纳的源码：键对应的模块根向量必须恰有一个元素。
- 同一文件内两个不同且唯一的模块会各自触发一次全文件扫描，因此相同超长行保留两条相同诊断；重复同名模块和无模块源码被跳过。
- 每个物理行不裁剪，长度经 UTF-8 → UTF-16 → Windows `CP_ACP` 转换后按 ANSI 字节数比较。
- 配置键 `GJB10157_VLOG_5_1_4_NUM` 经十进制转换写入规则对象阈值；标准阈值为 80。
- 达到阈值即输出 Error，第 1 列，精确正文为“建议每行字符数小于80个”。

## 产品变更

- 将旧的逐源码 UTF-8 字节近似检查替换为模块映射驱动的原生判据。
- Windows 复现活动 ANSI 代码页计数；非 Windows 只对代码页无关的 ASCII 行自动判断，非 ASCII 保持未知。
- 在最终诊断整理阶段保留 `A-1-4` 的原生重复数量。
- 增加 79/80/81 字节边界、尾随空格、同文件多模块、重复同名模块、无模块源码和 VHDL 排除回归。
- 台账将该规则提升为“证据支持的核心判据；集成源码适配器”。
