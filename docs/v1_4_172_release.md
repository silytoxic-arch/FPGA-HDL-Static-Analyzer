# FPGA HDL Static Analyzer V1.4.172

## 本轮目标

恢复 GJB10157 官方规则 `R-12-3`（内部条款键 `GJB10157.9.3.3`）的事件名称匹配、完整分支门限和诊断重数。本版不调整界面和表格。

## 新恢复的原生行为

- `FUN_1805874a0` 要求当前记录恰有一个 `AST_MODULE(2)` 根，并递归收集 `AST_ALWAYS(0x52)`。
- 所有仅含一个 `AST_IDENTIFIER` 子节点的正/负边沿事件名称进入同一集合；入口不区分时钟和复位角色，也不要求同时存在两种边沿。
- 只检查过程块的直接 `AST_FOR` 和循环块中的直接 if 降低 CASE；两个层级各允许一次首子块展开。
- if 条件只接受裸事件标识符或一层逻辑非包裹的事件标识符。
- `FUN_180560070` 要求存在 default/else，并递归处理带最终 else 的 else-if 链；无最终 else 不报告。
- 原生实现不检查两分支的赋值目标和赋值值。消息为“for循环中同时出现复位部分和逻辑部分”。

## 产品修正与测试

- 移除原先缺少原生依据的“唯一 negedge 复位、必须另有 posedge 时钟、两分支必须写同一目标”限制。
- 改为所有边沿事件名称集合、直接 FOR/IF 结构、完整 else/default 和逐 CASE 诊断。
- 支持高/低有效、单边沿过程、不同分支目标、一个过程中的多个直接 FOR、一次嵌套块、括号化事件和完整 else-if 链。
- 增加无 else、复合条件、else-if 无最终 else、多 module 根等阴性边界。
- 未恢复路径与所有无告警结果继续保持 `ManualReviewRequired`。
