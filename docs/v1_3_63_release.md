# FPGA HDL Static Analyzer V1.3.63

本版只调整规则判断与验证，未修改表格或界面布局。

GJB9765.4.2.b 现区分 VHDL 的信号赋值 `<=` 与关系比较 `<=`。`if`、`while`、`assert`、`wait until`、变量赋值及属性调用中的比较不再触发“赋值右侧回读”告警；`then` 后实际信号赋值仍会报告。原生判断和未覆盖范围见 [证据记录](evidence/native_vhdl_output_port_read_4_2_b_findings.md)。

另用 Ghidra 12.1.4 对 GJB10157.10.1、10.4、7.2.2 的入口做定点只读反编译。10.1 与 10.4 依赖状态图索引及后续辅助函数，7.2.2 的入口涉及多层对象/连接查询；这些入口不能单独证明完整触发条件，因此仍保持人工复核，不引入推测性检测。

209 条规则中，171 条接入了证据支持的核心判断，38 条仍需解释；未宣称与原生完整算法等价。全套测试通过后生成 macOS arm64 可运行包。
