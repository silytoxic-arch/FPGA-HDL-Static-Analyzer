# FPGA HDL Static Analyzer V1.4.168

## 本轮目标

继续恢复 GJB10157 官方规则 `R-12-5`（内部条款键 `GJB10157.9.3.5`）的函数候选、调用图、递归闭环、去重和诊断输出。本版不调整界面和表格。

## 新恢复的原生行为

- 只把包含 `AST_FCALL` 的 `AST_FUNCTION` 加入名称图；名称匹配区分大小写，未解析调用不形成边。
- 从每个已解析调用边启动路径 DFS，只有回到路径首函数才构成递归环。
- 原件以环成员名称集合去重，而不是按函数或调用点输出；互递归环只报一次，成员集合不同的重叠环分别报告。
- 诊断定位到首次发现路径的首函数，消息列出 `模块/函数` 路径。
- DLL 内部严重度为 Warning；产品按官方强制规则配置继续显示 Error。

## 产品修正与测试

- 旧实现会对环内每个函数分别报告；新实现改为原生成员集合粒度。
- 新增直接递归、二/三节点互递归、重复自调用、重叠环、无环、跨模块同名、未解析/限定调用、局部遮蔽、重复定义与固定消息测试。
- 未支持或无法证明的前端解析路径以及无告警结果继续保持 `ManualReviewRequired`。
