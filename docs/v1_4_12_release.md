# FPGA HDL Static Analyzer V1.4.12

本版继续只处理规则集，不调整界面。

## GJB10157.5.2.3 条件编译关键字命名

原生规则对前端已解析的七类 AST 声明执行 ASCII 不区分大小写的全名精确匹配。
产品此前只要源文件含有任意反引号指令，就整体跳过关键字判断，会漏报活动宏分支中的确定违规。

本版改为使用工程 `defines` 成功预处理后的活动声明：

- 活动分支中的 VHDL、Verilog、SystemVerilog、SDF/EDIF 保留名称正常报告；
- 只存在于非活动分支的保留名称不产生误报；
- 项目显式的六类关键字策略继续优先，默认仍严格依据附件规则文本启用前四类；
- 诊断行列映射回原始源文件；
- 语法错误、重复模块根或预处理失败时不猜测违规。

新增活动分支正例、非活动分支反例、原始源位置和失败边界测试。完整厂商宏/include/生成 AST、
错误恢复与诊断排序仍为未恢复项，无告警继续保持人工复核。
