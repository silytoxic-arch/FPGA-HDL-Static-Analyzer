# 第一百一十一轮：补齐比较单元的复位根匹配

目标与静态边界同第一百零九轮。原始辅助函数、字符串保存在
`reverse-tools/evidence/t_linter_pass111/`；匹配器的完整摘录已在
`reverse-tools/evidence/t_linter_pass102/reset_root_matcher.txt`。

## 取证修正

此前“8 类单元”的概括不完整。匹配器在这些分派后还有两组类型判断。
FUN_1801cccc0 明确判断单元类型等于两个给定 ID 中任意一个。

| ID 辅助函数 | 字符串地址 | 实际类型 |
| --- | --- | --- |
| FUN_180280240 | 0x180e8664d | $eq |
| FUN_18027f8a0 | 0x180e8665d | $eqx |
| FUN_18027fcc0 | 0x180e86655 | $ne |
| FUN_180280030 | 0x180e86665 | $nex |

两组分支先核对输出 Y，随后分别尝试 A 为常量、递归 B，以及 B 为常量、递归 A。
FUN_1809bcb00 检查信号分块没有非空线来源；FUN_1809b66f0 检查常量位中是否有
状态 1。递归仍经过输入宽度必须为 1 的入口。极性和复杂关系类别的处理保留在
原始记录中；本轮只接入能确定唯一标量来源的简单名称表路径。

因此不必假设等式先变为直接线或 NOT，才能建立这条准入链。第一百零五轮的
有界生成窗口本身仍不足以证明完整链路，缺失部分现由匹配器剩余分派补齐。

## 产品接入与边界

完整简单叶模块中，根条件可递归为标量、!/~，或 ==/!=/===/!== 比较；比较
须一侧为显式宽度 1 的合法数字字面量，另一侧递归到同一个标量来源。
两侧顺序均可。沿用已有数字解析，可识别有符号和 X/Z/? 字面量；这些恢复的是
原生常量状态及来源路径，不是对 HDL 四态复位行为的合规认证。

名称表准入与诊断表达式分派不同：本轮没有把 !=、===、!== 或复合条件加入
R-6-3 的诊断条件。它们能建立复位名，不表示自身应发出该规则诊断。
显式宽度大于 1、无尺寸/无基数填充值、参数比较、多来源布尔组合及完整图关系
仍不发布完整名称表。无诊断继续人工复核，完整算法等价仍为 0/209。
