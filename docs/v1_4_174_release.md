# FPGA HDL Static Analyzer V1.4.174

## 本轮目标

修正 GJB10157 官方规则 `R-12-5` 的函数名称图作用域。本版不调整界面和表格。

## 原生行为与产品修正

- 原生候选表和邻接表只以区分大小写的函数名字符串为键，没有 module 身份。
- 候选组之间共享名称图；不同 module 中不同名称的函数可以形成递归闭环。
- 同名候选覆盖报告节点，但各候选产生的调用边继续合并。
- 环仍按完整成员名称集合去重，重复调用点、旋转路径及跨 module 同名候选不会增加同一成员集合的报告数。
- 产品已移除原有 module 隔离键，并增加跨 module 闭环和同名覆盖定位测试。
- 用户可见规则编号严格为官方三段式 `R-12-5`。

## 未闭合边界

跨候选组环的模块显示文本、外层组排序与增量建边时机、旧环在后续组中的报告重数、宏/include、包、类、层次函数及错误恢复仍未完全恢复。无告警继续保持 `ManualReviewRequired`，不声明完整原生算法等价。
