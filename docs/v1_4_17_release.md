# FPGA HDL Static Analyzer V1.4.17

本版继续只处理规则集，不调整界面。

## 三条格式结构规则条件编译修正

修正 `GJB10157.5.1.2`、`.5.1.3` 和 `.5.1.6` 的条件编译输入边界。三条规则分别检查
if/case 分支左对齐、端口/内部声明左对齐以及同一物理行的多个赋值；DLL 证据表明其输入来自
前端 AST 节点及源位置，而不是未经条件选择的全部原始 token。

本版仅在工程预处理成功后检查活动分支：

- 活动分支中的三类确定违规正常报告；
- 未激活宏分支中的相同文本不再误报；
- 三条诊断保留原始物理行号；
- 预处理失败时不猜测结构；
- 原生确认为原始物理文本判据的其他格式规则保持不变。

新增三条规则的活动分支正例、未激活分支反例、精确重数和逐条位置测试。完整宏/include/
generate 展开、厂商列号正规化与 `.5.1.6` 的全部 AST 分组仍未知，无告警继续保持人工复核。
证据边界见 [对齐规则条件编译记录](evidence/native_verilog_alignment_preprocessing_findings.md)。
