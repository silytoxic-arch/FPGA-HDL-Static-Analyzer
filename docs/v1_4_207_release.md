# FPGA HDL Static Analyzer V1.4.207

## R-4-3 原生判据深化

- 软件规则编号严格采用官方三段式 `R-4-3`。
- 连续赋值的直接标识符 RHS 被排除；非平凡表达式和无边沿组合过程赋值进入有界
  时钟目标检查。
- 同一时钟目标的多个组合驱动按名称去重，只在首个驱动处报告一次。
- 恢复精确正文、`Warning`、驱动物理行及原生无列语义。
- 增加反相、算术表达式、直接别名、组合/时序过程和重复驱动边界验证。
- 无告警继续为 `ManualReviewRequired`，完整专有前端等价仍不宣称完成。

Windows 安装包只由 GitHub Actions 构建和保存；本地不下载、不保留 Windows 安装包。
