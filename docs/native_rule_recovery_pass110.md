# 第一百一十轮：proc_arst 之前的过程变换入口

同一目标，仅静态检查；虚表、入口及选定工作函数的原始摘录见
`reverse-tools/evidence/t_linter_pass110/`。

实际虚表（不含 meta_ptr）+0x18 绑定如下：

| 过程变换 | 执行函数 | 跟进的工作函数 |
| --- | --- | --- |
| ProcCleanPass | FUN_180293b70 | FUN_180294310 |
| ProcRmdeadPass | FUN_1802c46e0 | FUN_1802c2c50、FUN_1802c34e0 |
| ProcPrunePass | FUN_1802c2650 | FUN_1802c1ad0 |
| ProcInitPass | FUN_1802b5e10 | FUN_1802b5980、FUN_1802b63b0 |

入口遍历选定模块和过程；所跟进窗口可见空开关清理、分支树递归、赋值修剪调用，
以及初始过程动作到 init 属性的处理和非恒定初始化错误文本。
这些是第一百轮准备顺序中 proc_arst 之前的实际目标入口。

本轮没有穷尽各工作函数的全部传递调用，因此不以“未看到某个优化名字”证明
不存在其它优化，也不以公开 Yosys 实现代替目标代码。比较单元的复位准入由
第一百一十一轮匹配器的正向分派证据建立，不依赖这种否定推断。
