# 第七十八轮：R-5-5 寄存器上电初始化

本轮只深化规则判断逻辑，不调整界面和表格。软件对外编号继续采用官方三段式
`R-5-5`，内部兼容键为 `GJB10157.6.2.5`。

## 新恢复事实

- 构造函数 `0x180558d00` 注册规则；slot 0 为 `FUN_1805596f0`，slot 1 固定返回
  false，slot 2 只接收 `AST_MODULE(2)`。
- 通用构造函数不初始化对象 `+0x140`；产品继续要求显式 initial 接纳策略，不猜测
  DLL 对象默认值。
- `FUN_18055ae60` 只读取赋值目标的直接 `AST_IDENTIFIER(0x13)`，以“归一化目标名 +
  物理行”建立记录，不读取或验证 RHS。
- selector 为 1 时，变量 RHS 等非固定表达式也会按目标名计入 initial 集合。条款文字要求
  “赋固定值”，但 DLL 这一分支没有对应校验，产品不虚构不存在的原生判断。
- 同名目标位于不同行时保留多条记录；同名目标在同一物理行重复时合并。
- 简单缺失分支精确正文为 `必须对寄存器<名称>进行上电初始化,赋固定值`，级别
  `Error`，位置为赋值目标物理行且无列。
- 复杂 default/reset 分支另有正文 `寄存器<名称>无初值`；该分支完整候选归属仍未接入。

## 产品变更

- 简单单边沿源码子集使用精确正文、Error 和物理行第 1 列映射。
- 候选集合由按名称唯一改为按“名称 + 物理行”唯一，恢复跨行重数和同一行合并行为。
- 增加精确表面、动态 RHS initial、跨行重复赋值、同一行重复赋值四类回归断言。
- `R-5-5` 台账提升为 `integrated-source-adapter`；复杂分支和未知工程上下文仍保持
  `ManualReviewRequired`，完整供应商算法等价仍为 `0/209`。
