# FPGA HDL Static Analyzer V1.3.50

本版本只推进规则集，不包含表格或界面格式调整。

## GJB9765.4.13.a

- 从用户附件 `T-Linter.dll` 的构造函数 `0x1800256f0` 和 vtable slot 0 `0x1805bb190` 恢复 VHDL 文件头关键字核心判据。
- 使用工程显式 `header-policy` / `header-keyword` 配置，对最早的 `library`、`use` 或 `entity` 节点之前的非空物理行执行逐关键字子串匹配。
- 每个关键字保留独立的大小写敏感标志；缺失项合并到一次诊断。
- 显式空表禁用检查；配置未知时不伪造厂商默认关键字，也不生成该条款违规。
- 移除此前把示例模板推断为“文件名、作者、功能描述、修改记录”固定四字段的 VHDL 默认判定。
