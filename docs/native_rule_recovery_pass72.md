# 第七十二轮：A-4-1 时钟双边沿使用

本轮只深化规则判断逻辑，不调整界面和表格。软件对外编号继续采用官方三段式 `A-4-1`。

## 新恢复事实

- 恢复构造函数、虚表、综合连接模型入口和端点展开路径。
- 每个端点贡献一个边沿位，位掩码达到 `3` 时形成冲突。
- 原生对形成冲突的前一端点和当前端点分别报告，随后结束该关系族遍历；每个冲突
  时钟族是两条端点告警，而不是一条汇总告警。
- 恢复精确正文 `时钟<名称>不能同时使用上升沿和下降沿`、`Warning`、端点物理行
  和无列语义。
- 名称辅助函数的反斜杠归一化边界得到静态确认。

## 产品变更

- 将每个冲突时钟族的一条汇总报告改为两个端点报告。
- 恢复原生正文、两个端点物理行和第 1 列占位。
- 保留直接别名和一元反相别名的循环安全有效边沿归一化。
- 增加精确正文、双端点位置、同边沿重复和三类附件场景的边界测试。

完整综合网表拓扑、库原语属性、跨层次传播和原生端点顺序仍保持人工复核。
