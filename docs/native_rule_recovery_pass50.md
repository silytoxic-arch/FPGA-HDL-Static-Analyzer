## 新恢复事实

- 闭合构造函数、别名 `VLR-110018`、虚表、活动入口和候选过滤槽。
- 候选类型为连续赋值、阻塞赋值、非阻塞赋值、FOR 和 GENFOR。
- FOR/GENFOR 根及其直接赋值子节点会从一般候选中移除；裸循环体赋值不参与同行配对。
- 剩余候选按同行两两配对，较早候选的首子节点必须为 `AST_IDENTIFIER`。
- 记录按源路径和物理行去重，同一行三条以上赋值仍只报告一次。
