# FPGA HDL Static Analyzer V1.3.51

本版本只推进规则集，不包含表格或界面格式调整。

## GJB9765.4.13.b

- 从用户附件 `T-Linter.dll` 的构造函数 `0x180025780` 和 vtable slot 0 `0x1806b1620` 恢复 VHDL 实体端口注释核心判据。
- 对每个实体端口独立检查其名称所在的精确物理行是否含有原始字节标记 `--`。
- 声明前后相邻行的注释不生效；同一行的分组端口共享该行注释。
- 保留原生的非词法字节搜索语义，包括字符串中的 `--` 也会使该行通过。
- generic 和体系结构内部 signal 不属于本规则候选。
