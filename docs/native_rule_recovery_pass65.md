# 第六十五轮：R-3-2 顶层端口类型

本轮只深化规则判断逻辑，不调整界面和表格。软件对外编号继续采用官方三段式 `R-3-2`。

## 新恢复事实

- 构造函数安装的虚表 `0x180eef3d8` 将运行槽和模块选择槽分别指向 `FUN_180543030` 与 `FUN_1807238a0`。
- 选择器只准入 `AST_MODULE(2)`；运行函数只处理配置顶层中的 `AST_WIRE(6)` 输入/输出端口。
- 十二个非 wire/reg 类型字节标志中任一个置位即报告，且每个违规端口独立追加结果。
- 从 DLL 的 49 个 GB18030 字节恢复固定正文 `顶层模块的输入输出端口必须只使用reg型和wire型数据`。
- 严重级别为 Warning；位置取端口物理行，原生记录无列。

## 产品变更

- 正文改为原生固定文本，定位改为端口物理行第 1 列。
- 为该规则关闭通用相同诊断合并，恢复同一行逐端口重数。
- 增加固定正文、Warning、行/列、同一行多个端口和 SystemVerilog `logic` 不误报测试。

十二个标志的一对一厂商字段名仍未完全恢复；产品维持有界类型映射，无告警继续要求人工复核。
