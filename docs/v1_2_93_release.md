# V1.2.93 规则集进展

本版仅调整规则判断、测试与证据台账；未修改表格格式。

- GJB10157.8.2：DLL 槽位 `FUN_180571230` 从 `AST_ALWAYS/AST_ASSIGN` 类根递归收集五类位运算节点，跳过一元节点，只处理恰有两个子节点的候选；分别调用原生宽度推断，并在结果不同时报错。
- 产品新增 `RTL-BITWISE-WIDTH-MISMATCH`，映射到 GJB10157.8.2，覆盖二元 `&`、`|`、`^`、`^~`、`~^`。连续赋值和过程中的位运算均检查，一元 `~` 与逻辑 `&&/||` 不进入该规则。
- 有界宽度推断支持固定宽度信号、常量位/片选、显式定宽字面量、连接及简单括号操作数。无法确定宽度、复杂嵌套、宏、参数覆盖与生成范围继续人工复核。
- 附件违反例的五个位置全部命中，遵循例零告警。446 个附件示例中，自动检测类从 243/244 提升到 245/246；唯一自动类未匹配例仍为含重复枚举字面量及未声明状态的无效 GJB9765.4.11.f.a 示例。
- 209 条规则中，87 条 DLL 证据支持的核心子判据部分接入，6 条附件子判据接入但原生完整算法未恢复，122 条核心判据仍待解释，完整等价验证为 0。无告警不等于合规。

判据证据见 `evidence/native_bitwise_width_8_2_findings.md`，逐条状态见 `evidence/native_rule_implementation_ledger.json`，附件审计见 `evidence/t_linter_after_1_2_93.json`。
