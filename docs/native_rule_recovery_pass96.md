## 原生观察

- 第九十三轮主函数的两条相等路径读取 AST_CONSTANT +0xbc 的 uint，直接与
  事件极性 0/1 比较；不是把非零值转成 true 后比较。
- AST 构造器 FUN_1808d8dc0 初始化 +0xbc 为 0。
- FUN_1800d1350 去除数字文本的下划线和空白，识别宽度、可选小写 s 以及
  b/o/d/h（基数字母支持大写），再调用 FUN_1800d1e40。
- FUN_1800d1e40 对十进制逐位除二产生位向量，对二/八/十六进制按位生成向量。
  无尺寸值补至至少 32 位；显式宽度通过 FUN_1800d2860 调整向量长度。该调整
  入口的实际截断/填充实现由后续补充核对。
- FUN_1808e3930 将向量的低 32 位逐位写入 +0xbc，仅字节值等于 1 时置位；
  有符号且向量不足 32 位时复制最高位。FUN_1808e3a30 是其无第三标志的包装。
- 因此 `1'sb1` 的缓存整数为 0xffffffff，而 `1'b1` 为 1；宽于 32 位的数值
  只保留低 32 位参与此规则比较。

## 产品接入

将原来的 0/1 文本白名单替换为确定二态整数字面量解码，覆盖多位与无尺寸数、
二/八/十/十六进制、宽度截断、有符号扩展及低 32 位缓存。单 token 的 '0/'1
沿用原生一位常量路径。限制宽度为原生正 int 范围，异常宽度不推断。

测试覆盖 24 个数值形态、两个边沿、常量左右两个方向，共 96 个比较场景。
不将 `RST==2` 简化为高有效；0/1 之外的缓存整数与两种边沿均不一致。

四态数字、负号等运算表达式的折叠、参数替换、复杂布尔条件、宏及合成关系
仍未恢复；未知条件保持人工复核，完整算法等价仍为 0/209。
