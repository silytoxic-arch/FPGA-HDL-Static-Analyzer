# FPGA HDL Static Analyzer V1.4.246

扩大 VHDL A-10-4 的已接入来源范围：

- 检查 postponed process、IF/FOR generate 和 block 内的进程，支持嵌套及命名结束。
- 分别处理局部信号、常量和生成迭代参数，避免把外层 IEEE 类型套到同名局部对象。

- 同一词法 owner 的配对保持次数；不同对象同名的原生限定名仍待恢复，不猜测额外配对。
