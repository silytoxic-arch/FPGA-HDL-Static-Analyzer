- RHS 名称不在集合时，仅在目标键尚不存在的分支插入布尔值 0。已有键不被这个
  插入分支覆盖。混合 RHS、多目标及赋值顺序可能影响最终值，需逐分支验证。
- 主函数仅对最终布尔值为零的名称记录构造报告，原生严重度固定为 `error`。

- 报告文件取模块/设计根路径；当前反编译显示行字段读取候选过程 `+0x200`，
