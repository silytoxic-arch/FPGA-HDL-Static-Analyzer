## 原生证据闭环

- `FUN_180775050` 对 `AST_ASSIGN_LE(0x56)` 只接受直接目标标识符、双子节点 `AST_WHEN(0xb6)` 和直接常量族末端组成的三子节点形态。
- `AST_WHEN` 的数据侧必须是直接标识符；条件侧必须包含一个双操作数关系节点，辅助函数从关系两侧的直接名称中解析控制源。
- `FUN_180772510` 对同一目标的驱动记录逐 pair 比较。任一记录缺少目标、数据或控制字段即进入诊断路径。
- 两条记录都完整时还要比较控制源名称；控制源不同仍报告，相同才豁免。
- 附件正确例的 `B/C/D when A="01"/"10"/"11" else 'Z'` 使用不同关系常量但共同控制源 `A`，与该原生比较一致。

## 产品修正

- 三态多驱动豁免现在要求每条赋值的数据侧为一个直接标识符。
- 条件必须是一个简单二元关系，两侧均为直接简单原子，且至少一侧为直接标识符。
- 控制标识符可位于关系任一侧；同一目标的所有驱动必须解析到同一控制源。
- `else` 分支仍严格要求 `'Z'`。
- 不同控制源、复杂数据表达式、复杂条件或普通驱动与三态驱动混用继续报告。
- 字符常量同时兼容词法器的单 token 和拆分 token 表示，不扩大原生关系运算符集合。
