- `FUN_1804fcec0` 查找名称键；已有键时返回记录 `+0x40` 的值地址。因此
  `FUN_180561f70` 的 `*value=1` 确实更新已有值。
- `FUN_180558ca0` 将名称与传入的单字节布尔值构造为记录；动态 RHS 路径仅在
  查找失败时以 0 构造记录。它没有将已有的 1 写回 0。
- `FUN_1805601e0` 清零并分配一张新名称树；主函数在候选分支循环内调用它。
  单边沿路径也为当前过程新建状态表，不能跨过程借用常量赋值。
- `FUN_1804c8570(...,1)` 保留大小写；只有第三参数为 0 时才执行逐字节 tolower。
- `0x22` 类型与既有宽度恢复证据
  `docs/evidence/native_arithmetic_result_width_8_7_findings.md` 的
  `AST_CONCAT(0x22)` 映射一致。

## 本轮实现

单边沿显式 always 的有界适配现在从同一过程内全部直接数值常量赋值建立覆盖名称集。
目标曾直接赋数值常量时，后续动态赋值不撤销覆盖；动态赋值后出现常量也置为覆盖。
不同过程独立计算。新增 Q1 常量后动态、Q2 动态后常量、Q3 仅动态三个并列对照。
原生参数/表达式、拼接目标、专有候选关系和 `+0x200` 定位仍需深化，台账继续为部分接入。
