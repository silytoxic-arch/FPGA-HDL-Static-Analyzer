# FPGA HDL Static Analyzer V1.4.176

本版深化官方规则 `R-14-1`，不修改表格和界面布局。

- 从附件 DLL 中分离状态机死循环与不可达两条原生路径；
- 新增基于可证明初始状态和完整简单转换图的逐状态不可达检查；
- 使用恢复的原生中文消息格式；
- 将 `R-14-1` 严重级别修正为 Warning；
