# V1.2.7 持续逆向检查点

本轮新增三项有原生静态证据支持的部分检测，已进入 GUI/CLI 共用引擎：

- GJB9765.4.10.h：解析真实 entity/architecture/process/IF，绑定明确的 IEEE 标量信号，按已恢复的 class1/2 子集收集时钟与条件 EQ 标识并求交集。不是仅凭“赋常量”或扫描所有时钟比较。
- GJB9765.4.14.d.1：72 个非空白代码字节阈值，缩进和内部空格不增加计数。
- GJB9765.4.14.d.2：同一物理代码行超过一个分号 token；字符串和注释中的分号不计入。

原生格式循环存在固定 fgets 分块和不识别引号的边界；产品使用完整物理行及词法注释/字符串识别，这是明确的独立安全改进，不声称逐字节等价。
时钟检查限定可靠的平直进程和明确声明，复杂语法、跨文件绑定、遮蔽、生成块等保留人工复核。不同 architecture 隔离是产品选择，不是原生全局名称集合已证实的性质。
附件把纯边沿常量赋值列为反例，但原生交集逻辑没有相应控制 EQ；保留该证据冲突，不为吻合文档标签制造告警。

验证：114/114 CTest、90/90 CLI 回归通过；边沿 helper 42 组、时钟源码检测器36例通过。
独立FSM模型25条输入及2组字段断言、显式配置文件头策略23组断言纳入测试；它们尚未作为完整标准检测器接入。

该统计不是算法准确率；人工复核和上下文无报警不等于符合标准。
