# FPGA HDL Static Analyzer V1.4.229

R-6-3 的简单模块复位名称表扩展到多个寄存器：按唯一目标名对应两侧常量/运行时
赋值，支持分支赋值顺序变化、普通嵌套块和空语句。只要存在缺失、重复或不能恢复
的目标，整张名称表继续保持未知，避免凭部分集合排除候选。

补充多寄存器时钟过滤、有效低复位、嵌套块及跨过程报告验证。原始分支消除链见
第一百零四轮。第一百零五至一百零六轮补充等式降低边界和 AstModule 覆盖克隆入口，
修正基类虚表不能证明全部动态调用的解释。尚不把等式根纳入完整名称表。
