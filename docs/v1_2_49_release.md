# V1.2.49 表格列宽与框体修复

## 修复结果

- “问题列表”和“代码规模明细”的内部列分隔线采用相邻列等量联动：向左拖动时左列变窄、右列等量变宽，向右拖动时方向相反。
- 拖动期间表格总宽度保持不变，避免横向滚动条范围变化造成分隔线反向跳动。
- 拖动指示线以实际列边界为起点，即使鼠标按在边界热区内侧，指示线也不会偏离列边界。
- 表格面板使用连续的深色双像素外框，标题栏与表头使用明确的底边，数据区使用完整边框和可见网格。

## 验证范围

- 未滚动状态下向左、向右拖动。
- 横向滚动后的中间列拖动。
- 滚动到最右端后的倒数第二列拖动。
- 两张表格均验证相邻列宽度的等量变化与恢复。
- 生成真实数据窗口截图，核对外框、标题栏、表头、数据网格和空白区列线。
