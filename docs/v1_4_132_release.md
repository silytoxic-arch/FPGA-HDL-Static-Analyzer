# V1.4.132 R-9-2 条件信号赋值候选

本版本只推进规则逆向、判断逻辑和验证，不调整界面或表格布局。对外规则编号继续严格采用官方三段式 `R-X-X` / `A-X-X`。

## 新恢复并接入的原生判断

- `FUN_180699180` 除 IF/CASE 候选外，还递归收集 `AST_ASSIGN_LE(0x56)`。
- 只有赋值第二个子节点为 `AST_WHEN(0xb6)` 时进入该分支。
- WHEN 的直接条件子项为标识符时，以该名称建立候选。
- 条件子项为直接 `AST_EQ(0x36)` 时，只取第一个子节点，且它必须是标识符；等式右侧名称不会成为候选。
- 该分支不调用通用条件收集器，因此 NOT、AND/OR、函数调用和其他关系根不会递归提取时钟名。

## 新增验证

- `q <= d when clk else '0'`：产生 1 条 `R-9-2`。
- `q <= d when clk='1' else '0'`：产生 1 条 `R-9-2`。
- `when not clk`：不产生该路径告警。
- `when en=clk`：只看等式左侧 `en`，不因右侧 `clk` 告警。
- V1.4.131 的类别 1/2、类别 3/4 排除、IF/CASE 候选与边沿惯用式边界继续回归。
