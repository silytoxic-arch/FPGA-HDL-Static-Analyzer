# FPGA HDL Static Analyzer V1.4.84

本版本仅推进规则判断逻辑与验证，不调整界面和表格布局。

## 本轮规则

- 官方规则编号：`A-2-6`
- 标准映射：`GJB10157.5.2.16`
- 规则主题：禁止使用 `defparam` 语句。

## 原生证据支持的行为

- T-Linter 原生入口的 slot 2 只接收 `AST_DEFPARAM(11)`。
- 原生运行函数逐个遍历候选节点；每个非空、类型为 11 的节点各输出一次，不在首个命中后终止，也不按名称去重。
- 原生诊断使用节点源文件和物理行号，严重级别固定为 `Error`。
- 原生固定消息解码为：`禁止使用defparam语句`。
- 当前证据没有恢复列号；产品对该行级定位统一使用第 1 列。

## 产品修正

- 输出与原生固定消息一致，并固定为错误级别。
- 同一物理行出现多个 `defparam` 时保留逐节点多条结果，不再被全局诊断去重合并。
- 对条件编译后的活动源码进行检查：活动分支报告，非活动分支不报告。
- 无告警不等同于完整合规；宏、包含文件及生成 AST 的完整所有权仍需工程上下文或人工复核。

## 验证结果

- 自动化测试：`135/135` 通过。
- 规则审计：446 个示例；435 个自动化匹配、6 个工程上下文匹配、4 个需上下文、1 个原生文档冲突，结果与 V1.4.83 基线稳定一致。
- 已集成源适配器：`15` 条。
- 209 条公开规则编号格式：全部通过 `R-X-X` / `A-X-X` 三段式校验。
- 与厂商完整算法等价：`0/209`（本版本不作虚假等价声明）。
