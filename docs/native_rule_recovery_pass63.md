# 第六十三轮：A-2-3 时钟声明映射

本轮继续只深化规则判断逻辑，不调整表格或界面格式。软件对外编号保持官方三段式 `A-2-3`。

## 新恢复事实

- 虚表选择器 `FUN_1807238a0` 仅准入 `AST_MODULE(2)`，确认规则按模块根建立候选作用域。
- 准备阶段只把 `AST_WIRE(6)` 写入规则对象的模块名/信号名二级映射；映射记录保存原声明节点指针。
- 运行阶段先用时钟关系的模块和规范化名称查询该声明映射，再从声明节点读取文件和物理行。
- 因此原生告警位置是端口、`wire`、`reg` 或 `logic` 声明行，不是敏感表中的边沿使用行；无声明的隐式网不能被当前有界适配器伪判为原生命中。

以上均来自附件 DLL 的离线静态反编译，不是运行观测。关系类别 2/3 的正式名称、别名/派生时钟传播、宏/include/generate 完整 AST 和异常语法恢复仍未知。

## 产品变更

- A-2-3 仅检查当前活动预处理分支内、可解析为 wire-like 的时钟声明。
- 告警定位改为声明物理行和第 1 列。
- 同一模块同名双边沿继续只报告一次；不同模块中的同名时钟分别检查。
- 增加 ANSI 端口、内部 `reg`、隐式网、跨模块作用域、精确正文、严重度和行号测试。

无告警路径继续标为 `ManualReviewRequired`，完整专有前端算法等价仍不声明完成。
