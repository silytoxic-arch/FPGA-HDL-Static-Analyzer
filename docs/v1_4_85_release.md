# FPGA HDL Static Analyzer V1.4.85

本版本只推进规则判断逻辑、原生诊断还原与测试，不调整界面或表格布局。

## 本轮规则

- 官方公开编号：`A-2-7`
- 内部标准映射：`GJB10157.5.2.17`
- 主题：避免在不同 module 中复用相同参数名。

## 准确性修正

- 依据原生有序模块映射遍历，产品以模块名字节顺序决定首次参数，而非按输入文件顺序；厂商精确比较器仍列为未知。
- 原生消息还原为 `参数<当前名>有<首次模块>.<首次名>同名`。
- 固定错误级别，使用后续参数的源文件和物理行；原生未恢复列号，产品使用第 1 列。
- 每个后续参数节点各输出一次；同一行的相同诊断不再被全局去重吞掉。
- 保持条件编译活动分支、localparam 排除和大小写敏感边界。

## 验证结果

- 自动化测试：`135/135` 通过。
- 规则审计：446 个示例；435 个自动化匹配、6 个工程上下文匹配、4 个需上下文、1 个原生文档冲突，相对 V1.4.84 基线稳定。
- 已集成源适配器：`16` 条。
- 209 条公开规则编号格式：全部通过 `R-X-X` / `A-X-X` 三段式校验。
- 厂商完整算法等价：`0/209`，本版本不作超出证据的声明。
