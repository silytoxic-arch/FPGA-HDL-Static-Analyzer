# 第一百零五轮：等式降低链的证据边界

同一目标映像，静态检查未执行目标。断言字符串
`Yosys::AST::AstNode::genRTLIL` 的引用定位到 FUN_1808f6f80；simplify.cc 文件名
引用定位到 FUN_180914500 等函数。读取完整反编译结果，保留与本问题有关的原始
窗口及完整临时文件哈希，见 `reverse-tools/evidence/t_linter_pass105/`。

genRTLIL 的 0x36/0x37/0x38/0x39 分派分别取操作类型 ID，再通过共同二元节点
生成路径处理两个操作数。simplify 的对应窗口显示：两侧都是常量时才进入该处的
整数字面量运算折叠，另有实数比较路径。

这些窗口没有建立“变量与 0/1 比较一定在复位目录生成之前变成直接线或取反”的
完整链路。准备函数的 opt_expr 调用在第一阶段快照之后，不能挪用它为此前目录
准入作证明。仍须检查完整布尔控制降低及其它优化入口；这不是整函数不存在相关
处理的结论。本轮不把等式根直接纳入完整复位名称表，既有 AST 比较适配继续保留
其原有部分恢复边界。

后续修正：第一百一十一轮确认匹配器另有比较单元分派，显式单比特比较无需
先变为直接线即可进入已恢复的路径。此前“8 类”的概括不完整；本轮生成窗口
的观察保留，但不再用缺少直接线转换证据阻止该已证实的准入子集。
