# FPGA HDL Static Analyzer V1.4.250

新增带文件/行来源恢复的 Verilog 宏和 include 展开，接入六条命名规则：
R-2-1、R-2-2、R-2-4、R-2-6、A-2-2、A-2-5。

- 支持对象/函数宏、默认参数、拼接、字符串、多行参数、条件编译与嵌套包含。

- 声明按词法来源定位到 include 文件或 line 指令位置；这与部分原生入口采用 module 路径

3 项既有静态实现/文档差异，没有新增未解释变化。
