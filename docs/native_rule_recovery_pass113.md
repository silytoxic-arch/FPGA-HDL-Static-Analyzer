## 原生观察

FUN_180282ef0 为 proc_arst 主体逐 action 调用的复位值求解函数。它建立起始位向量，
反复调用 FUN_180282250 处理动作/分支，再经 FUN_1801d9540 逐位映射；遇到全常量
或结果不再变化即停止。仍非恒定且计数大于 100 时，进入带有
`Async reset ... yields endless loop ...` 文本的错误路径。
末尾调用 FUN_1809bc4a0；该函数查询常量块是否含状态 5，本轮不擅自定义其完整业务意义。

工作函数先处理动作，再逐开关调用根匹配器；能匹配当前复位条件时按比较项选择分支，
否则以另一模式递归其它路径。这里仍有完整分支求值和位映射尚未接入，不能称为
已经复现了该求解器。

前端 simplify 的标识符分派查询参数/局部参数声明，取得其常量子节点作为替换节点。
整数运算分派在相应子节点为 AST_CONSTANT 时调用位向量运算并构建常量节点。
共用替换尾部保留源位置，再调用 FUN_1808dbab0；其克隆、清理和复制链已跟进。
因此可将已证明的整数常量数据作为简单复位分支中的常量端，不能只认源码数字 token。

另保留整数除/模辅助函数 FUN_18095f410、FUN_1809611e0 的完整摘录，可见状态 2

除零或含未知位的复位值符合 HDL 安全规则。
