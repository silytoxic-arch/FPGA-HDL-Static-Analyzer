## GJB10157.8.7 嵌套算术表达式位宽

对附件 `T-Linter.dll` 的静态反编译和指令核对确认，GJB10157.8.7 调用
`FUN_1808f4650` 的五处路径均把第五个 flag 参数置为 0。对应的
`FUN_1808f46c0` 位宽推断行为为：

- 嵌套 ADD/SUB/MUL/DIV/MOD 节点取直接子节点的最大宽度；
- 嵌套 POW、单目正号和单目负号传播第一个子节点宽度；
- CONCAT 对各项宽度求和，REPLICATE 用静态重复次数乘内容宽度；
- 最外层规则分支仍保持各自原生判据，不能把整个表达式简单展平。

产品已据此加入遵循 Verilog 优先级和结合性的有界递归表达式解析。最外层 ADD/SUB
继续逐操作数判断并保留已恢复的拼接豁免；最外层 MUL 对两个直接子表达式的推断宽度
求和；DIV/MOD 使用 `max(child_width)-1` 阈值；POW 继续要求标识符/静态选择底数，
并以指数表达式的推断位宽计算原生公式。

新增正反例覆盖嵌套加法、嵌套乘法、左结合连续乘法、嵌套除法、静态选择底数与
嵌套指数，以及原生不接纳的复合表达式底数。未解析参数、函数、动态选择、其他 AST
运算符、越界位宽、单元端口绑定和精确诊断去重仍保留人工复核，不以无告警判定合规。
