# V1.3.8 规则集进展

本版本仅推进规则集恢复与验证，没有继续调整问题列表或代码规模表格格式。

## 新接入规则

- `GJB9765.4.5.f.26`：仅对语义上实际作为时钟使用、且绑定到实体端口的名称执行大小写不敏感的 `clk_` 前缀检查。
- `GJB9765.4.5.f.28`：仅对时序模型已经证明为低有效的控制信号执行大小写不敏感的 `_n` 后缀检查。
- `GJB9765.4.5.f.29`：对并发直接缓冲和 `not` 反相赋值比较首个下划线之前的基名；无下划线时以完整名称为基名。

## 准确性约束

- 普通数据与 `'0'` 的比较不会被猜成低有效控制信号。
- 复合表达式、选取名、下标名、进程/子程序赋值不被扩大解释为 f.29。
- 派生时钟、跨层级别名、完整低有效关系图等未恢复部分继续要求人工复核。
- 没有任何规则因本次接入而把“未报警”解释为完全合规。
