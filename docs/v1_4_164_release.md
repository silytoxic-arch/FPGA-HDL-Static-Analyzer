# FPGA HDL Static Analyzer V1.4.164

## 本轮目标

继续恢复 GJB10157 官方规则 `A-11-2`（内部条款键 `GJB10157.9.2.8`）的原生入口、候选节点、诊断粒度和空结构边界。本版不调整界面和表格。

## 新恢复的原生行为

- 构造函数 `FUN_180024010` 注册规则并安装虚表 `0x180ef5458`。
- 选择器 `FUN_180716130` 只接收非空 `AST_CASE(0x57)`、要求节点字节 `+0x183 == 0`，从已观察路径排除 IF 降低形成的 CASE。
- 执行函数 `FUN_1805843e0` 只在直接子节点中寻找 `AST_CONDX/AST_CONDZ(0x59/0x5a)`；命中第一项后用 CASE 自身的文件和行号输出一条 Warning，并立即停止当前 CASE 的扫描。
- 固定原生消息解码为“避免使用casex与casez语句.”。
- 因此每个含 item 的 `casex/casez` 最多报告一次；空 case 没有相应子节点，不报告。

## 产品修正与回归

- 检测器现在要求 selector、匹配的 `endcase` 和至少一个可识别 case item，不再只凭 `casex/casez` 关键字报警。
- default-only 和带三元表达式的 case item 保持可检出。
- 嵌套 `casex/casez` 按各自 CASE 根分别报告。
- 空 case、不完整 case、注释和字符串不报告；无告警继续为 `ManualReviewRequired`，不会伪判合规。
- 新增正反例和空结构、不完整结构、三元 item、嵌套结构边界测试。
