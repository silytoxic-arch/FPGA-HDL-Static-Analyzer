# 第七十六轮：R-5-2 同一复位线路同步/异步混用

本轮只深化规则判断逻辑，不调整界面和表格。软件对外编号继续采用官方三段式 `R-5-2`。

## 新恢复事实

- 恢复构造函数、最终虚表、模块选择器及关系记录首字节 `< 2` 的准入条件。
- 恢复异步控制名称归一化与按名称唯一化。
- 确认只检查恰好一个边沿节点的过程，并且只消费第一个布尔化条件。
- 确认条件中的每个匹配标识符独立报告，不按名称或物理行去重。
- 恢复精确正文 `<名称>同时作为了异步复位和同步复位`、`error`、标识符物理行和无列语义。

## 产品变更

- 用原生结构对应的源码适配器替代通用混用汇总诊断到标准条款的直接映射。
- 增加精确正文/位置、两个同步过程、同一条件重复标识符及嵌套第二条件不参与四组边界测试。
- 保留通用混用诊断用于非标准分析，不影响原有诊断能力。

跨层次关系、库端口及非 `if` 条件的专有前端降低仍保持人工复核边界。
