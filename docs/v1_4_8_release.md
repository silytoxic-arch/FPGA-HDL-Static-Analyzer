# FPGA HDL Static Analyzer V1.4.8

本版继续只处理规则集，不调整界面。

## GJB9765.4.9.h 时钟关系归一化

对 `FUN_18060b400` 的完整控制流复核确认：直接时钟关系去重超过一个时立即报告；直接计数
不超过一个时，原生函数还会进入关系图分支。该分支证明规则不能撤销工程上下文门槛，但也
说明仅按源码名称计数会把明显的同源别名误判为多个物理时钟域。

本版增加有界关系图适配：

- 架构并发区的 `alias_clk <= clk` 归一到 `clk`；
- 架构并发区的 `alias_clk <= not clk` 同样归为一个时钟域，边沿极性不增加域数；
- 进程内部赋值不参与折叠，寄存器产生并被再次用作时钟的信号仍是独立域；
- 条件赋值、函数、组件/原语、generate/configuration 和跨层次传播继续保留为未知边界。

本条仍保持 `ProjectContext`；无告警不会被标记为已证明合规。

## GJB10157.6.1.7 工程上下文边界复核

对 `FUN_180555380` 的完整控制流复核确认：直接时钟关系去重后超过一个会立即报告；
直接计数不超过一个时，函数继续调用 `FUN_1804ce730` 构建关系/端口图，并存在第二条
独立告警路径。因此产品继续只把同一模块内可确定的第二时钟域作为确定违规，跨模块、
原语和复杂生成时钟关系留给工程上下文分析；无告警不声明合规。

静态反编译导出保存在：

- `reverse-tools/evidence/clock-domain-hierarchy/180555380.c`
- `reverse-tools/evidence/clock-domain-hierarchy/1804ce730.c`

导出文件均记录目标摘要，并明确标注为静态伪代码证据而非原始源码或运行时输出。
