# FPGA HDL Static Analyzer V1.4.248

VHDL A-10-4 新增对已绑定 IEEE 标量子类型链的检查。

- 支持 architecture、block、IF/FOR generate 中无约束、无选名的 subtype 链。
- 在声明点绑定类型，遵守局部对象、类型名、枚举字面量与生成变量遮蔽，并恢复外层可见性。
- 不根据包选名末段推断 IEEE 类型；前向、循环和重复声明保持未知。
- 信号 owner 独立于基础类型，保留原生逐对计数；不扩大不同局部对象的同名配对。

新增 24 组模型边界及 4 组端到端回归，并更新已有别名检查。
本地 CTest 134/134 通过，446 个附件示例保持 433 项自动匹配、6 项工程上下文匹配、
4 项需上下文和 3 项既有静态实现/文档差异，没有新增未解释变化。

本轮保留 8 份静态输出/分析脚本，还用调用指令核对了一处反编译漏掉的第三参数，
详见 [第一百三十轮](native_rule_recovery_pass130.md)。
有界来源适配不等于恢复完整原生类型引擎；entity/process 内别名、跨文件、复杂类型、
约束/解析函数及完整名称归一化继续恢复。完整算法验证仍为 0/209，无诊断需人工复核。
Windows 版仅在 GitHub Actions 构建、测试和保存，本地不生成或下载安装包。
