- 软件规则编号严格采用官方三段式 `R-5-3`；共享原生核心的建议规则为 `A-5-2`。
- 确认两个构造器均清零相同模式字节并调用同一核心，不再把两条规则假设成不同算法。

  无列定位。

  `ManualReviewRequired`。
