# FPGA HDL Static Analyzer V1.4.11

本版继续只处理规则集，不调整界面。

## GJB10157.5.2.6 条件编译名称冲突

原生规则在每个解析后的 `AST_MODULE` 内比较声明名称：精确同名不报告，原始名称不同但
小写归一后相同才报告。产品此前基于原始 token 构造集合，并跳过整个条件编译块，导致活动
宏分支中的确定冲突漏检。

本版改为使用工程 `defines` 预处理成功后的活动声明：

- 活动分支中的 `Data`/`data` 一类冲突正常报告；
- 只存在于非活动分支的冲突不产生误报；
- 后一个声明的物理行列保持准确；
- 每个模块仍独立比较；
- FUNCTION 继续排除，TASK 继续纳入；
- 预处理失败时不猜测声明集合。

新增活动冲突、非活动冲突和源位置边界测试。完整厂商宏/include 展开、生成 AST 和区域设置
仍为未知项，无告警继续保持人工复核。
