# 第一百一十四轮：比较端口宽度与常量准入

同一目标，仅静态检查。原始宽度初始化、字符串、ID 构造器和 genRTLIL 窗口见
`reverse-tools/evidence/t_linter_pass114/`。二元单元完整函数仍见第一百零六轮证据。

## 宽度链路

AST_IDENTIFIER 普通信号路径直接使用 RTLIL 线的宽度构建信号块；没有选择时，
其输出保持声明宽度，不因父比较的宽度提示直接增加。
共同二元单元函数 FUN_1808f2de0 分别从 A、B 的实际 SigSpec 宽度构建参数，
再连接各自原始信号。初始化指令及原始字符串将 DAT_18137e14c 绑定到 A_WIDTH、
DAT_18137e16c 绑定到 B_WIDTH；后者通过 FUN_1803c7f00 完成 ID 赋值。

第一百一十一轮的比较匹配器要求递归的非恒定端宽度为 1，常量端则检查其为常量，
并不要求常量端也为 1。因而直接标量与较宽、无尺寸、无基数填充值或已恢复整数
常量表达式比较，也可保留该标量的复位来源。此前仅接入显式一位常量的范围可以扩展。

但不能把这个结论扩展到任意运算节点：逻辑 NOT、位 NOT、比较等节点生成的 Y
可能采用父运算的宽度提示。较宽常量参与比较时，嵌套非恒定运算端可能不再为 1。
相应原始窗口一并保留，避免按布尔代数等价擅自忽略实际信号宽度。

## 产品边界与验证

直接标量端可与分类器证明的整数常量端配对，支持两侧顺序变化；递归的非恒定
运算端继续要求已证明的一位上下文。宽常量作用于 !/~ 或嵌套比较的情况保持未知。
参数和运算表达式只用于名称表的常量性质证明，本轮不把它们的值写入诊断缓存，
原生诊断 AST 是否经过相同替换仍待继续追踪。

新增宽/无尺寸/无基数常量、参数/常量表达式比较及运算宽度提示边界验证，保留
低 32 位缓存的既有行为。完整信号宽度传播仍未恢复，无诊断继续人工复核，
完整算法等价仍为 0/209。
