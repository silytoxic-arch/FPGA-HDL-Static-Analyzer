# V1.2.47 VHDL 声明名称对齐规则

新增 GJB9765.4.14.b.5 的有界检测：在明确可映射的 VHDL `port (...)` 声明组和连续 `signal`、`variable` 声明组中，按源码显示列逐项比较名称；Tab 依照原生逻辑推进至下一个 4 列制表位，与前一项不对齐时报告 Warning。

附件错误例按 `CLK → INPUT1 → INPUT2 → B1` 的相邻显示列变化产生两条告警，正确例无告警。测试还覆盖 Tab 与空格达到相同显示列、信号和变量独立分组、无关声明打断分组、同一物理行的后续声明不参与比较。原生证据及限制见 [恢复记录](evidence/native_vhdl_declaration_alignment_4_14_b_5_findings.md)。

公开样例审计仍为 446 例，Automated 类匹配数由 193 增至 195、失配维持 17。逐条台账现为 209 条中 52 条核心谓词部分接入、2 条模型谓词已观察但未接入、157 条仍需解释、0 条完整等价验证；无告警仍不判定为已证明合规。
