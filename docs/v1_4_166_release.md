# FPGA HDL Static Analyzer V1.4.166

## 本轮目标

继续恢复 GJB10157 官方规则 `R-11-2`（内部条款键 `GJB10157.9.2.2`）的 CASE 候选、常量选择器边界和诊断粒度。本版不调整界面和表格。

## 新恢复的原生行为

- 构造函数 `FUN_180023c20` 注册规则并安装虚表 `0x180ef4cd8`。
- 选择器 `FUN_180581b90` 与执行函数 `FUN_180581600` 均要求节点为 `AST_CASE(0x57)`、`+0x183 == 0`、直接子节点非空，且首子节点是 `AST_CONSTANT(0x10)` 或 `AST_REALVALUE(0x11)`。
- 每个匹配的 CASE 根只输出一条 Warning，不检查分支标签或分支语句。
- 固定原生消息解码为“禁止在case语句的控制表达式中使用固定值.”。

## 产品修正与测试

- 只对结构完整的 `case/casex/casez` 执行本规则；不完整 case 不因关键字与常量选择器而误报。
- 完整空 case 仍报告，嵌套的两个常量 case 分别报告。
- 保留标准配置中强制规则 `R-11-2` 的 Error 严重度；DLL 内部 Warning 仅作为原生实现证据记录。
- 参数、局部参数按已接入的有界词法常量解析处理；未知折叠路径和无告警结果保持 `ManualReviewRequired`。
