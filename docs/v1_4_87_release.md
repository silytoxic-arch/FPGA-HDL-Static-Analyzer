# FPGA HDL Static Analyzer V1.4.87

本版本只推进规则逆向、判断逻辑和验证，不调整界面或表格布局。

## 本轮规则

- 官方公开编号：`A-2-4`
- 内部标准映射：`GJB10157.5.2.14`
- 主题：复位信号命名。

## 准确性修正

- 修复 `rst_nx_n` / `RST_NX_N` 被错误放行：原生比较第一次极性标记位置，而非普通后缀判断。
- 还原 DLL 的精确大小写前缀与尾部/内部极性标记。
- 还原完整动态消息，采用 DLL 的 `RST_X`，不使用附件正文中与二进制冲突的 `Rst_X`。
- 固定 Error，使用候选物理行和第 1 列。
- 保持完整关系模型、别名和层次传播未知时的人工复核状态。

## 验证结果

- 自动化测试：`135/135` 通过。
- 规则审计：附件中的 `446` 个示例结果保持稳定（`435` 个自动匹配、`6` 个工程上下文匹配、`4` 个仍需上下文、`1` 个原生实现与附件正文冲突）。
- 已集成源适配器：`18` 条。
- 209 条公开规则编号格式：全部符合官方三段式 `R-X-X / A-X-X`。
- 厂商完整算法等价：`0/209`。
