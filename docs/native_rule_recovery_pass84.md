# 第八十四轮：R-6-2 参数 RHS 状态接入

延续第八十二、八十三轮的同映像静态证据。

`FUN_180561f70` 对 RHS 的每个 identifier 查找当前设计的 parameter/localparam
名称向量。命中一次即将全部当前目标状态写成 1；未命中时只插入尚不存在的零值键。
因此对单个目标，混合参数与动态信号的 RHS 最终为 1，与这两类 identifier 的
遍历先后无关。无 identifier 的 RHS 也直接将全部目标置为 1。

本轮在单边沿显式 always 的简单目标适配中接入：

- 从所属 module 范围内收集 parameter/localparam 声明名，保留大小写。
- 接纳 identifier-free 数值表达式；RHS 含任一参数名称时建立覆盖状态。
- 常量或参数覆盖不会被后续动态赋值撤销。
- 过程之间的目标状态独立；模块之间的参数名称独立。
- 括号条件中的 <= 比较不作为赋值；函数调用和系统调用仍不作此状态推断。

新增混合表达式 `P+D`、`D+L`、纯数值 `1+2`、动态对照、跨模块同名信号和
条件比较测试。此处只复现厂商判断行为，不等同于证明电路已经具有硬件复位。

候选归属和状态清表、过程 +0x200 定位字段。台账保持 partial-integration，
完整专有前端等价仍为 0/209。本轮修改尚未作为新版本发布。
