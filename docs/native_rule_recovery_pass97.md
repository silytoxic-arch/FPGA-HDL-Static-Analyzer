# 第九十七轮：常量位宽调整核对

同一目标 SHA-256 `60e6b52875f4d7c3fbdf494d869b3a4bcc3fdc8ee63d8620ea9614da5d6599b0`，
静态分析未执行目标。

FUN_1800d2860 在请求长度小于位向量长度时直接将 end 设为 begin+length，
因此按低位在前的布局丢弃高位。长度增加时，逐字节复制传入的填充值，再更新 end。
这补齐第九十六轮显式宽度截断/填充入口的实现证据。

二态数字在转换入口以 0 扩充至显式宽度；随后若带 s，常量缓存构造器才按调整后
的最高位扩展至 32 位。所以 `1'b10` 缓存为 0、`1'b11` 为 1、`1'sb1` 为
0xffffffff。大于 32 位的数值保持位向量，R-6-3 只读取其低 32 位缓存。

原始摘录见 `reverse-tools/evidence/t_linter_pass97/vector_resize.txt`。
本轮补充证据，不将此窄路径推广成完整前端等价或四态转换恢复。
