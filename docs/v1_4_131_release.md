## 原生证据与产品接入

- `FUN_1804d24a0` 不仅扫描直接 ELSIF，还会进入 ELSE 的直属 BLOCK，寻找带源码 IF 链接标志的 lowered CASE，并从其直接条件提取边沿。
- 前置非边沿分支存在 `FUN_1804d20e0` 证明的常量动作时，该关系归入主函数会消费的类别 1；否则仍是主函数明确忽略的类别 4。

- ELSE 中存在前置语句、多候选嵌套 IF 或其他复杂降低形态时不猜测，继续保持人工复核。
