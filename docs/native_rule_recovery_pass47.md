# 第四十七轮：A-1-8 工程级注释率生产链

本轮按官方索引使用三段式编号 `A-1-8`，内部条款键仅用于实现与证据关联；未进行表格或界面格式调整。

## 新恢复事实

- 原生入口对整个工程只维护一组总行数与注释行数，并在所有设计根扫描结束后只比较一次。
- Verilog `+0xa8` 映射仅接纳唯一同名 `AST_MODULE` 根；VHDL/另一前端通过独立的 `+0x78` 映射加入同一累计。
- 同一文件拥有多个设计根时按根数重复计权；空行进入分母。
- 扫描器仅删除空格和 Tab，然后原样搜索 `//`、`--`、`/*...*/`，字符串里的标记也会计数。
- 阈值为 20%，严重度为 Error，固定位置为空文件路径第 1 行，固定正文为“该工程代码注释率小于20%”。

## 产品变更

- 删除逐源码独立判断，改为标准后处理阶段的工程级聚合。
- 接入唯一 Verilog 模块根、VHDL 设计根和多根文件计权。
- 对重复 VHDL 实体键、预处理失败等未恢复边界停止判断，不伪判合规。
- 增加项目聚合、重复计权、字符串原始标记、混合 Verilog/VHDL 根及固定诊断回归。
- 台账将该规则提升为“证据支持的核心判据；集成源码适配器”。
