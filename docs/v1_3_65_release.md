# FPGA HDL Static Analyzer V1.3.65

## GJB9765.4.6.g / 4.10.b

两条规则的原生 vtable slot 0 均指向 `FUN_180650a90`。共享入口通过 `FUN_180652070` 建立复位/置位关系，随后比较到达同一寄存器的异步控制源；源名称相同时进入报告路径。

产品接入的已证实源码形态为：同一进程、时钟事件之前存在两个异步 `if/elsif` 分支，两个分支使用同一控制信号并驱动同一赋值目标。该条件同时映射到：

- `GJB9765.4.6.g`：同一信号源驱动同一寄存器的多个异步控制端；
- `GJB9765.4.10.b`：复位与置位信号来自同一个信号。

附件违反例中，外部 `RST` 和组合信号 `int_async_sig` 各命中一次，两条规则均报告 2 处；正确例使用不同的复位/置位源，两条规则均为零告警。证据见 [共享异步控制恢复记录](evidence/native_vhdl_shared_async_control_4_6_g_4_10_b_findings.md)。
