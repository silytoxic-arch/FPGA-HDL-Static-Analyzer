# FPGA HDL Static Analyzer V1.4.19

## GJB9765.4.14.c.2 原生逐字节判据修正

DLL 静态证据确认该规则不是标准 VHDL 词法检查。原生代码按 `fgets(..., 0xff, ...)`
读取原始文本块，在首个字面 `--` 处停止，并检查每个 `<=`、`:=` 紧邻两侧是否均为
ASCII 空格或 Tab。V1.4.19 已恢复其核心判断：

- 字符串中的赋值运算符同样参与检查；
- 字符串中的 `--` 也会使本行余下内容停止检查；
- 换页等其他空白不再被错误接受；
- 每个缺少左侧或右侧分隔的运算符独立报告 Warning；
- 注释截断后的文本不报告。

新增字符串、字面双连字符、Tab 与 form-feed 边界测试。原生 254 字节读取块边界、重复源
记录、文本模式及完整诊断排序尚无充分运行态证据，因此无告警继续保持
`ManualReviewRequired`，不宣称完整算法等价。证据见
[4.14.c.2 逆向记录](evidence/native_vhdl_assignment_spacing_4_14_c_2_findings.md)。
