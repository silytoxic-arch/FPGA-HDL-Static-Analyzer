# FPGA HDL Static Analyzer V1.4.90

本版本只推进规则逆向、判断逻辑和验证，不调整界面或表格布局。

## 本轮规则

- 官方公开编号：`A-2-2`
- 内部标准映射：`GJB10157.5.2.12`
- 主题：Verilog 声明名称长度。

## 准确性修正

- 从 DLL 恢复模块名映射入口、六类 AST 选择器及函数排除边界。
- 默认上下限为包含端点的 2..32 字节；按原生有符号扩展后无符号比较还原负数和倒置边界。
- 同名模块包含多个根时，完整模块组及其后代跳过检查。
- 还原 Error 严重度、物理行定位和完整原生消息。
- 活动预处理分支继续使用有界源适配器；外部配置写入路径尚未恢复，无告警仍需人工复核。
