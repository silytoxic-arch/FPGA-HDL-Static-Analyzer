# FPGA HDL Static Analyzer V1.4.171

## 本轮目标

恢复 GJB10157 官方规则 `R-12-2`（内部条款键 `GJB10157.9.3.2`）的循环体算术标识符收集、排除、去重和定位逻辑。本版不调整界面和表格。

## 新恢复的原生行为

- `FUN_180586120` 只接收四子节点、块体为 `AST_BLOCK(0x54)` 的 `AST_FOR(0x5c)`。
- 精确算术节点集合为 `AST_ADD/SUB/MUL/DIV/MOD/POW`；每个算术节点下的全部 `AST_IDENTIFIER` 后代进入候选集合。
- `FUN_180580440` 以 AST 标识符节点指针为键：嵌套父子算术重复访问同一节点时去重，不同源码出现位置即使同名仍分别报告。
- 候选名称等于循环计数器或模块参数/localparam 时排除；诊断定位到候选标识符自身，而不是运算符。
- 原生 GBK 消息模板确认为“禁止在for语句中对循环变量值%s之外的变量%s进行算术运算.”。

## 产品修正与测试

- 从“只看运算符相邻操作数、按运算符报警”改为递归分析完整表达式范围，按标识符 token 出现位置报警。
- 支持嵌套算术、一个表达式中的多个运行时变量、选择/索引内变量、条件表达式与内联 `integer` 循环计数器。
- 嵌套 `for` 的头部不归入外层循环体判定，但嵌套循环体继续按各自循环规则分析。
- 新增 `(d+1)*w`、`d+w`、同名变量两次出现、`d[k]+1`、嵌套循环头部和内联计数器边界测试。
- 未恢复路径与所有无告警结果继续保持 `ManualReviewRequired`。
