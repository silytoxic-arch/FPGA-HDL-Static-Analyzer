# FPGA HDL Static Analyzer V1.4.169

## 本轮目标

恢复 GJB10157 官方规则 `R-12-4`（内部条款键 `GJB10157.9.3.4`）中 `is_count_zero` 属性的前端生成逻辑，并修正附件参数与宏零次循环漏检。本版不调整界面和表格。

## 新恢复的原生行为

- `is_count_zero` 字符串只有消费函数和前端生成函数两个静态引用。
- 前端对 `AST_FOR` 条件复制并反复常量化；第一次测试结果的常量整数域为 0 时写入属性。
- 属性记录使用原始 FOR 的源路径和物理行，并在循环体展开前结束该路径。
- 因此规则覆盖前端能折叠的参数、定宽常量和 generate FOR，不限于两个源码十进制字面量。

## 产品修正与测试

- 支持定宽/不定宽二、八、十、十六进制整数。
- 支持直接参数/局部参数默认值和单行对象数值宏。
- 支持计数器出现在比较任一侧，并严格按第一次条件值判断。
- 新增附件参数、对象宏 generate、定宽参数、反向比较和原有条件编译边界测试。
- 未支持的完整常量折叠和无告警结果继续保持 `ManualReviewRequired`。
