# FPGA HDL Static Analyzer V1.3.94

本版恢复 GJB10157.7.2.1 的原生组合回路路径，并扩展基本门实例检测。

## 变化

确认原生 slot 0 为通向通用组合回路工作函数的跳转桩；沿其输入/输出依赖、强连通分量及最终报告路径，补入标量基本门实例的组合反馈检查。两门交叉耦合与三门及更大的环均可报告；7.2.2 仍单独应用其“超过两个指定门则跳过”的条件。已有连续赋值回路报告会按模块和分量代表信号复用，避免重复输出。

新增五项边界断言：连续反馈去重、两 NAND 门回路、较大连续回路、三 NOR 实例回路、无环基本门链。证据见 [7.2.1 恢复记录](evidence/native_verilog_combinational_loop_7_2_1_findings.md)。

6.2.5 补充了通用构造函数、登记函数、默认分支查找及赋值目标收集证据，并确认 `+0x140` 的写入入口为导出 API `setMaxStatesNum`；调用参数来源和非 SRAM 适用性仍需追踪，继续人工复核。

## 当前状态

204/209 条规则已有证据支持的原生核心谓词部分接入；剩余五条为 GJB10157.5.1.7、5.2.8、6.2.5、6.2.10 和 GJB9765.4.2.e。完整厂商算法等价仍未宣称完成，未知逻辑和缺少工程上下文的无告警结果保留复核。

- 附件 446 个文档示例：435 个匹配，11 个既有差异；7.2.1 的四个示例均保持匹配。
