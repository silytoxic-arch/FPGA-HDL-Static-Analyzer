## GJB9765.4.6.i

原生 slot 0 分别收集条件三态门的控制信号和架构直接子级中的组合表达式输出，通过连接记录传播后求交。产品接入同一来源模型：识别并发逻辑、算术及条件表达式形成的信号，沿直接标识符别名传播，并在其用于 `data when control='0/1' else 'Z'` 时报告。实体输入、时序进程寄存器输出和未解析 component 输出不猜测为组合逻辑。

完整层级连接、厂商原语、generate/configuration、进程型组合逻辑和其他三态编码尚未恢复，不判为合规。详见 [恢复记录](evidence/native_vhdl_combinational_tristate_enable_4_6_i_findings.md)。
