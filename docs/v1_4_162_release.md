# FPGA HDL Static Analyzer V1.4.162

## 本轮目标

继续恢复 GJB10157 `R-5-3` 与 `A-5-2` 共享原生函数 `FUN_180758410` 的诊断重数与去重所有权。本版不调整界面或表格。

## 新恢复的原生行为

- 访问名称树只在把别名源加入下一工作集前查询，用于防止关系名称重复遍历和循环。
- 当前关系名称对应的赋值记录逐个处理；每个非别名连续赋值或组合过程赋值都会独立进入诊断构造。
- 诊断块中没有按目标名称或物理行执行合并，因此同一行的两个独立赋值节点应输出两条诊断。
- 两条别名路径汇聚到同一个上游来源名称时，访问树会使该来源只遍历一次。

## 产品实现与回归

- 将诊断去重键从“目标名称+行号”收窄为具体赋值目标 token，即每个源赋值节点最多一次。
- 新增同一物理行两个 `comb_rst` 非别名驱动，验证两条规则各报告两次。
- 新增两个异步复位别名分别直接/反相汇聚到同一 `logic_rst`，验证两条规则各只报告一次。
- 多级别名、组合过程上游及循环终止回归继续保留。
- 无诊断路径仍保持 `ManualReviewRequired`，不声明完整规则合规。

- Release 构建与完整回归通过：`135/135`。
- 附件审计覆盖 544 条附件规则、537 个规则页，其中 GJB10157/GJB9765 共 209 条；执行 446 个文档样例，结果为 435 个 `Automated:matched`、6 个 `ProjectContext:matched`、4 个 `context-required` 和 1 个 `native-documentation-conflict`。
