# FPGA HDL Static Analyzer V1.4.175

## 本轮目标

修正 GJB10157 官方规则 `A-12-1` 的 repeat 变量分类。本版不调整界面和表格。

## 原生行为与产品修正

- 原生规则对 repeat 计数中的每个 identifier 逐项检查并分别报告。
- 豁免依据是同组 parameter/localparam 的平面名称表，不是词法绑定或常量表达式求值。
- 直接未知普通名称不在参数表中，因此需要报告。
- 同一组中只要存在同名参数，块变量或 function 参数的同名遮蔽仍被豁免。
- 产品现以 owning module 作为有界分组，按原生平面表和逐出现重数执行。
- 用户可见编号严格为官方三段式 `A-12-1`；内部条款键不作为规则编号显示。

## 未闭合边界

厂商分组键、完整宏/include/generate 展开、限定名称、系统查询、调用节点降级、参数覆盖和错误恢复仍未完全恢复。相关无告警结果继续保持 `ManualReviewRequired`。
