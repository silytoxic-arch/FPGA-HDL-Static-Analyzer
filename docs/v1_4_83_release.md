# V1.4.83：R-2-7 include 路径原生次数语义闭环

本轮只深化规则判断，不修改界面或表格布局。公开编号使用官方三段式 `R-2-7`。

## 原生恢复

- 原生入口 `FUN_18053afd0` 遍历规则对象 `+0x68` 的模块名称映射；只有映射值恰含一个非空 `AST_MODULE(2)` 根时，才打开该根 `+0x1e0` 保存的源文件。
- 每个物理行先匹配精确八字节 `` `include``，再匹配同行任意位置的冒号；它不是 HDL 词法检查，也不是通用绝对路径识别。
- 同一文件中的不同唯一模块会重复打开文件并保留相同诊断；同名重复模块组因根向量长度不为 1 而被跳过；无模块文件不扫描。
- 恢复出原生 `error` 级别及 GB18030 消息“文件引用时,必须使用相对路径而不是绝对路径”。
- 详细证据见 [R-2-7 原生证据](evidence/native_verilog_include_path_5_2_7_findings.md)。

## 产品接入

- 按全工程解析后的模块名统计定义次数，并按每个源文件中的唯一模块数保留原生重复扫描语义。
- 保留注释、字符串、畸形指令、未激活条件分支和路径外冒号均可触发的原生原始字节边界。
- Unix 斜杠绝对路径没有冒号，仍按原生谓词排除；列号作为产品必需字段固定为 1。
- 无告警结果仍为 `ManualReviewRequired`；生成模块、宏/include 产生的 AST 根归属、文件打开失败和完整厂商前端仍未恢复。
