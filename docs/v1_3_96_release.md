# FPGA HDL Static Analyzer V1.3.96

本版完成 GJB9765.4.2.e 不可达无符号比较的原生核心判据恢复与独立接入，并补充 GJB10157.6.2.10 的原生分组计数证据。

## 规则准确性

GJB9765.4.2.e 不再复用过宽的通用常量条件映射。原生 DLL 的直接关系比较路径已恢复：对固定宽度无符号信号，等于或大于等于超上界常量、以及大于等于上界常量的不可达形式进行报告；不交换操作数，也不把 LT、LE、NE 或任意常量条件归入本条。

产品实现承认证据覆盖的直接名称、固定 unsigned/std_logic_unsigned 位宽和十进制常量。signed、复合操作数、泛型位宽、局部遮蔽及重载不猜测为违规或合规。详细证据见 [4.2.e 恢复记录](evidence/native_vhdl_unreachable_comparison_4_2_e_findings.md)。

GJB10157.6.2.10 的入口现已证明按过程内的分组容器计数：每组只要存在首字节标记 1 就计一次，超过一个分组才报警。标记生产路径仍未恢复，因此现有附件支持的源代码子集暂不提升为原生核心。详见 [6.2.10 恢复补充](evidence/native_verilog_multiple_reset_6_2_10_findings.md)。

## 当前状态

209 条规则中，206 条已有证据支持的原生核心谓词部分接入；剩余 GJB10157.5.1.7、5.2.8、6.2.10 三条继续恢复。完整算法等价验证仍为 0 条，无告警结果继续保持人工复核。
