# GJB10157.7.1.3 复位触发边沿与进入条件极性原生判据

## Recovered predicate

目标为用户附件中的 `T-Linter.dll`，SHA-256 为
`60e6b52875f4d7c3fbdf494d869b3a4bcc3fdc8ee63d8620ea9614da5d6599b0`。

静态逆向观察到：

- `GJB10157_VLOG_7_1_3` 构造函数位于 `0x180022a90`；
- slot 0 为 `FUN_1805629e0`（`0x1805629e0`），证据
  `ev_5227f8580d7594cfd1ce8c4870778518f68bfc4c2bd6d9667b892eb70eb9cacb`；
- slot 1 为 `FUN_180564050`，它直接委托给边沿触发 `always` 过滤器
  `FUN_1804e6df0`，证据
  `ev_16b894aa8c8c4e639d06ec49e60914d47df3cf0a8dc74fe48f5c0a9f0c8c24a3`；
- 主函数遍历 `AST_POSEDGE/AST_NEGEDGE(0x65/0x66)`，以事件信号名称为键记录
  上升沿/下降沿极性；
- `FUN_180562930` 复制关系名称，并保留其极性字节；
- 主函数随后遍历 `IF(0x57)` 节点，对直接标识符、前缀取反标识符以及标识符与
  一位常量的相等比较进行名称和极性比对；
- 条件表达的有效电平与事件边沿极性相反时进入诊断构造路径。

附件错误例中的 `posedge RST` 配合 `RST==1'b0`、`negedge RST` 配合
`RST==1'b1` 均被标记；正确例分别使用高有效和低有效的匹配条件。

## Product integration boundary

产品在条件预处理后的 Verilog/SystemVerilog 源码中检查边沿触发 `always`，为每个
简单事件标识符建立极性，并检查其作用域内以下确定条件：

- `if (RST)`；
- `if (!RST)`；
- `if (RST == <整数常量>)` 及常量位于左侧的等价写法；
- 有/无尺寸二/八/十/十六进制整数字面量及单 token 的 `'0`/`'1`/`'x`/`'z`。

第九十六至九十七轮确认相等分支比较常量缓存的低 32 位整数与 0/1，不进行布尔
真值转换。接入显式宽度截断和有符号扩展；如 `1'sb1` 为 0xffffffff，不能当作 1。
对应证据、24 种字面量的双边沿双方向测试见两轮记录。

第九十八轮用指令补齐 X/Z/? 的标记与状态转换：它们在位向量中为 2/3/4，缓存
构造器仅对状态 1 置位，因而保留混合字面量中的确定 1 位。产品恢复这一原生缓存
行为，不将其解释为 HDL 四态逻辑中的 X=0。矩阵扩展为 48 种形态、192 个场景。

第九十九轮补齐 Primary/Mintypmax 的静态转交链：普通括号保留内部节点，
min:typ:max 选择中项。比较两侧与 ! 操作数使用相同转交，保留内部节点源行。
事件按完整表达式类型过滤，复合表达式不再仅凭首个名字入选；带选择范围的
标识符按原生保留的名称比较，不据此认定不同位具有同一复位语义。

第一百至一百零一轮追踪模块目录、第一阶段快照、第二阶段指针追加及原生
proc_arst 分支。R-6-3 的事件名须先出现在电平敏感复位目录中。产品加入必要
边界：结构明确的完整叶模块只有单边沿过程时，不凭这些事件产生复位极性报告；
多个单边沿过程不能合并、模块目录不能跨模块生效。完整复位名称映射仍待接入。

第一百零二至一百零三轮绑定根匹配器的单比特入口、直接同步信号匹配、8 类
组合节点及 A/B/Y 端口 ID。产品对全部多边沿过程均可恢复的简单叶模块建立
模块复位名称表，并据此排除普通时钟；复杂或未解析模块不据此发布完整名称表。
分支、位宽及别名边界详见两轮记录，完整复位图仍待恢复。

第一百零四轮扩展为同一复位控制多个唯一赋值目标，按目标名逐个对应两侧分支，
支持顺序变化、普通嵌套块和空语句；缺失、重复或不支持目标保持目录未知。
第一百零五至一百零六轮保留等式降低证据边界，并修正 AstModule 派生克隆入口
解释，不将基类虚表当作全部动态派发的证明。

第九十三轮确认原生只分派逻辑取反 0x47，位取反 0x24 不进入该分支，因此移除
此前 `~RST` 的适配。报告固定 Warning 和正文 `复位信号的触发条件与进入条件必须一致.`，
每个独立 IF 保留一条报告，包括同一物理行的不同 IF。原始证据及定位限制见
`docs/native_rule_recovery_pass93.md`。

第九十四至九十五轮补齐行号回调及条件生产者。原生相等分支定位到常量一侧，
直接标识符与逻辑取反分支定位到对应条件节点。产品现映射为常量、标识符或 `!`
所在行及第 1 列，不再统一采用 IF 行列。依据见两轮记录及原始绑定摘录。

复合布尔条件、`!=`/case equality、别名传播、宏生成的事件、generate、层次关系、
完整原生前端降级方式、宏/合成节点位置映射及综合关系仍未恢复。
未知条件不报告；无诊断保持
