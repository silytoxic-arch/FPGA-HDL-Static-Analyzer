# GJB 规则公开编号映射记录

## 结论

产品公开编号统一使用三段式 `R-X-X` / `A-X-X`，完整 GJB 条款号仅作为内部追溯键保留。公开编号的第二段为规则组，第三段为该组内同类准则的数字序号，不再把条款字母或嵌套点号拼入编号。

示例：

- `GJB9765.4.2.a` -> `R-2-1`
- `GJB9765.4.8.e` -> `A-8-1`
- `GJB9765.4.5.f.2` -> `A-5-3`
- `GJB10157.5.2.1` -> `R-2-1`

## 映射原则

- `R` 表示强制准则，`A` 表示建议准则；
- 同一规则组内，强制准则与建议准则分别编号；
- 附件规则集没有收录、但在标准顺序中实际存在的条目保留编号空档；例如 9765 的 `4.11.b` 未出现在 106 条附件规则入口中，所以 `4.11.c` 仍映射为 `R-11-3`，不能压缩成 `R-11-2`；
- 两个标准属于不同规则配置文件，可以各自存在 `R-2-1`。跨标准持久化、抑制和追溯仍使用完整条款号，避免歧义；
- 映射采用显式表，不再由条款字符串机械推导。

## 证据边界

观察事实：附件 PDF 明确给出每条准则的章节顺序和“强制准则 / 建议准则”属性；附件 T-Linter 规则入口给出当前产品需要覆盖的 103 条 Verilog 与 106 条 VHDL 条款集合。

实现解释：依据上述顺序与属性建立数字化三段索引，并保留附件规则集未收录条目的位置空档。

未知项：附件规则入口并不覆盖标准正文中的所有条目，因此没有入口的规则仍不加入当前 209 条检测清单，也不声明已经实现。
