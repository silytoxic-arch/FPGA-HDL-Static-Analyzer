## 已观察事实

- 构造函数 `0x1800221e0` 安装最终虚表 `0x180edb800`，规则键为
  `GJB10157_VLOG.6.1.3`；slot 0 是 `FUN_18054de80`，slot 1 是
  `FUN_18054ed80`。
- slot 1 接受 `AST_ASSIGN(0x4d)`；对 `AST_ALWAYS(0x52)`，只要任一直系
  子节点为 `AST_POSEDGE(0x65)` 或 `AST_NEGEDGE(0x66)` 就拒绝，其余节点类型
  拒绝。
- slot 0 对准入的组合过程递归收集 `AST_ASSIGN_EQ(0x55)` 和
  `AST_ASSIGN_LE(0x56)`。连续 `AST_ASSIGN` 必须至少有两个子节点，且 RHS 根节点
  不能是 `AST_IDENTIFIER(0x13)`，所以直接时钟别名不属于本规则。
- 候选赋值的第一个子节点必须是 `AST_IDENTIFIER`。归一化后的目标名称与展开后
  的时钟关系名称相等时成为命中候选。
- 命中候选通过 `FUN_180242200` 构造节点，再由 `FUN_1800d6580` 插入以目标名称
  为字符串键的红黑树；重复键的载荷由 `FUN_1800da640` 释放。因此同一时钟名称
  有多个组合驱动时只保留首个候选并报告一次。
- 报告使用保留候选 AST 的来源和物理行，不写入列。严重度为 `Warning`。
- GB18030 字符串 `0x180ef0610` 与 `0x180ef0600` 拼接为精确正文：
  `禁止将组合逻辑的输出<名称>作为时钟信号`，无句号。
- 附件示例只标记组合驱动赋值行，而不是后续使用该信号的边沿过程行。
