# GJB10157.6.2.2 原生同步/异步复位混用判据恢复记录

## Recovered predicate

过滤槽只接收 `AST_MODULE(2)`。主函数首先从全局展开关系构造并去重一个 32 字节
字符串记录向量；结合条款、示例和后续使用，该向量是已知异步复位名称集合。

随后函数对目标模块收集 `AST_ALWAYS(0x52)`，对每个过程：

1. 收集 `AST_POSEDGE(0x65)` 与 `AST_NEGEDGE(0x66)`，仅保留恰好一个边沿事件的过程；
2. 收集 `AST_REDUCE_BOOL(0x2d)` 条件节点，并取第一个条件；
3. 在条件下收集 `AST_IDENTIFIER(0x13)`；
4. 规范化标识符名称并在异步复位名称向量中查找；
5. 命中时在该条件标识符位置构造告警。

这与附件违规例一致：`RST` 在一个双边沿事件过程内作为异步复位，又在只有
`posedge CLK` 的过程中作为条件复位。合规例仅异步使用 `RST`。

## 产品映射与验证边界

产品已有的 `RTL-MIXED-RESET-MODE` 为该谓词的有界源代码模型：同一设计单元内，
同名复位同时具有 `asynchronousObserved` 和 `synchronousObserved` 时映射到
`GJB10157.6.2.2`。

- 正例：同一 `RST` 一处异步、一处同步使用。
- 反例：同一 `RST` 多次异步使用。
- 边界反例：异步使用 `RST`，同步过程使用不同的 `RST2`。
- 无告警状态仍为 `ManualReviewRequired`。
