## 已观察的原生判据

- `0x180581e80` 只接纳 AST_CASE (`0x57`)；该路径不接纳
  AST_CONDX/AST_CONDZ (`0x59`/`0x5a`)。
- `0x180581ee2` 把 Windows x64 第五参数栈槽置为 0，
  `0x180581ef7` 调用 `FUN_1808f4650` 推断选择器宽度。
- `0x180581f22` 要求分支组为 AST_COND (`0x58`)；
  `0x180581f37` 跳过首子项为 AST_DEFAULT (`0x5b`) 的组；
  `0x180581f52` 跳过只有一个 AST_BLOCK (`0x54`) 子项的组。
- 原生代码遍历分支组的每个子项，`0x180581f83` 跳过 AST_BLOCK；
  因而同一分支中的多个选择标签分别判断，而不是只判断第一个。
- `0x180581f95` 再次把第五参数置为 0，`0x180581fa7` 对选择项调用同一
  位宽辅助器。
- `0x180581fb0` 先比较选择器和选择项宽度，相等时在 `0x180581fb4`
  跳过；不相等后，`0x180581fba` 才把选择项宽度与 `-1` 比较，并在
  `0x180581fbd` 跳过未知选择项。因此未知门控是不对称的：选择项为
  `-1` 时不告警；选择器为 `-1`、选择项已知时仍进入告警路径。

## 产品映射

产品撤销本条对通用 case 字面量/取值范围诊断的间接映射，改用专用适配器。
适配器在配置的条件预处理之后：

- 只遍历普通 `case`，排除 `casez` 和 `casex`；
- 对选择器和每个非 default 标签使用已恢复的 flag-zero 有界表达式位宽模型；
- 支持固定宽度信号与选择、显式位宽字面量、连接、静态重复连接、位运算和
  有界算术表达式；乘法按 flag-zero 取子项最大宽度；
- 在不存在实例参数覆写歧义时解析固定数值参数默认值，包括定宽进制字面量；
- 对同一分支的多个标签逐项判断，并独立处理嵌套普通 `case`；
- 选择项宽度未知时跳过；选择器宽度未知但选择项已知时按原生分支报告；
- 未激活的条件编译分支不参与判断。

## 验证边界

新增正反例和边界回归覆盖命名选择项、等宽/不等宽连接、乘法 flag-zero、
未知选择器、未知函数调用选择项、多标签、嵌套 case、casez 排除和条件编译。

仍未知：函数返回宽度、强制转换、动态选择、完整参数覆写/宏/生成展开、原生前端
对复杂表达式的 AST 归一化、源位置和诊断去重策略。产品不推断未知选择项；
无告警不等于已证明合规，也不宣称完整原生算法等价。
