# R-5-1 异步复位连接到非复位端原生判据

目标为用户附件中的 `T-Linter.dll`，SHA-256 为
`60e6b52875f4d7c3fbdf494d869b3a4bcc3fdc8ee63d8620ea9614da5d6599b0`。以下结论来自静态分析，未执行目标文件。

## 已观察事实

- 构造函数 `0x1800224c0` 先注册旧键 `VLR-110026`，再注册
  `GJB10157_VLOG.6.2.1`；最终虚表为 `0x180ef1068`。
- slot 0 是 `FUN_1806e8d60`；slot 1 是只接受 `AST_MODULE(2)` 的共享选择器
  `FUN_1807238a0`。
- 主函数建立异步复位/置位关系集合，遍历 `AST_ALWAYS(0x52)`、
  `AST_ASSIGN_EQ/AST_ASSIGN_LE(0x55/0x56)`、`AST_CELL(0x4f)` 和
  `AST_IDENTIFIER(0x13)`。
- 赋值数据表达式和单元实际端口中的每个匹配标识符 AST 都进入候选向量；报告阶段逐项
  消费候选，没有观察到按名称或物理行去重。
- 单元分支查询专有端口元数据，复位/置位端口被排除，其他端口上的异步控制标识符进入候选。
- 每条诊断使用候选标识符的源文件和 `+0x200` 物理行，不写列号。
- `0x180f07a48` 与 `0x180f126e0` 的 GB18030 常量组成精确正文
  `异步复位/置位信号<归一化名称>连接到非复位/置位端口`；
  `0x180ee83b0` 解码为 `警告`。

附件违规例覆盖 `D <= RST`、`.DI(RST)` 和 `assign my_logic = RST & COND[0]`；
合规例只在异步复位事件、条件和 `.RST(RST)` 使用该信号。

## 产品有界实现

- 在同一 Verilog/SystemVerilog 模块中，以解析器确认的异步控制集合检查连续赋值、
  过程赋值数据端和命名实例实际端口。
- 一个数据表达式中的每个异步控制标识符分别报告；同一物理行的多个标识符保持原生次数。
- 正文恢复为原生固定格式，位置使用标识符物理行和列 `1` 表达原生“无列”。
- 命名形式端口只有在名称明确不是 reset/rst/set/preset/clear/clr 类端口时才报告；
  明确的复位/置位形式端口不报告。
- 产品标准配置仍按 GJB 强制条款显示 `Error`；原生二进制内部标签 `警告`作为观察事实保留，
  不据此降低标准配置严重级别。
