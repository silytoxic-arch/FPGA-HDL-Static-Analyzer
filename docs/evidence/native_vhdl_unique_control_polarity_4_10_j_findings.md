## Recovered predicate

规则构造函数 `0x180024f10` 安装 vtable `0x180ef9d00` / `0x180ef9d48`，两表的
slot 0 均指向 `FUN_1806530a0`。入口通过 `FUN_1804c5890` 从类型 `0x75` 的直接子节点中
收集类型 `0x52` 的进程节点，再由共享关系构造器 `FUN_1804d56f0` 生成分类后的时钟与
异步控制关系。

主函数只遍历外层关系类别键区间 `[1, 2)`。对该类别中的每条记录，它取得规范化信号名
和整数有效电平字段，在跨进程有序表中按名称查找：首次出现时保存名称和电平；同名记录
电平相同则继续；同名记录电平不同则在后出现记录关联 AST 的 `+0x214` 行号处生成诊断。
冲突分支不替换首次保存的基准，因此后续每条与首次电平相反的记录仍可再次报告。

附件示例证明类别 1 同时覆盖 `RST` 和 `SET` 异步控制，而不仅是包含 reset/rst 的名称。
`0x180f08d58` 附近 GB18030 常量为“同一复位/置位信号”和“宜使用唯一的有效电平”。

产品继续使用时序语义模型按 VHDL 大小写不敏感名称合并有效电平，并补齐 set 类异步控制
名称。显式条件电平优先于名称后缀推断，避免单个低有效进程同时被错误记录为高、低两种
电平。产品当前每个设计单元、每个信号合并为一次诊断。

## 已验证边界

- 同一 `RST` 在不同进程分别使用高、低有效时报告。
- 同一 `SET` 在不同进程分别使用高、低有效时报告。
- `RST` 与 `SET` 各自冲突时保留两个独立信号诊断。
- 同一 `SET` 在多个进程保持相同有效电平时通过。
- 单个显式低有效 `SET='0'` 不会因名称默认值再产生虚假的高有效记录。
- 附件违规与合规样例均与预期匹配。
