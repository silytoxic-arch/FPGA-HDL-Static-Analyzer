## Recovered predicate

每个模块下遍历端口声明节点。节点只有在输入方向字节 `+0xa0` 或输出方向字节 `+0xa1` 至少一个非零时才进入类型判定，因此内部信号不属于本规则。随后原生函数对十二个布尔类型标志执行 OR：`+0xa7`、`+0xa8`、`+0x109`、`+0x29c` 至 `+0x29f`、`+0x2a2` 至 `+0x2a6`。任一标志非零即报告当前端口节点；没有按模块提前退出，所以多个违规端口分别报告。

- 向量宽度和同一声明中的多个端口不改变类型判据。

每个命中的端口节点都会独立追加结果；函数内没有首个命中即退出，也没有正文/行号去重。因此同一物理行的三个违规端口会产生三条完全相同的诊断。
