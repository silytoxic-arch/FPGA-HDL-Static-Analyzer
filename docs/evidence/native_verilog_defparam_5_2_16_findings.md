## 已观察事实

- 构造函数 `0x180021540` 安装的规则虚表中，slot 0 为 `FUN_180531530`，slot 2 为
  `FUN_180531af0`。
- slot 2 只在节点类型字段 `+4 == 0xb` 时返回真；同一附件的 AST 类型表把 `0xb`
  确认为 `AST_DEFPARAM`。
- 执行函数遍历规则对象 `+0xa8` 的候选映射，对每个映射值中的每个非空候选再次检查
  `+4 == 0xb`，随后逐节点构造诊断；循环中没有首次命中后停止或名称去重。
- 每条诊断读取节点 `+0x1e0` 的源路径和 `+0x210` 的物理行号，严重级别固定为
  `error`；没有恢复出列号字段。
- 地址 `0x180eec418` 的 20 字节 GB18030 固定消息解码为“禁止使用defparam语句”。
- 完整伪代码见 `reverse-tools/evidence/a2_6_defparam_entry.txt`，SHA-256：
  `88a7e65c08c7abb8461d656c7f88e3ccf744e118bafe623fd7aba280d03c673a`。
