## Recovered predicate

过滤槽只接收 `AST_MODULE(2)`。主函数构造复位关系记录并关联到模块中的
`AST_ALWAYS(0x52)`。对候选过程，辅助函数执行两阶段判断：

1. 在条件节点 `AST_REDUCE_BOOL(0x2d)` 下收集 `AST_IDENTIFIER(0x13)`，与复位关系
   名称集合比较；匹配标识符数量必须大于一。
2. 遍历条件分支 `AST_COND(0x58)`，从直接的阻塞/非阻塞赋值
   `AST_ASSIGN_EQ/LE(0x55/0x56)` 右值读取 `AST_CONSTANT(0x10)` 的常量值。

主函数分别统计结果向量中的 `0` 与 `1`，仅当两类值都出现时构造告警。因此该条
不是“只要存在两个异步控制就告警”，而是要求多个异步控制分支同时表现出复位
到 0 和置位到 1 两种动作。辅助函数对常量字段值小于 2 时保留原值；值大于等于
2 时向结果向量同时追加 0 和 1。嵌套 `AST_CASE` 以清零后的模式递归。

原生报告级别为固定小写 `error`，正文精确为
`always中同时使用了异步复位信号和异步置位信号`。源文件取模块/根节点路径，行号
取命中的 `AST_CASE`，不提供列号。报告后内层遍历退出，证据支持每个过程最多一条。

## 产品实现与测试

产品对显式 `always/always_ff @(...)` 的有界子集执行相同区分：边沿事件至少包含
两个在条件中出现的异步控制标识符和一个未出现在条件中的时钟代理。每个源代码
IF/ELSE 树独立计算，不能把相邻独立 IF 的常量拼接成违规。直接数值常量按 0、1、
大于等于 2 分类，最后一类同时贡献 0 和 1；命中后在第一个合格 IF 根的物理行输出
一次精确原生 `Error` 正文，产品列号映射为 1。

- 正例：`ARST1` 分支赋 0，`ARST2` 分支赋 1。
- 正例：合格条件树直接赋值 `2'b10`，复现原生值大于等于 2 的分支。
- 反例：多个异步控制合并在一个分支内且全部赋 0。
- 反例：多个异步控制合并在一个分支内且全部赋 1。
- 反例：两个独立相邻 IF 分别赋 0、1，不能跨树合并。
- 无告警状态仍为 `ManualReviewRequired`。
