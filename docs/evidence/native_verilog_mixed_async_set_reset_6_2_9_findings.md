## Recovered predicate

过滤槽只接收 `AST_MODULE(2)`。主函数构造复位关系记录并关联到模块中的
`AST_ALWAYS(0x52)`。对候选过程，辅助函数执行两阶段判断：

1. 在条件节点 `AST_REDUCE_BOOL(0x2d)` 下收集 `AST_IDENTIFIER(0x13)`，与复位关系
   名称集合比较；匹配标识符数量必须大于一。
2. 遍历条件分支 `AST_COND(0x58)`，从直接的阻塞/非阻塞赋值
   `AST_ASSIGN_EQ/LE(0x55/0x56)` 右值读取 `AST_CONSTANT(0x10)` 的常量值。

主函数分别统计结果向量中的 `0` 与 `1`，仅当两类值都出现时构造告警。因此该条
不是“只要存在两个异步控制就告警”，而是要求多个异步控制分支同时表现出复位
到 0 和置位到 1 两种动作。

## 产品实现与测试

产品对显式 `always @(...)` 的有界子集执行相同区分：事件列表至少包含两个被条件
保护的异步控制和一个未被保护的时钟，且这些复位分支直接赋值的单比特常量集合
同时包含 0、1 时报告一次。

- 正例：`ARST1` 分支赋 0，`ARST2` 分支赋 1。
- 反例：多个异步控制合并在一个分支内且全部赋 0。
- 反例：多个异步控制合并在一个分支内且全部赋 1。
- 无告警状态仍为 `ManualReviewRequired`。
