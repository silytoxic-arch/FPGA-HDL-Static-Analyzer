## 已观察事实

- `FUN_18052f910` 从内部关系记录收集规范化名称，只接收首字节小于 2 的关系类别，并按名称字节去重；随后把名称解析回候选 AST 记录。
- 小写名称必须以 `rst_` 或 `reset_` 开始，并满足以下任一条件：第一次 `_n`/`_p` 出现在长度减 2 的位置；或包含 `_n_`/`_p_`。
- 大写分支必须以 `RST_` 或 `Reset_` 开始，极性标记对应为 `_N`、`_P`、`_N_`、`_P_`。
- 后缀判断使用从偏移 0 开始的第一次 `find`。因此 `rst_nx_n` 和 `RST_NX_N` 虽以正确标记结尾，仍因更早的非后缀标记而失败。
- 每个去重后的失败候选输出一次，固定严重级别为 `error`；位置取候选 AST 的源路径 `+0x1e0` 和物理行 `+0x210`，未发现列字段。
- 消息由 GB18030 前缀、规范化名称和后缀构成：`复位信号<名称>命名应采用“RST_X”、“Reset_X”、“rst_x”或者“reset_x”，其中“x”为“p”时代表高电平复位，“x”为“n”时代表低电平复位`。
- 附件正文中的 `Rst_X` 与 DLL 字面量及 DLL 自带消息的 `RST_X` 不一致；产品遵循二进制证据。
