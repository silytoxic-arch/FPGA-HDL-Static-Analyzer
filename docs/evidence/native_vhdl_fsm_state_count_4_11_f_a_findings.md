## FUN_1805b7860

规则对每个设计根调用 `FUN_18019e860`，获得一组已恢复的 FSM 对象。对每个对象，入口读取 `+0x98` 至 `+0xa0` 的连续记录区间，以 32 字节为步长计算记录数：

`(+0xa0 - +0x98) >> 5`

仅当记录数严格大于 `0x28`（40）时输出告警。等于 40 不报警。规则没有在入口读取枚举声明条目数，也没有按目标状态集合计数。附件 `.rdata` 中的中文诊断文本同样以“少于 40”为边界。

附件错误例的枚举声明含重复 `ST_S1/ST_S2/ST_S3`，case 中还含未声明的 `ST_12`，但仍在状态类型声明行标记违规；其 case 具有超过 40 个不同的非 `others` 转换源标签。该对照支持“恢复对象中的转换源记录数”在严格枚举合法性失败时仍可用于 f.a，而不能据此认为该模型适用于编码或可达性规则。

## FUN_18019e860

该帮助函数构造包含转换、名称映射和编码分类的 FSM 对象；其完整控制流较大，本轮只确认 `FUN_1805b7860` 使用的 32 字节记录区间来自恢复对象，而不是直接扫描类型声明。已有相邻 f.b/f.c 证据表明同一对象还保存独立编码字段，因此状态数量和编码判断不能共用“语义有效”门槛。
