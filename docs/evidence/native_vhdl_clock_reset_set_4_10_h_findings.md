## Documented constant-action branch（已撤回推断）

附件把纯 rising_edge(clk) 下的 dout <= '0' 标为违反；此前为了吻合这个例子，
产品增加了文档驱动的纯常量动作分支。第一百二十七轮恢复实际前端和收集器后确认，
边沿调用生成 0x65/0x66，而 EQ 控制收集路径要求已有 0x36 条件；直接常量赋值
不会单独生成本规则的复位条件。该额外报警分支已删除。
