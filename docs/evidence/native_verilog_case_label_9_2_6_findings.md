1. 分支必须是 `AST_COND/AST_CONDX/AST_CONDZ(0x58..0x5a)`；
2. 只读取该分支的第一个直接子节点；
3. 第一个子节点为 `AST_CONSTANT(0x10)`、`AST_REALVALUE(0x11)`、`AST_BLOCK(0x54)` 或 `AST_DEFAULT(0x5b)` 时不报告；
4. 其他第一个子节点输出一条 Warning，位置来自分支节点本身；
5. 函数继续扫描后续分支，因此诊断粒度是“每个不合格 case item 一条”。

最关键的新边界是：同一 case item 中逗号后的第二、第三个选择值不参与本规则决策。形如 `0, runtime_signal:` 的分支不会因为后面的变量产生原生诊断；形如 `runtime_signal, 0:` 的分支输出一条。

## 产品修正

旧适配器会逐段扫描所有逗号分隔选择值，并在第一项为常量、后续项为变量时报警，超出了 DLL 的明确判据。本轮已改为：

- 只分析每个 item 的第一项；
- 第一项含已证明的运行时依赖时，按 item 起点输出一条；
- 后续选择值不再产生本规则诊断；
- 两个 item 的第一项均为运行时对象时输出两条；
- 常量折叠阶段、未解析名字和复杂语法未知时保持 `ManualReviewRequired`。

新增单元与集成回归覆盖常量在前、变量在前、多分支、拼接内部逗号、三元表达式、嵌套 case 和条件预处理。
