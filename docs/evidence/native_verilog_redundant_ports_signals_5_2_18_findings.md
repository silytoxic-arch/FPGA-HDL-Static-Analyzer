# GJB10157.5.2.18 冗余端口与内部信号原生判据

## Recovered predicate

目标为用户附件中的 `T-Linter.dll`，SHA-256 为
`60e6b52875f4d7c3fbdf494d869b3a4bcc3fdc8ee63d8620ea9614da5d6599b0`。

- 构造函数为 `0x180021660`；slot 0 为 `FUN_180533200`，静态反编译证据为
  `ev_c23e1dd474e34320a04313e6aa3afdf5242bad24898eb80fb524c4f680f3ab79`；
- slot 2 为模块过滤器 `FUN_1807238a0`，接纳 `AST_MODULE(2)`，证据为
  `ev_aaa493aac258e6c8e9f4d04fcd2ebeb575f37e5d55e363a21c32a358a3f3965b`；
- 主函数要求收集结果恰好包含一个 module 根，然后递归收集 `AST_WIRE(6)` 声明；
- 方向字节 `+0xa0/+0xa1` 均为零的声明进入内部候选分支，端口类声明进入另一候选分支；
  内部候选还受声明字段 `+0xa2/+0xa4` 组合约束；
- 函数收集 `AST_ASSIGN(0x4d)`、`AST_ASSIGN_EQ(0x55)`、`AST_ASSIGN_LE(0x56)`、
  cell 类结点 `0x4f` 与 `AST_IDENTIFIER(0x13)`，通过多个名称/位置关系表传播使用关系；
- `FUN_180532db0` 递归收集给定子树中的 `AST_IDENTIFIER`，只把名称已在
  候选表中的记录插入使用集；赋值分支对左值另行记录驱动位置，并只对
  右值调用该递归收集器；
- cell 分支在可解析子模块时逐个匹配 formal/actual：子模块纯输出 formal
  对应的 actual 进入驱动位置集，输入/inout formal 对应的 actual 进入使用集；
  无法解析子模块时保守地把 actual 记为使用；
- 最终分别遍历端口候选集和内部候选集，只对未出现在使用关系结果中的记录报告；
- 构造函数 `0x180021660` 在规则对象 `+0x158` 一次写入小端字 `0x0001`，
  因此附件默认值为 `+0x158=1` / `+0x159=0`：开启附加内部信号分支，并选择
  `冗余的端口` / `冗余的内部信号` 两条原生 GB18030 消息；另一组
  `未使用端口` / `未使用信号` 只在 `+0x159!=0` 时选中；
- 附件错误例中的 `my_sig1/my_sig2` 被驱动但没有负载；正确例通过
  `assign G = my_sig1 & my_sig2` 建立使用关系。

新增离线证据：

- `reverse-tools/evidence/a2_8_constructor_messages.txt`：构造函数写入、四条消息原始字节与
  默认分支选择；
- `reverse-tools/evidence/a2_8_relation_helpers.txt`：七个候选/使用/位置关系辅助函数的
  Ghidra 静态伪代码。

上述内容来自离线静态反编译和附件示例对照，不是运行时跟踪。字段名称、配置来源及所有
关系表的业务类型没有调试符号，因此只将可由控制流证明的候选—使用集合差作为核心判据。

## Product integration boundary

产品使用 Verilog/SystemVerilog 语义模型实现以下确定子集：

- 未被本地逻辑读取或实例转发的输入端口；
- 既无驱动又无读取/实例连接的内部声明；
- 已有声明初始化、连续赋值或过程赋值驱动，但没有读取/实例连接的内部信号；
- 右值、条件、敏感表达式、自读、位选/范围选择及实例实参均建立使用关系；
- 对同一源文件中唯一可解析的 Verilog/SystemVerilog 子模块，按命名或位置端口
  方向分类实参：输出 formal 对 actual 建立驱动，输入/inout formal 对 actual
  建立使用；未解析或重名子模块仍保守处理；
- 标准输出使用构造函数默认选中的原生中文消息；
- 未驱动输出和未引用双向端口不作为本条款的确定违规，因为模块边界外部使用无法从当前
  源文件证明。

与 5.2.10 相比，本条款额外覆盖未使用输入端口和完全未使用的内部声明；5.2.10 只覆盖
“有驱动无负载”内部信号。原生 `+0xa2/+0xa4` 的语义名称、跨文件/库端口解析、
跨层别名、generate 和精确告警次数仍未恢复。未知外部客户在构造后直接改写规则对象
内存也不在附件静态证据可证明范围内。无诊断保持
`ManualReviewRequired`，不声明完整厂商算法等价。
