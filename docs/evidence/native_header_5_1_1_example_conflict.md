# GJB10157.5.1.1 文件头示例冲突记录

来源：附件 `examples_html/GJB10157_VLOG.5.1.1.html`，DLL SHA-256 `60e6b52875f4d7c3fbdf494d869b3a4bcc3fdc8ee63d8620ea9614da5d6599b0`。

- 实例 2 的正确代码有 `Filename:`、`Description:`、`author:`，但作者值为空；说明至少此简版示例不能要求作者值非空。
- 实例 3 的错误代码有 `File name:`、`Last modified Date:`、`Last Version:`、`history:`、`Descriptions:`，但作者值为空；说明详版示例把空作者视作错误。
- 默认模板据此按修订字段区分简版与详版，以同时匹配两组示例。这是从示例推断出的独立产品策略，不是已证实的厂商原生条件。
- 原生反编译证据显示此规则由外部关键字映射启用，按模块前物理行做关键字子串匹配；映射的厂商默认值尚未恢复。因此产品配置显式关键字策略与默认模板必须分开解释，不能将默认模板宣称为原生等价实现。
