## 已观察事实

1. 构造函数登记 `GJB10157_VLOG.9.4.5`。
2. 过滤器只接纳 `0x55` / `0x56` 两种赋值节点，要求至少两个 child；结合交叉规则映射，对应阻塞/非阻塞赋值路径。
3. 第一 child 的内部名称必须包含 `$func$`，且以 `$result` 结尾。这把候选限定为前端降级后的 function 返回值赋值，而不是普通同名信号写入。
4. 运行函数对第一、第二 child 分别调用 `FUN_1808f4650`，并以整数不等比较两个推导宽度；不只检查“返回值较窄”，反方向不等同样报告。
5. 报告位于候选循环内部，使用当前赋值节点的源码位置；一个 function 中多个不匹配返回赋值分别输出。
6. 严重度固定为 `Warning`。
7. `0x180ef6620` 的 GB18030 格式模板为：
   `在function语句中，返回值的位宽%d与输入信号的位宽%d不一致`。
8. 两个 `%d` 的参数顺序分别是第一 child 宽度和第二 child 宽度。

既有共享位宽 helper 证据表明，在该调用模式中，嵌套 `ADD/SUB/MUL/DIV/MOD`
以直接子表达式最大宽度传播，一元符号传播 child 宽度，选择节点按所选范围推导。
本轮产品只接入这些已有交叉证据支持、且源码范围可静态确定的形状。

## 产品接入

完成条件预处理后，独立源码适配器当前支持：

- 非 ANSI function 的固定十进制返回范围与 input 范围；
- 阻塞和非阻塞的直接 function 返回赋值；
- input 标识符、固定数值 bit-select/part-select；
- 括号、一元 `+/-/~`，以及嵌套 `+ - * / %`，按已恢复的最大 child 宽度传播；
- 每个可证明的宽度不匹配赋值独立输出，使用原生 `Warning`、格式文本、宽度顺序和赋值行列。

公开编号保持官方三段式 `R-13-5`；内部条款键仅用于标准追溯。

## 未知与保守边界

- `$func$...$result` 的完整前端命名和所有函数语法降级仍未知；
- ANSI、typed、参数化返回类型，参数覆盖、局部 typedef、完整字面量规则、concat/replicate、调用及其他 SystemVerilog 表达式尚未在本适配器中证明；
- 完整原生位宽 helper 对 signedness、常量折叠、动态选择和错误恢复的行为仍未恢复；
- 无法推导宽度的赋值不输出本条报警，并继续保持 `ManualReviewRequired`，不判为合规。

因此本轮状态为“证据支持的核心谓词 + 已接入的有界源适配器”，不是完整厂商前端等价。
