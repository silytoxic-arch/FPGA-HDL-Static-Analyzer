# GJB9765.4.14.d.2 分号计数判据（核心分块算法已接入）

目标附件：`T-Linter.dll`，SHA-256 `60e6b52875f4d7c3fbdf494d869b3a4bcc3fdc8ee63d8620ea9614da5d6599b0`。

## 原生静态观察

`FUN_1805cb0d0` 使用 `fopen(path, "r")` 和 `fgets(buffer, 0xff, file)`。每次最多读取 254 个数据字节，读取块序号直接作为诊断行号。扫描在首个字面 `--` 处停止，并统计此前所有 ASCII 分号；计数大于 1 时输出一条 Warning。它不解析 VHDL 语句或字符串，因此字符串内的分号同样计数。证据 `ev_1368fc8f429eba7e2bc3986daf88028e9d33f5cbf274f32757b2333040e50c6a`。这是反编译静态观察，不是原厂源码或运行观测。

## 产品接入

V1.4.22 与 d.1 共用 Windows 文本模式和 `fgets(0xff)` 分块模拟。字符串中的分号参与计数；字符串中的 `--` 截断后续扫描；跨 254 字节边界的两个 `-` 不组成注释。每个含两个以上分号的数据块最多报告一次。测试覆盖代码、注释、字符串、字符串内双连字符及分块边界。

## 尚未恢复的边界
