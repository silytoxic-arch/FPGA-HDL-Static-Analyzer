# V1.2.36 表格拖动方向与明确框体

本版针对“问题列表”和“代码规模明细”两张结果表：

- 列标题分隔线的拖动量改用全局屏幕坐标计算，避免横向滚动或表头视口位置变化时出现反向观感；保留向左收窄、向右加宽的交互。
- 增加表头悬停调整光标；增加滚动到右侧后的拖动方向回归测试。
- 取消内外两重边框，将标题和表格放入同一深色 2 px 外框；空白区域也绘制横向、纵向网格线，明确每列边界。
- 两张表仍支持横向滚动，调整某列不会自动改变相邻列宽。

本版没有更改 HDL 规则判据。规则集恢复进度以 `docs/evidence/native_rule_implementation_ledger.json` 为准，尚不能声称 209 条均与原生工具等价。
