## GJB9765.4.14.c.1、c.2、c.3 原生读取块修正

DLL 静态证据确认三个规则分别由 `FUN_1805c86a0`、`FUN_1805c9410`、
`FUN_1805c9e90` 执行，并通过 `fopen("r")`、`fgets(..., 0xff, ...)` 读取源码。
V1.4.24 已接入：

- 每个读取块最多 254 个数据字节，遇 LF 提前结束；
- 诊断行号使用读取块序号，超长物理行可能占用多个序号；
- 注释起点只终止候选扫描，不缩短候选已经读取的右邻接缓冲区；
- c.1 的警告标志及 `(others` 清除仅在同一读取块内生效；
- c.2 不拼接跨块的 `<=`、`:=`，并跳过缺少右邻字节的块尾候选；
- c.3 跳过缺少右邻字节的块尾单运算符；
- 三条规则继续保留字符串参与扫描和首个字面 `--` 截断行为。

新增 254 字节分块、跨块运算符、跨块 `(others`、块序号及运算符紧邻注释测试。
产品按目标 Windows PE 和文本模式推断进行常规 CRLF→LF 转换；反编译中的特殊
左边界地址保护、NUL、Ctrl-Z、代码页、流错误、重复源记录和文件变化仍缺少运行态
验证，因此无告警继续保持 `ManualReviewRequired`。
