# FPGA HDL Static Analyzer V1.4.170

## 本轮目标

恢复 GJB10157 官方规则 `R-12-1`（内部条款键 `GJB10157.9.3.1`）中两个前端属性的产生逻辑，并提高 FOR 初值、条件和步进目标判断准确性。本版不调整界面和表格。

## 新恢复的原生行为

- `FUN_1805856b0` 分别消费精确属性 `is_initVal_const` 与 `is_loop_condition_const`，并比较第 1、3 个循环子节点的目标名称。
- `FUN_180914500` 要求第 1、3 个循环子节点为 `AST_ASSIGN_EQ(0x55)`，procedural/generate 左值分别绑定 `AST_WIRE(6)` / `AST_GENVAR(0x5f)`，两个绑定指针必须相同。
- 初始化 RHS 和循环条件均先被克隆、准备宽度并反复简化；最终不是 `AST_CONSTANT(0x10)` 才生成对应属性。
- 循环条件在当前计数器被替换为常量之后简化，因此计数器本身不能作为非常量依赖报告。

## 产品修正与测试

- 完整分析初始化式与条件表达式的声明运行时依赖，不再拆成孤立标识符。
- 保留系统常量函数调用上下文，修复 `$bits(d)` 参数被误判为运行时边界的问题。
- 显式第 1、3 段目标按声明对象比较，支持选择左值以及内联 `integer` / `genvar` 计数器。
- 新增参数/localparam 算式、系统常量函数、嵌套运行时初值、选择左值和 procedural/generate 边界测试。
- 未支持的完整常量折叠和无告警结果继续保持 `ManualReviewRequired`。
