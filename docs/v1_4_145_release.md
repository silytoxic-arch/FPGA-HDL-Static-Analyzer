# FPGA HDL Static Analyzer V1.4.145

> 后续更强的寄存器级证据已在 V1.4.146 修正本版本关于别名传播的结论：原生使用两个独立集合且只构造一跳派生名称，汇聚后的裸别名不会报告。请以 V1.4.146 为准。

本轮继续恢复 `GJB9765 / R-9-1`（原附件内部名称 `GJB9765.4.9.a`）的时钟重汇聚判断，软件和报告仍只展示官方三段式编号 `R-9-1`。

## 原生边界修正

- 原生 `FUN_18069ed00` 对最终候选 RHS 使用位掩码 `0xe0000019f`，精确接受 AST 类型 `0x24`、`0x25`、`0x26`、`0x27`、`0x28`、`0x2b`、`0x2c`、`0x45`、`0x46`、`0x47`，并额外接受 `AST_WHEN(0xb6)`。
- 这些类型对应 NOT、AND/OR、XOR/XNOR、NAND/NOR 及条件表达式，不包含移位或旋转根；此前把 `sll/srl/sla/sra/rol/ror` 当作最终候选的范围过宽，现已移除。
- `FUN_18069fb50` 会递归检查单个表达式树的标识符叶节点；本版本当时尚未区分两个调用点使用的不同关系容器，相关别名结论已由 V1.4.146 替代。
- 只有同一时钟关系在候选表达式中命中两次以上，且该候选实际进入解析器确认的时钟路径，才报告 `R-9-1`。

## 验证

当时增加了别名和移位根边界回归；其中别名预期已由 V1.4.146 的寄存器级调用点证据纠正。层次绑定、建模黑盒和完整原生关系类别仍保持人工复核，不声明完整原生等价。
