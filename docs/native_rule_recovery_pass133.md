## 产品接入

默认展开器在用户配置宏之后插入 `SYNTHESIS=1`，与已确认的原生选项顺序一致；
原移植宏表保留 `YOSYS=1`。保留源码 `undef`、`resetall` 对宏表的删除行为。
保留物理位置的条件编译投影也初始化这两个默认定义，并支持 resetall 清空。
没有添加 formal/nosynthesis 模式的 UI 或暗中推断另一种前端。

每次标准检查先展开所有适用 Verilog 根，再使用同批展开结果建立跨文件模块名称计数；
规则检查复用这些结果。R-2-1/R-2-2/R-2-3/R-2-4/R-2-6/A-2-2/A-2-5
在已恢复的模块唯一性门控处使用该计数。宏生成和 include 中的模块均参与；
重复组不会压制另一个唯一组，非活动分支不会制造重复组。

R-2-3 从旧的物理投影和未展开 structure 迁移到展开声明，保留既有语法准入、
七类主体、类别配置及优先级、精确正文、Error 严重度、逐节点报告。
A-2-5 的活动函数 `1805306e0` 也明确检查根向量字节数恰为 8 且节点为 AST_MODULE(2)，
本轮修正之前未应用其跨文件唯一性准入的问题，声明族边界保持独立。
任何根展开失败时，工程模块索引视为未证明，不靠省略失败根来制造唯一性。
没有命中继续为需人工复核，不宣称合规。

定位延续上一轮已公开的产品政策：声明报告实际词法来源文件/行，列 1 表示原生无列。
部分原生入口使用模块根文件加候选行，因此仍不宣称报告表面完全等价。
