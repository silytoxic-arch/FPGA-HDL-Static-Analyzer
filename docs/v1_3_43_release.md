# FPGA HDL Static Analyzer V1.3.43

本版只推进规则集，没有调整问题列表、代码规模明细或其他表格界面。

- 逆向并接入 `GJB9765.4.6.b.1` 的赋值、六类关系运算和四类运算操作位宽判据。
- 修复原实现只报告“源宽于目标”的截断、漏掉目标更宽的隐式扩展问题；原生规则对两个方向都要求位宽相等。
- 附件违反样例由原先只命中 `a2(7)←A(8)` 一处，提升为准确命中 `a1(9)←A(8)`、`a2(7)←A(8)`、时序 `a3(12)←A(8)` 三处。
- 新增 VHDL `and/or/xor/xnor` 直接操作数宽度检查；关系运算继续使用已知宽度的有界检查。
- 未知宽度不猜测，复杂函数、属性及尚未恢复的加减特例保持人工复核。
- 131 项测试全部通过；446 个附件样例审计保持 345 个自动匹配和 5 个自动不匹配。
- 核心判断逻辑累计接入 152/209，仍有 57 条需要继续解释；完整原生算法验证仍为 0。
