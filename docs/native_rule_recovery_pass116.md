# 第一百一十六轮：有类型整数折叠接入 R-6-3

同一目标，仅静态检查。新增指令证据见
`reverse-tools/evidence/t_linter_pass116/`；常量转换与低 32 位缓存见第九十六至九十八轮，
简化运算和源节点替换见第一百一十三轮。

普通十进制构造路径在 0x1800d19c7 明确设置 DL=1，再调用 FUN_1808e3a30。
结合转换函数的最少 32 位与正数最高位补零路径，可确认其有符号属性；
正数 2147483648 需要 33 位，不能简单套用宿主 int32 或布尔真值。
源节点替换尾部保留 +0x210 行号；localparam 替换后诊断应定位使用处。

产品新增 `native_verilog_integer.h`，支持 1 至 64 位两态整数、明确尺寸的
二/八/十/十六进制、有符号扩展、截断、受支持的一元和二元运算，以及词法作用域
内不可覆盖的 localparam。父运算的位宽和符号上下文先传播，再计算位向量。
localparam 初始化值单独求解后按声明类型调整，使用处重新参与外层表达式。
R-6-3 的相等比较两侧都可以使用这些常量，最终仍按原生低 32 位缓存比较 0/1。
旧的单字面量四态缓存行为继续保留。

可覆盖 parameter 的默认值、依赖它的 localparam、循环/未解析绑定、四态表达式、
超过 64 位、无尺寸带基数字面量的运算、除零、负移位、幂、拼接、三元和函数调用
保持未知。未实现完整 HDL 展开器，也不把未知路径判为合规。

独立检查脚本 `scripts/verify_integer_folding_iverilog.py` 使用 Icarus 的
`-g2012 -gstrict-expr-width`，比较自然位宽和位向量值；没有运行原厂软件。
47 项中 45 项一致。两项大十进制运算有已知差异：严格模式使用 32 位，
原生转换使用 33 位；原生证据对应的预期在 C++ 中单独断言。
有符号缓存由 C++ 固定预期验证，独立脚本不宣称完整符号类型等价。
JSON 保留每项结果，不能将其宣传为 47 项原厂运行对照通过。

规则级测试覆盖两种边沿、比较两侧互换、类型截断、符号扩展、localparam 链、
未知边界及使用处行号。完整算法等价仍为 0/209。
