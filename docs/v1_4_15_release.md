# FPGA HDL Static Analyzer V1.4.15

本版继续只处理规则集，不调整界面。

## 五条子程序规则条件编译修正

修正 `GJB10157.9.4.1`、`.9.4.2`、`.9.4.4`、`.9.4.5` 和 `.9.4.6` 的条件编译
输入边界。它们分别检查 task 延时、initial、子程序写模块寄存器、function 返回位宽和 task
实参位宽；原生输入均来自 AST 或 lowering 后的内部节点。

本版改为仅在工程 `defines` 预处理成功后对活动 token 流执行有界适配器：

- 活动分支中的确定违规正常报告；
- 非活动分支中的 task、function 和 initial 不再误报；
- 五条规则的诊断位置保持原始物理行号；
- 预处理失败时不猜测结构。

新增五条规则的活动分支正例、非活动分支反例及逐条位置测试。原生内部标志、完整宏/include/
generate 展开和完整位宽推导仍未恢复，无告警继续保持人工复核。
