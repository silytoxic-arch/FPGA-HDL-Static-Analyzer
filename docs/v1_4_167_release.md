# FPGA HDL Static Analyzer V1.4.167

## 本轮目标

继续恢复 GJB10157 官方规则 `A-11-3`（内部条款键 `GJB10157.9.2.9`）的模块/CASE 候选、default 分支所有权、赋值过滤和诊断重数。本版不调整界面和表格。

## 新恢复的原生行为

- 构造函数 `FUN_1800240a0` 注册规则并安装虚表 `0x180ef5568`；根选择器只接收 `AST_MODULE(2)`。
- `FUN_1805853a0` 只收集首子节点为 `AST_IDENTIFIER(0x13)`、且不与模块根同一源码行的 `AST_CASE(0x57)`。
- 只检查 CASE 的直接 default 分支，并只从其第二个子节点递归收集阻塞/非阻塞赋值。
- 每个赋值必须恰有两个直接子节点；首子节点字符串含 `$` 时跳过。
- `FUN_180585480` 扫描完整赋值子树，只认编码字节 `0x02` 的 X；一个赋值含多个 X 仍只报一次，多个违规赋值分别报告。
- 固定消息为“避免在default分支中出现包含'x'的值.”，DLL 内部严重度为 Warning。

## 产品修正与测试

- 旧实现对常量/运算表达式 selector 也会检查，并将一个 default 中的多个违规赋值合并成一条。
- 新实现要求完整 `case/casex/casez`、模块内标识符根 selector 和直接 default item，保留原生每赋值诊断重数。
- 新增常量/运算/位选择 selector、多赋值、多 X、嵌套 CASE、LHS X、`$` 名称、拼接左值、不完整 case、模块同行 CASE 和固定消息边界测试。
- 未支持或无法证明的前端折叠路径以及无告警结果继续保持 `ManualReviewRequired`。
