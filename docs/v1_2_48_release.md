# V1.2.48 VHDL 嵌套 IF 缩进规则

新增 GJB9765.4.14.b.4 的有界检测：为顺序 VHDL `if`、`elsif`、`else` 建立分支关系，每个分支只链接首个嵌套 IF；Tab 按 4 列制表位换算显示列，嵌套 IF 未位于父分支关键字右侧时报告 Warning。

附件错误例在未缩进的第二层 IF 处产生一条告警，正确例无告警。测试还覆盖 elsif/else 独立分支、只增加一个显示列仍满足本条原生谓词、第二兄弟嵌套 IF 不替代首个链接以及 if-generate 排除边界。原生证据及限制见 [恢复记录](evidence/native_vhdl_nested_if_indentation_4_14_b_4_findings.md)。

公开样例审计仍为 446 例，Automated 类匹配数由 195 增至 197、失配维持 17。逐条台账现为 209 条中 53 条核心谓词部分接入、2 条模型谓词已观察但未接入、156 条仍需解释、0 条完整等价验证；无告警仍不判定为已证明合规。
