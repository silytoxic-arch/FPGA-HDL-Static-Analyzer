# FPGA HDL Static Analyzer V1.4.163

## 本轮目标

继续恢复 GJB9765 官方规则 `A-5-2`（内部条款键 `GJB9765.4.5.f.1`）的原生名称长度候选集，修正旧版“仅端口与 signal”的过窄实现。本版不调整界面和表格。

## 新恢复的原生行为

- 在全新 Ghidra 12.1.4 工程中重新分析 SHA-256 为 `60e6b52875f4d7c3fbdf494d869b3a4bcc3fdc8ee63d8620ea9614da5d6599b0` 的 `T-Linter.dll`。
- `FUN_1805e5770` 只有规则入口 `FUN_1805e4790` 一个非递归代码调用者，并在末尾无条件递归所有子节点；旧证据说明中的“仅从四类起点遍历”已纠正。
- 原生枚举函数确认候选涉及函数、结构体、实体、类型、信号、变量、过程、子类型，以及结构体/块/泛型/端口容器下的直接声明节点。
- 全局默认范围为 1～20 字节；`AST_BLOCK` 另有名称必须长于 22 字节的准入门槛，所以 21、22 字节块标号不报告，23 字节非内部块标号报告。

## 产品实现与回归

- 产品接入可从源码可靠绑定的实体、结构体、类型、子类型、信号、变量、常量、端口、泛型、函数、过程、进程标号和块标号类别。
- 每个源码 token 最多由本适配器报告一次，避免同一声明经多条源码收集路径重复输出。
- 新增综合正反例，覆盖 12 类长名称；新增 21/22/23 字节块标号边界。
- 无告警路径继续保持 `ManualReviewRequired`，不声明完整原生等价或自动合规。
