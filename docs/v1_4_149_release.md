# FPGA HDL Static Analyzer V1.4.149

## 本轮逆向结论

- 对用户附件 `T-Linter.dll` 的 `FUN_1804c5890 @ 0x1804c5890` 进行只读定点反编译。
- 该辅助函数仅执行两级直接子节点遍历：根节点的直接 `AST_ARCHITECTURE(0x75)` 子节点，以及架构的直接 `AST_ALWAYS/PROCESS(0x52)` 子节点。
- 收集器不递归。因此 generate、block、子程序或其他并发节点下的进程不会交给 `FUN_1804d56f0` 建立 `R-9-1` 时钟关系。
- 收集顺序保持根节点顺序和架构子节点顺序，不按名称去重。

## 产品修正

- `R-9-1` 的类别 1/2 时钟关系只从架构直接进程建立；generate/block 内嵌进程不再扩充原始关系集合。
- 提取并复用架构直接节点掩码，同时保留无函数体的前向子程序声明，避免其错误阻断架构 `begin` 识别。
- 新增边界用例：只有 generate 内嵌进程把 `clk` 声明为时钟时，两条 `clk` 派生路径汇聚到另一个直接时钟，`R-9-1` 不得报告。
- 规则公开编号保持官方三段式，例如 `R-9-1`；完整 GJB 条款号仍仅作内部证据键。
