# 第九十轮：R-6-2 候选容器不去重

目标为既有 T-Linter.dll，同一 SHA-256；静态反编译，未执行附件。

## 容器语义已确认

- FUN_180af6c20 将三个指针清零，是空向量初始化。
- FUN_18092e190 返回 `(end-begin)>>3`，按 8 字节指针元素计数。
- FUN_1801a67e0 返回 `begin + index*8`，直接按索引取指针地址。
- FUN_180132830 扩容后在尾部写入传入元素，将 end 增加 8。没有键查找、
  指针查重或已有元素比较；其自引用分支只为扩容时保持传入元素地址有效。

结合第八十九轮两次调用 R9 均为同一个输出容器，证实重复 AST 指针会作为多个
候选保留。后续对每个元素独立创建状态表并报告，因而重复候选可产生重复报告。
此前“是否容器去重”的未知项已消除。

## 尚不能直接映射的边界

两个祖先路径前缀存在重叠，但源码 always 的隐式 statement/block 与显式
begin/end 是否恰好对应一层或两层 AST_BLOCK 尚未完全追踪。不能只看源码缩进
或 begin 关键字数量就决定报告乘数。本轮保留产品当前每源码根一次的有界行为，
将完整原生重数明确列为待接入，不将其误称已等价。

构造器调用窄窗口脚本对类型 0x54 没有返回匹配；此前已有反编译中存在直接
0x54 构造调用，说明该脚本的引用/窗口覆盖不足，空结果不构成不存在生产者的证据。
