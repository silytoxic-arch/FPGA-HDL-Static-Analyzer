# FPGA HDL Static Analyzer V1.3.61

本版推进 GJB9765.4.9.b。原生代码把条件控制名与时钟关系名求交集；产品已检查同一 VHDL 设计单元里直接用时钟名作 `IF`、`ELSIF` 或 `CASE` 控制的情况，并在控制表达式定位。边沿检测函数及非时钟控制信号不会触发这条规则。

规则证据和已知边界见 [4.9.b 恢复记录](evidence/native_vhdl_clock_mux_control_4_9_b_findings.md)。复杂层次与赋值传播尚未恢复，无告警仍需人工复核。
