# FPGA HDL Static Analyzer V1.4.25

本版继续只处理规则集，不调整界面。

## GJB10157.8.7 DIV/MOD 原生阈值接入

DLL 静态反编译确认 `FUN_1805790d0` 对 `AST_DIV(0x3f)` 与
`AST_MOD(0x40)` 执行相同判据：先由 `FUN_1808f4650` 推断整个运算节点位宽，
仅当 `target_width < inferred_width - 1` 时报告。进一步恢复
`FUN_1808f46c0` 后确认，这两个节点通过递归遍历子节点取得最大子宽度。

产品现对两个直接、静态定宽、非 memory 信号操作数接入该非常规原生判据：

- `inferred_width = max(left_width, right_width)`；
- `/` 与 `%` 都在目标小于 `inferred_width - 1` 时报告；
- 一位表达式不会因减一产生无符号下溢或伪告警；
- 未用常规 HDL 经验公式替换厂商二进制判断。

新增除法命中/边界、取模命中及一位下界测试。字面量、嵌套表达式、符号传播、
参数覆盖和 POW 浮点公式仍保持 `ManualReviewRequired`。

## GJB10157.5.1.3 报告粒度证据补全

新增 `FUN_180527930`、`FUN_180527d90` 的静态伪代码证据。现可确认：主函数对
每个收集到的 AST_WIRE 节点构造一条记录，报告函数逐记录比较并逐记录写入诊断，
报告阶段不按物理行去重。

但二进制消费端仍不能证明专有前端会把 `wire a,b` 构造成一个还是多个 AST_WIRE
节点，因此同一物理行的最终原生重复次数仍标记为未知。产品继续按物理行合并，
不依据推测制造重复告警。
