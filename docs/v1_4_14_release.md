# FPGA HDL Static Analyzer V1.4.14

本版继续只处理规则集，不调整界面。

## 七条结构规则条件编译修正

修正 `GJB10157.9.1.5`、`.9.2.5`、`.9.2.6`、`.9.3.5`、`.9.3.6`、`.9.4.3`
和 `.9.4.10` 的条件编译输入边界。这些规则的原生实现消费 AST 模块、过程、函数、case、
repeat 或索引结构；产品此前却在预处理之后再次扫描原始 token，可能漏报活动分支或误报非活动
分支。

本版统一使用工程 `defines` 成功预处理后的活动 token 流：

- 活动分支中的覆盖赋值、错误敏感列表、运行时 case 标签、函数递归、运行时 repeat、function
  非阻塞赋值及复杂索引正常报告；
- 非活动分支不产生上述规则的误报；
- 七条规则的诊断行号均保持原始物理源位置；
- 预处理失败时不猜测条件分支。

新增七条规则的活动分支正例、非活动分支反例及逐条源位置测试。完整厂商宏/include/generate
展开、常量折叠和错误恢复仍未恢复，无告警继续保持人工复核。
