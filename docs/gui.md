# 桌面分析工作流

Qt 6 Widgets 桌面应用已连接与 CLI 相同的 `analysis::Analyzer` 和报告层，不维护第二套
规则实现。

## 工作流程

1. 点击 **打开 RTL 源码** 或 **文件 → 打开 RTL 源码…**，直接选择 `.v`、`.sv`、`.vhd`、
   `.vhdl` 文件，支持多选。只分析选中的源码，不会自动递归扫描父目录。
2. 在顶部规则集选择 GJB10157-2021（Verilog）或 GJB9765-2020（VHDL）；GUI 选择覆盖配置中的
   标准设置。应用读取首个源码所在目录的 `.fpga-lint.conf` 及诊断基线，在 Qt 全局线程池中执行分析。
   切换规则集会重新分析当前工程，状态栏显示逐条评估数量与通过/违反/待上下文/待复核统计。
3. **设计层次** 显示 module/entity、顶层标记、parameter/generic、端口方向及默认值、
   时钟/复位属性、时序过程读写、实例参数覆盖和端口连接数量/风格/通配状态及
   VHDL association 顺序状态、resolved/external 状态。
4. **问题列表** 支持列排序，显示严重级、规则、消息、设计单元/信号、文件和行号。
   状态栏同步显示 critical/error/warning/info 数量以及 suppression/baseline 统计。
5. 单击问题显示完整说明与修改建议，并在只读源码视图中定位和选中对应行。
6. 双击层次树节点可打开 module/entity、时钟/复位事件、时序过程或实例所在源码位置。
   已认证 CDC 同步器以独立子节点展示源信号、两级寄存器和目的时钟域，并可跳转到目的过程。
7. 切换左侧 **代码行数统计** 页面查看总行数、代码行、注释行、空白行，包含工程/语言/文件
   汇总，支持数字排序和双击文件打开源码。
8. 可从 **文件** 菜单原子导出 HTML、SARIF 报告或行数统计 CSV（兼容 Windows Excel 中文）。

文件选择采用可见的非阻塞 Qt 窗口，避免依赖系统原生选择面板；取消选择保留当前结果。
分析期间 Run/Export 动作及规则集选择被禁用，窗口事件循环保持响应。后台任务捕获源码路径列表和所选标准，不访问
窗口对象；结果通过 `QFutureWatcher` 回到 GUI 线程更新控件。

界面遵循 [Figma 设计规范](ui_design.md)，包含工程导航、指标卡片和可调整的源码/问题区。

## 构建依赖

GUI 需要 Qt 6.2+ 的 Widgets 与 Concurrent 模块。核心/CLI 构建仍可用
`FPGA_ANALYZER_BUILD_GUI=OFF` 完全避开 Qt。

V1.0 已在 macOS arm64、Qt 6.11.2 下完成 Release 构建与离屏 GUI smoke 测试。该 smoke
覆盖窗口创建、核心页面装配与事件循环退出；交付到 Windows 或 Linux 时仍应在目标 Qt SDK
下重新构建，并补充本机人工交互验收。
