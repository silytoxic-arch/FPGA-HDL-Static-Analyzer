# FPGA HDL Static Analyzer V1.4.247

修正 VHDL A-10-4 在普通枚举和无关子类型声明下的检查遗漏。

- 按声明顺序建立 architecture、block 和 generate 的可见绑定。
- 普通标识符枚举和无约束 subtype mark 不再直接阻断无关时钟检查。
- 类型名和枚举字面量先隐藏外层同名对象，离开局部区域后恢复外层绑定。
- 别名类型归一化尚未恢复；使用该类型的对象不猜为 IEEE 标量，无诊断仍需人工复核。
- 复杂类型、约束、字符枚举、entity 声明和完整名称归一化继续恢复。

新增 34 组模型边界与 4 组端到端回归，本地 CTest 134/134 通过。
446 个附件示例保持 433 项自动匹配、6 项工程上下文匹配、4 项需上下文、
3 项既有静态实现/文档差异，没有新增未解释变化。

本轮保留 6 份新原始静态证据及摘要，详见 [第一百二十九轮](native_rule_recovery_pass129.md)。
完整算法验证仍为 0/209，不将来源子集测试宣称为完整厂商运行等价。
