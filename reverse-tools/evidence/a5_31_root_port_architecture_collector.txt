===========================

in param_2, and a mode byte in param_3.  It iterates only the current root's

   visited.  Its direct children of type 0x78 are handled by the same

Product consequence
===================

For a project containing an entity declaration in one VHDL file and its
architecture in another, the source adapter may combine entity ports with the
architecture's direct signal/assignment graph when the case-insensitive entity
name resolves to exactly one project design unit.  Diagnostics for a port must
retain the entity declaration's original file and location.

If the project contains more than one entity with the same folded name, source
order is not evidence of the native binder's choice.  That architecture is
therefore left unresolved and the rule remains ManualReviewRequired rather
than guessing a binding or declaring compliance.
